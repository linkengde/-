# Ag–Ti₃SiC₂ 相场双连续形貌候选

## 先看形貌

`phasefield_model_preview.png` 是直接预览：左侧为三维相界点云，中间为竖直切片，右侧为顶层俯视。紫色表示 Ti₃SiC₂ 骨架相，金色表示 Ag 相。相区看起来是互穿网络，不是两块平板。

## 用 OVITO 打开

打开 `AgTi3SiC2_phasefield_voxel_proxy.data`，文件类型选择 LAMMPS Data；再按 Particle Type 着色：Type 1 为 Ti₃SiC₂ 区域，Type 2 为 Ag 区域。

**这个 `.data` 文件是形貌查看代理，不是原子模型。** 每个点表示一个相场网格单元中心，共 62,208 个点；Type 1/2 是相标签，文件里的质量也只是占位值。不要把它用于 LAMMPS 力学计算、最小化或轰击模拟。

## 相场与几何审计

- 形貌由守恒型 Cahn–Hilliard 相场方程演化，初态在旋节线不稳定波数带内加入随机扰动；再按序参量分位数将 60% 网格分给 Ti₃SiC₂、40% 分给 Ag。
- 网格为 `36 × 36 × 48`。两条面内矢量夹角 120°，长度约 37.286 Å；固体厚度 50 Å，顶面真空/入射空间 20 Å。设计边界为面内周期、法向开放。
- 以 6 邻接体素、面内周期边界审计：Ti₃SiC₂ 与 Ag 均为单一连通簇，最大簇比例均为 1.0；两相都绕过 x/y 周期边界并贯穿固体厚度。
- 相场自由能、迁移率和界面系数没有按 Ag–Ti₃SiC₂ 热力学参数标定；这一步只筛形貌，不代表平衡相分离预测。

## 原子模型状态

输入 `inputs/planar_reference.data` 的 SHA-256 为 `80b53f26f0665607753ab7a7677d1d504e99b0d75ef78ec70f6d6c82cca7615a`。它只是 4,783 原子的平面界面晶格参考，不是 Stage69 三维模型。用它将晶格点直接切分到相区后，异相最近距离最短为 0.335 Å，其中 379 对小于 1.5 Å、990 对小于 2.0 Å。因此，未把该原子映射保存成候选结构；筛查数据见 `direct_lattice_mapping_screen.json`。这份相场形貌和体素代理通过的是**形貌连通性检查**，还没有通过原子界面几何检查。

文件 `audit.json` 记录相场种子、步数、网格、尺寸、连通性和映射筛查。`build_phasefield_candidate.py` 与 `plot_phasefield_preview.py` 可用于重新生成相场候选和预览；所有输出均为几何阶段结果，没有运行势能计算、结构弛豫、加热或粒子轰击。
