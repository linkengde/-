# Ag–Ti₃SiC₂ 相场双连续形貌候选

## 先看形貌

`phasefield_model_preview.png` 是直接预览：左侧为三维相界点云，中间为竖直切片，右侧为顶层俯视。紫色表示 Ti₃SiC₂ 骨架相，金色表示 Ag 相。相区看起来是互穿网络，不是两块平板。

## 用 OVITO 打开

优先打开 `AgTi3SiC2_phasefield_atomic_candidate.data`，文件类型选择 LAMMPS Data；再按 Particle Type 着色：Type 1/2/3 分别是 Ti/Si/C（都设为紫色），Type 4 是 Ag（金色）。查看其照片级概貌可打开 `phasefield_atomic_candidate_preview.png`。

`AgTi3SiC2_phasefield_voxel_proxy.data` 仍作为相区体素代理保留：每个点表示一个相场网格单元中心，共 62,208 个点；Type 1/2 是相标签，文件里的质量也只是占位值。它只用于看连续相区，不是原子模型。

## 相场与几何审计

- 形貌由守恒型 Cahn–Hilliard 相场方程演化，初态在旋节线不稳定波数带内加入随机扰动；再按序参量分位数将 60% 网格分给 Ti₃SiC₂、40% 分给 Ag。
- 网格为 `36 × 36 × 48`。两条面内矢量夹角 120°，长度约 37.286 Å；固体厚度 50 Å，顶面真空/入射空间 20 Å。设计边界为面内周期、法向开放。
- 以 6 邻接体素、面内周期边界审计：Ti₃SiC₂ 与 Ag 均为单一连通簇，最大簇比例均为 1.0；两相都绕过 x/y 周期边界并贯穿固体厚度。
- 相场自由能、迁移率和界面系数没有按 Ag–Ti₃SiC₂ 热力学参数标定；这一步只筛形貌，不代表平衡相分离预测。

## 原子映射候选

输入 `inputs/planar_reference.data` 的 SHA-256 为 `80b53f26f0665607753ab7a7677d1d504e99b0d75ef78ec70f6d6c82cca7615a`。它只是 4,783 原子的平面界面晶格参考，不是 Stage69 三维模型。直接切分曾产生 0.335 Å 的异相近接；相关初筛见 `direct_lattice_mapping_screen.json`。

当前原子文件是**局部几何净距筛查后的候选**，不是势能弛豫结构：现有版本有 4,305 个原子，没有删原子；TSC 2,908、Ag 1,397。这个数是相区掩膜与晶格位点映射自然得到的记录值，不是构造目标或验收门槛；后续可因网格、晶格终止和连通性调整而变化。按两相体晶格位点密度估算 Ag:TSC 体积比约 39.58:60.42；Ag 质量分数约 61.14%。

固体原子最高约 z=50.35 Å，盒子法向长度 70 Å；面内盒矢量长度约 37.286 Å、夹角 120°。原子图连通审计中两相最大簇均覆盖该相全部原子；这些连通阈值是几何代理。

- 对异相原子施加 2.02 Å 的几何最小距离约束；最终异相最近距离约 2.020 Å，没有异相对小于 2.0 Å。
- 同时约束各相最近晶格距离不低于来源晶格的 95%。局部位移中位数为 TSC 0.118 Å、Ag 0.218 Å；最大位移分别 1.272 Å、1.203 Å。逐原子位置与位移见 `atomic_displacements.csv`。
- 按 3.35 Å（TSC）和 3.20 Å（Ag）的邻接半径做图连通检查，两相各自最大簇均为全部原子；这些是几何连通代理，不是势能稳定性证明。

2.02 Å 是几何筛查下限，不是 Ag–Ti/Si/C 平衡键长。交叉势参数没有验证，所以候选仍**不能用于生产级 LAMMPS 动力学或熔坑结论**。完整距离分类、位移统计、连通性与迭代记录在 `atomic_mapping_audit.json`。本轮没有运行势能计算、结构最小化、加热或粒子轰击。

脚本：`build_phasefield_candidate.py` 生成相场及体素代理；`map_atomic_candidate.py` 执行带距离约束的晶格点映射；`plot_atomic_candidate.py` 绘制原子候选预览。

## 八发轰击熔坑候选

后续探索性轰击结果单独保存在 [`impact_pilot_8hits_20261007/`](impact_pilot_8hits_20261007/)。该试验沿用上述双连续相区，将局部活动区重新对准实际入射点；不修改相场掩膜、相组成或盒子。报告、OVITO 末态、形貌预览、命中组和无轰击对照均在该目录。
