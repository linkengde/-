# Ag–Ti₃SiC₂ 100 ps 连续轰击续算

本分支从上一分支第 55 发后的冷却态开始：`structures/start_after55.data`（SHA-256 `3500c0ab98d74bcb9815cbf44ef0c31a934e06ab22c1539f01f5a52270b7ee09`）。此前第 1–36 发按约 0.5 ps/发运行；第 37–55 发按 0.2 ps/发运行。把先前轰击积分时长记为约 21.8 ps 后，本续算追加 391 发 Ag（每发 62 eV、200 fs 发射间隔），即增加 78.2 ps，目标累计轰击积分时长约 100 ps。批次检查用的额外冷却停顿不计入该时长；本续算不插入额外停顿，底部 300 K 热沉按每段输入保持启用。

入射半径目标分布在 7.5 Å 内按 `r/(1+(r/6 Å)^2)` 抽样。**第 56–322 发的旧驱动每批重复相同的随机数序列；第 323 发起改为跨批全局 seed=20261012 的连续序列。** 若候选入射位置与已有原子的三维初始距离小于 2.5 Å，则按相同半径分布重采样并记录实际坐标，防止把新原子创建在已有原子内部。实际位置记在 `impact_positions_used_323_446.csv`。时间步长 0.00005 ps，单发运行 4,000 步。每发均检查日志、原子数、局部温度、最大力、最近邻距离与几何连通性；每 25 发保存一个数据/restart/dump 检查点。任何异常会停在最近有效 `state_current`，不覆盖检查点。

## 第 323 发现场与边界修正

第 323 发首次尝试因入射 Ag 与已有 Ag 初始间距仅 0.489 Å，伴随 EAM 密度超表警告，并在 0.07 ps 时报 `Lost atoms`。该失败尝试和发射前第 322 发 data/restart 原样保存在 `failed_attempts/hit323_fixed_boundary_and_overlap/`。检查确认 `state_current` 仍是第 322 发完成态（约 75.2 ps），没有把失败尝试的半段改写进状态文件。

从第 323 发恢复时，输入 z 边界由固定 `f` 改为最小收缩包络 `m`，让非周期真空方向在原子接近盒边时扩展，避免把飞出表面的 Ag 当作数值丢失删除；x/y 仍为周期边界。入射能量、速度、间隔、势函数和材料原子没有改变。该边界变更和采样修正是续算方法的一部分，结果报告须标明在约 75.2 ps 处发生过此更改。

这是探索性高温轰击续算。Ag–Ti₃SiC₂ Morse/ZBL 交叉势未经独立验证；前置结构存在短 C–C 距离，阶段温度和形貌都不能当成已验证的液相/熔池判据。
