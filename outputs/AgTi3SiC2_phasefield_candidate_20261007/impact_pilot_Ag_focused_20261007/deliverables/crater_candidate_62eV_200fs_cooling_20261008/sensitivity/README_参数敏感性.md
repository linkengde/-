# 参数敏感性试验摘要

以下图片和指标是分开的探索性分支，不属于 62 eV 主条件。

- **150 eV 单发**：坑底局部 Ag 原子数占比 55.0%→52.5%，凹陷深度 14.3→14.9 Å；
- **再打三发 150 eV**：局部 Ag 占比回到 56.5%，凹陷深度变为 13.2 Å；再冷却 0.5 ps 后约 55.3% 和 12.8 Å。没有持续清空 Ag 的趋势。
- **500 eV 单发**：是论文中的高能单离子对照，不是电弧工作条件。自由坑区的瞬时动能温度峰值约 9,553 K；Ag 仍留在盒内，未形成坑内净清空，因此未续打。

这些结果说明提高单发能量会增强瞬态位移，但当前势和边界设置还不能可靠地产生“坑内只剩骨架”的结论。各百分比均为给定几何区域中的 Ag 原子数比例，不是 Ag 体积分数。
