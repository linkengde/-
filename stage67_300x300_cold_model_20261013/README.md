# Stage67 300×300 Å 冷态模型

模型已经在本地构建并核验。本分支只发布模型包与构建核验资料，不包含加热模拟，也没有运行MD。

- 模型尺寸：150.1 × 300 × 300 Å
- 原子数：682,587
- 起始状态：300 K冷态几何
- 周期边界：x/y/z均为周期边界
- 模型文件：`stage67_model_150x300x300_300K_1x3x3.data`

## 在云端取出模型

在仓库分支目录运行：

`python assemble_model.py`

脚本会按顺序拼接 `parts/` 下的归档分块，验证归档与模型SHA256，再将模型写入 `output/stage67_model_150x300x300_300K_1x3x3.data`。

模型SHA256：`36cbc94ec2aa4f7b13677d260fed4b55be7236583638be43b9f5a61e89a22cc1`

## 注意

此文件是几何构建结果，不是已经加热的熔池。几何报告记录一个继承的周期Ti–Ag最短距离1.000314475 Å；正式MD前应复核该接触与calibration-v0交叉势。几何构建成功不代表势函数或高温物理已验证。

完整结构核验报告在压缩包内的 `GEOMETRY_VALIDATION.md`。
