# POD v10 全模型 FIRE 停止报告

日期：2026-11-18（UTC）

## 判定

POD v10 全模型的 FIRE 结构松弛 **未通过 P0**。保守尝试在第 52 步停止；未得到收敛终态。按照门槛，不启动冷态 NVE/NVT，不启动加热，也不将该松弛副本用于后续 MD。

## 运行与停止原因

- 体系：347,464 原子，盒子 200 × 200 × 300 Å；固定底部 0–20 Å 的陶瓷骨架原子，其余可动。
- 先以 `dmax=0.01 Å` 单核运行至第 26 步，在第 25 步保存坐标；再从第 25 步坐标用 4 核 MPI 接续。
- Fmax 从初态 51.07 eV/Å 降至第 45 步的 13.49 eV/Å，随后反弹：第 47 步 13.67、第 48 步 14.77、第 49 步 17.00、第 50 步 19.81、第 51 步 23.23、第 52 步 27.04 eV/Å。按“异常力回升”停止条件中断。
- 最后检查点为第 50 步；总原子数仍为 347,464。未生成收敛终态、最终静态力文件或最终能量记录。

## 几何异常

第 50 步相对初态位移：中位数 0.093 Å、P95 0.244 Å、P99 0.302 Å、最大 0.470 Å。虽然全局位移尚小，局部短接触却明显恶化：

| 原子对 | 初态最短距离 (Å) | 第 50 步最短距离 (Å) |
|---|---:|---:|
| Ag–Ag | 1.567 | 2.124 |
| Ag–C | 1.441 | 1.878 |
| C–C | 1.639 | **1.391** |
| C–Ti | 1.656 | 1.724 |
| Si–Ti | 1.659 | **1.119** |

两个跟踪到的局部对进一步显示 FIRE 沿势能下降方向把原子拉近：Ti ID 76905–Si ID 76907 从初态约 1.681 Å 缩至 1.119 Å；C ID 140–C ID 2748 从约 1.705 Å 缩至 1.391 Å。它们在初态不是全体系最近的异种/同种原子对，但在松弛中成为最短对。

同一初态的 POD 静态净力在这两对原子上也分别指向彼此：沿 Ti→Si 方向的力投影为 +8.15/+8.97 eV/Å，沿 C→C 方向为 +3.82/+5.14 eV/Å（正号表示朝向配对原子）。这是包含周围邻居作用的总力投影，不能当成二体势分解，但与后续距离收缩相符。SNAP v10 在相同初态的两对投影没有呈现双方都朝向彼此；这仍不足以证明 SNAP 能通过全模型松弛，需另行验证。

Ti–C 距离 2.6 Å 的粗略邻接数增加（每 Ti 平均 2.207→2.517），没有 C 邻居的 Ti 数减少（13,862→8,530）。由于该诊断图不含 Si，最大分量比例约 6.07% 不能用来确认完整 MAX 骨架连通性；短接触恶化和力反弹已足以判定 P0 不通过。

## 结论与后续

这次结果表明，POD v10 在当前完整结构上做松弛时出现局部非物理塌缩迹象。它不能证明 POD v10 在一般条件下都失效，但当前结构和势的组合不满足冷态 MD 准入。下一步应定位并核对上述局部环境的元素映射、原始几何和势能/力响应，再决定修复结构或增加有针对性的 DFT 约束并训练新版本。已为 Ti–Si 与 C–C 两种塌缩环境各建立一个局部 DFT 训练候选；它们与盲测集分开，结果尚在计算。SNAP v10 尚未做同类 FIRE，不能自动替换 POD。P2 的 8 个 MTP16 局部 DFT 标签已完成并验收，但它们不是这些 POD 塌缩环境的盲测标签。

**后续补充（C–C DFT 局部标签）：** 在第 50 步的 1.391 Å C–C 裁剪中，DFT 对两中心原子的力沿着彼此方向的投影分别为 +4.02 和 +3.52 eV/Å；POD v10 的对应投影为 −0.70 和 +0.56 eV/Å。DFT 推动两原子靠近，而 POD v10 对中心 C 给出相反方向的力，因此该几何值得纳入 v11 力训练。不能仅以 1.391 Å 距离将它定性为非物理 C–C 塌缩，它也可能代表局部成键重排。该有限裁剪标签仍待与 Ti–Si 结果一起完成审核；全模型 P0 暂不通过的主要未决项是 1.119 Å Si–Ti 接触及尚未收敛的 FIRE 终态。
