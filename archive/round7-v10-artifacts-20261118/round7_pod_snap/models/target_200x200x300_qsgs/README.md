# Ag–Ti₃SiC₂ 双连续模型（计算盒 200 × 200 × 300 Å）

## 模型设计

- 计算盒：x=0–200 Å、y=0–200 Å、z=0–300 Å；x/y 周期，z 开放。
- 双连续材料区：z=0–150 Å，沿用 Round7 的材料厚度尺度。Ti₃SiC₂ 骨架由随机 QSGS 生长；Ag 填充互补空间。两相都要求在 x/y 周期方向绕行，并沿 z 贯穿材料厚度。
- 真空区：z=150–300 Å。Newton 区的 150–200 Å 段为上方缓冲真空；200–250 Å 为溅射观察区，250–300 Å 为蒸发观察区。观察区初始没有原子；进入这些区域的原子不受恒温约束，仍参与动力学。
- 固定层：z=0–20 Å 的 Ti₃SiC₂ 骨架原子固定，作为底部支撑；该层中的 Ag 不自动固定。
- 热沉层：z=20–40 Å 的初始原子组作为 300 K 理想热沉恒温组。
- 牛顿层：z=40–200 Å 的原子自由运动，供加热和冷却；初始材料在 z=150 Å 结束。

当前几何共有 347,464 个原子：Ag 80,674 个，Ti₃SiC₂ 骨架 266,790 个；按元素质量计算的 Ag:Ti₃SiC₂ 质量比为 1.00000034:1。原子数接近 35 万，与 Round7 的约 35 万原子规模接近。

### QSGS 四个随机控制量

1. 成核概率：0.0064（相对原候选 0.0032 加倍，以生成更细的骨架枝网）。
2. 生长概率系数：0.18；26 邻域按 `0.18 / 邻居距离` 生长，x/y 周期、z 开放。
3. Ag:Ti₃SiC₂ 目标质量比：1:1；据此搜索骨架体素比例并从互补域填 Ag。
4. 随机种子：20261116。

随机体素掩膜清理后，脚本还逐原子检查两相连通性。提高成核概率后，骨架体素线截平均值约从旧候选的 19.2 Å 降到 9.3 Å；这是网格形貌指标，不等于原子级最细颈宽。最终实际原子数及连通统计见 `geometry_report.json`。

## 热沉表示

当前已拟合的 POD/SNAP 势只包含 Ag、Ti、Si、C，因此这里把 20–40 Å 层作为**理想 300 K 恒温热沉**，没有加入显式 Al 原子，也没有声称它是原子级 Al–Si 合金。这样不会把未训练的 Al 相互作用混进当前四元势。若后续要求显式 Al–Si 原子层，需要增加 Al 势与跨界面参数，再重新验证模型。

## 文件

- `Ag_Ti3SiC2_bicontinuous_200x200x300.data.gz`：LAMMPS 原子模型，类型顺序为 Ti、Si、C、Ag。
- `Ag_Ti3SiC2_bicontinuous_200x200x300.extxyz.gz`：含 phase、固定骨架和恒温区标记的扩展 XYZ。
- `qsgs_bicontinuous_mask.npz`：100×100×75 的 QSGS 骨架掩膜。
- `geometry_report.json`：盒子、分层、原子数、连通性和 SHA-256。
- `in.layer_groups`：按设计定义固定层、恒温层、牛顿层和动态观察区的 LAMMPS 分组示例。
- `model_preview_OVITO_300dpi.png`：整盒 OVITO 三维预览。
- `model_center_cut_OVITO_300dpi.png`：沿 y=100 Å 剖切、保留后半模型的 OVITO 预览。

## 当前状态

几何已经构建并检查两相原子连通；它仍是未弛豫初始结构。当前没有执行能量最小化、热平衡、加热、冷却或凝固计算。预览图展示的是完整计算盒；初始 Ag 全为固态候选，没有熔化标记。
