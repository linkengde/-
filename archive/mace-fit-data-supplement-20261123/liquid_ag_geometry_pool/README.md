# 纯 Ag 液态 DFT 标注候选池（仅几何）

本目录含 12 个 Ag64 几何候选，供后续选择 DFT 标注。**目前没有这些结构的 DFT 能量或力；不得把它们当作拟合标签。** 它们也未并入任何 train/dev/test 文件。

## 构型来源与覆盖

- 母轨迹：项目内 `research/mace-v12-transfer/coordination/reports/window-c/continuation_geometry_prep_20261024/` 下的两条 Ag EAM 液态采样轨迹（seed 501、902）。EAM 仅生成坐标，不是参考标签。
- 目标温度：1250 K 和 1600 K。
- 参考密度：Abdullaev、Khairulin 与 Stankus (2020), DOI `10.1088/1742-6596/1677/1/012161` 的液态 Ag 密度拟合式；见清单中的方程、温度范围和来源 PDF SHA-256。
- 每个温度包含 0.97、1.00、1.03 倍参考密度以及两个种子。±3% 是敏感性采样点，不是实验误差范围。
- 坐标与晶胞作各向同性缩放，分数坐标保持不变；源候选文件未修改。

原论文说明为 CC BY 3.0。完整候选清单保留了每帧输入来源哈希、目标密度、最小原子间距和输出哈希。

## 数据角色与后续门槛

将该目录视为 `TRAINING_CANDIDATE_ONLY` 几何池；按源种子和母轨迹进行家族分组，任何同一母轨迹帧及其密度缩放衍生件都不得跨入开发/盲测集。独立温度、密度值本身不会自动构成独立验证。

标注前逐帧检查液态结构特征、最近邻距离与重复环境；DFT 必须使用冻结且与拟合目标一致的协议，保存自由能、外推总能、力和完整 GPAW 收敛证据。标签经过收敛、元素/原子序映射、单位、能量约定及哈希审查前，禁止集成或重拟合。

这些小盒子和 EAM 轨迹只能扩充初始液态候选覆盖，不能代表 Ag/Ti₃SiC₂ 界面、固液共存或真实熔池行为。
