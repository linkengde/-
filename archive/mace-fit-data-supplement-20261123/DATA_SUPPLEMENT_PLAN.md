# Ag/Ti₃SiC₂ 势函数数据补充计划

## 现有缺口

已归档的 71 个训练帧主要覆盖 Ti₃SiC₂、Ag/MAX 界面与局部接触响应；没有纯 Ag 液态帧，也没有盲测集。先前 ACE/MTP 指标不能据此证明高温熔化—凝固能力，Si 热点向量误差问题也仍需单独解决。

## 补充顺序

| 数据族 | 目标 | 当前状态 |
|---|---|---|
| 纯 Ag 固态 | FCC 体相、位移、体积和剪切扰动 | 7 帧既有 DFT 控制已审查并整理为候选；仍缺有限温热振动 |
| 纯 Ag 液态 | 独立高温轨迹快照及 DFT 能量/力 | 第一帧 DFT 计算中；见 `ag_liquid_first_label/` |
| Ag 固液共存 | 固液界面及凝固生长局部环境 | 待构型设计和 DFT |
| Ti₃SiC₂ 固态热振动 | 骨架在目标温度区间内的力响应 | 现有数据有部分覆盖，需检查温度范围和独立来源 |
| 高温 Ag/Ti₃SiC₂ 界面 | 加热后的接触区局部构型和 Si 热点 | 待从可靠界面模型采样并完成 DFT |

先建立约 15–25 个经审查的多族训练候选作为探索性试拟合起点；这个数量只是工作计划，不是足够性的保证。纯 Ag 固相候选均来自同一个 CIF/Ag32 结构族，只能整体放在训练候选侧，不能拆到开发或测试。液态帧按轨迹/随机种子分组，避免把相邻相关帧分别放入训练和验证。独立开发验证应使用不同种子或不同界面构型，最终测试留给后续未参与调参的族。

## 准入原则

1. EAM、ACE 或 MTP 仅用于构型提议，不提供 DFT 标签。
2. 记录每个 DFT 输入的结构哈希、原子映射、计算设置和完整 SCF 日志。
3. 仅把 SCF 收敛、有限力且坐标/元素顺序核验通过的数据纳入训练候选。
4. 保留独立结构族划分；不把拟合后反复使用的开发帧称作盲测。
5. 能量 RMSE ≤10 meV/atom、力分量 RMSE ≤0.1 eV/Å、指定 Si 热点中心向量误差 ≤0.5 eV/Å 为当前探索性准则；仍需结合熔点、液态结构、界面稳定性和冷态 MD 检查。
6. 不启动触头加热/凝固生产模拟，直至多族训练、独立验证及物理稳定性门槛通过。
