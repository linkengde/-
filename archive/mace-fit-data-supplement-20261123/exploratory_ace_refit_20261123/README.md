# Exploratory ACE refit and screening, 2026-11-23

Contains the exact 83-train/7-development dataset generated by the preparation script, five ACE fits, model files and metrics, and gated LAMMPS cold-interface screens. The development set is source-family correlated. All five new models failed the 52-atom Ag/Ti3SiC2 cold relaxation gate; no NVE was run for them, and no heating was started. The legacy ACE_energy100 reference passed a narrow cold relaxation/NVE check but lacks liquid coverage and has validation errors outside the current exploratory fit targets. See `EXPLORATORY_ACE_REFIT_AND_SCREEN_REPORT.md`.

The separate `../ag_liquid_density_reference_attempts/.../dft_attempt_002/` folder preserves a deliberately interrupted, unconverged DFT attempt; it is not a training label.
