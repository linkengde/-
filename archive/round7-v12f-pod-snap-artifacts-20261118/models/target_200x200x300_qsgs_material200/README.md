# Ag–Ti3SiC2 双连续模型（材料高度 200 Å）

目标盒子为 200 × 200 × 300 Å，材料区 z=0–200 Å，真空观察区 z=200–300 Å。分层按已确认方案设置：固定骨架 0–20 Å、300 K 理想热沉 20–40 Å、牛顿层 40–200 Å、溅射观察层 200–250 Å、蒸发观察层 250–300 Å。

骨架采用随机四参数 QSGS 生长，Ag 填充互补区域，目标质量比 Ag:Ti3SiC2=1:1，并检查两相连通性。当前模型仅为几何构建，须审查实际原子数、连续性、近邻距离和质量比；没有弛豫或 MD 验证。它与旧的 150 Å 材料高度、347,464 原子模型分目录保存。

构建脚本：`build_model.py`。生成结束后以 `geometry_report.json` 中的测量结果为准。

构建核验：458,248 个原子；Ag=106,396，Ti₃SiC₂ 骨架=351,852；实际质量比 Ag:Ti₃SiC₂=1.000003:1。两相均在 z 方向贯穿至约 198.3 Å，并具有 x/y 周期绕行连续性。初始最近邻距离 2.079 Å（Ti–C），Ag–骨架最小间距 2.293 Å；最近邻小于 1.8 Å 的原子数为 0。此检查仅确认几何，不代表势函数稳定或可直接开展加热。

POD v12f 全体系静态 run 0（不移动原子）结果：Fmax=22.355 eV/Å；Ag 22.355、C 11.436、Si 13.436、Ti 14.889 eV/Å；超过 500 eV/Å 的原子为 0。FIRE 与冷态稳定性测试尚未完成，因此不能据此启动加热。
