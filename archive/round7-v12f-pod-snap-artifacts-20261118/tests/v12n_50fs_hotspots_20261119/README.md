# POD v12n 50 fs 新短接触的定向 DFT 候选（2026-11-19）

从 458,248 原子 POD v12n 无热源冷态运行的累计 50 fs 末态抽取了两个局部环境。原始 LAMMPS dump 标注 step=40，是因为延续计算从重读 data 后重置了步数；该帧在 10 fs 前段之后又积分 40 fs，物理总时长为 50 fs。

| 类型 | 原子 ID | 末态间距 | 局部原子数 | POD 中心力误差 |
|---|---|---:|---:|---|
| Ti–C | 94075 / 99595 | 1.248324 Å | 47 | 待 DFT 标签 |
| C–C | 38346 / 33016 | 1.013862 Å | 37 | 待 DFT 标签 |

两构型都用 5.5 Å 球形局部裁剪，x/y 周期方向按最小镜像展开，嵌入 22 Å 立方真空盒。目标仍是训练候选；验证集及 Si01 留出构型没有改动。

初始数据的全元素对距离审计未发现原子重叠：最短 Ti–C 为 2.079 Å、Ti–Ag 为 2.293 Å、Ag–Ag 为 2.886 Å，详见 `initial_minimum_pair_distances.json`。50 fs 末态的 Ti–C 与 C–C 对都已向外分离，径向相对速度分别为 1.84 和 28.72 Å/ps；它们是瞬时碰撞短接触，不是稳定键。力和速度投影见 `pair_motion_audit.json`。C–C 点已由 GPAW PBE/PW350 Γ 收敛（37 轮）：POD v12n 中心力误差为 42.98 和 41.84 eV/Å，DFT 中心力范数约为 43.27 和 45.95 eV/Å，说明 v12n 在该瞬态距离上斥力偏强。标签文件与日志已随本目录归档。Ti–C 点也已收敛（82 轮）：v12n 对 1.248 Å 碰撞的两个中心力误差为 34.70 和 29.11 eV/Å，斥力不足。现有模型在 C–C 和 Ti–C 两类短程碰撞上分别过强和过弱；两份已收敛标签可用于 v12o 候选拟合。现阶段的 50 fs 温升和短接触说明冷态稳定性未通过，不批准加热。
