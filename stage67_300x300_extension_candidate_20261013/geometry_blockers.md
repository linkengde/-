# Stage67 300×300 Å 几何候选阻塞项

状态：**HOLD — 未生成最终模型。** 本目录只含本阻塞清单和 `extension_method_review.md`。

1. **非整数周期扩展缺少获批规则。** 源横向尺寸为 200×200 Å，目标为 300×300 Å，比例 1.5。坐标拉伸被禁止；整数复制无法直接得到目标尺寸。
2. **直接复制后裁切的周期接缝失败。** 内存诊断的最小最近邻为 0.007150 Å，14 个原子最近邻低于 1 Å；源结构中此类原子为 0。该方法不能用于模型。
3. **100 Å 象限不是已验证的平移基元。** step1650 的坐标来自演化后结构，来源包没有提供可证明能重现该帧的 100 Å 基元或边界缝合过程。禁止改用 Stage65、Stage63 或其他阶段模型替代。
4. **接缝重建的可接受误差未定义。** 若只在新增 Y/Z 区域合成/补入原子，仍需确定物质来源、各元素原子数、原子 ID 规则、边界相位与验收阈值；不能由我猜测。
5. **目标 TTM 场缺失。** `15×30×30` 网格需要 13,500 个 cell 的映射。旧 `15×20×20` 数据不能直接复用；新 `cell_material_fraction`、`G_mix`、`Te/Tl` 与热源分布均未生成。没有可运行 TTM/长时间模拟输入。
6. **势函数仍有未解决的物理资格限制。** 交接包中的交叉势为 `calibration-v0`，尚未生产级验证；此事不属于本次几何检查，且未被修改。

## 恢复所需的用户决定或材料
