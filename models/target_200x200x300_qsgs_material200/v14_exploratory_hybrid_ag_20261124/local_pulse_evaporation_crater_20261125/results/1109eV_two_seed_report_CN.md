# Ag 表层局部脉冲 1.109 keV 双随机种子试算报告

日期：2026-11-25

## 模拟条件

- 两次均从同一个 Q6/PTM/MSD 1.700 ps 快照独立启动；总原子数458,248，Ag 106,396。
- 脉冲中心(100,100,203) Å，横向高斯σ=12 Å，向内指数衰减深度6 Å。
- 实际新增Ag动能各为1109.4369719 eV（约为此前739.6246479 eV的1.5倍）；seed为20261131和20261132。速度增量零净动量，具体速度在prepared快照中。
- NVE，步长0.25 fs，运行2.0 ps；盒子xy周期、z非周期并扩到500 Å；底部Ag反射墙。
- Ag-Ag 使用Ag_u3.eam；Ti/Si/C完全固定；Ag-骨架使用既有WCA/LJ交叉项。没有TTM、恒温器或持续激光热源。

## 结果

| 项目 | seed 20261131 | seed 20261132 |
|---|---:|---:|
| 总能量波动范围 | 0.10 eV | 0.11 eV |
| 末时全Ag温度 / 热点温度 | 2382 / 3944 K | 2381 / 3969 K |
| 末时Fmax | 17.86 eV/Å | 14.32 eV/Å |
| 中心r<20 Å、180≤z<220 Å Ag数 | 573→362 | 573→363 |
| 初始中心/环带表面q50 | 201.96 / 200.84 Å | 201.96 / 200.84 Å |
| 末态中心/环带表面q50 | 212.53 / 210.31 Å | 208.56 / 207.52 Å |
| 末态中心相对环带高度 | +2.22 Å | +1.04 Å |
| 热源区轨迹峰值z>250 Å同时原子数 | 5 | 4 |
| 末态全场z>250 Å原子数 | 19 | 18 |
| 原子总数变化 | 0 | 0 |

两个种子均未形成中心低于环带的可见表面凹陷。中心计数下降约37%，可由 Ag 向真空、横向或骨架孔隙迁移共同造成，不能全部解释为蒸发。结果支持“局部上层稀疏、少量喷出”，但不支持“已经形成可重复熔坑”。
