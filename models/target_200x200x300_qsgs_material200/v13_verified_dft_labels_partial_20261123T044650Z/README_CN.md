## 通过审计的含义

审计确认 DFT SCF 收敛、能量和力为有限值、标签原子数正确，并确认标签对应冻结的结构文件哈希。它不等于 PW 截断能、k 点或电子展宽已经完成系统收敛验证。当前参数属于探索性标注设置，详情见 `verified_labels_manifest.json`。

验证集目录中的结构和标签是独立验证用途，**不得并入拟合训练集**。本快照只保存数据与协议记录；截至快照时间，POD 拟合尚未开始。

每个构型目录包含原始几何、带能量/力的 extxyz 标签、GPAW 标签 JSON 和 SCF 日志。`procedures/` 保存本轮执行时的 DFT 运行及审计脚本。`SHA256SUMS.txt` 可用于校验归档完整性。
