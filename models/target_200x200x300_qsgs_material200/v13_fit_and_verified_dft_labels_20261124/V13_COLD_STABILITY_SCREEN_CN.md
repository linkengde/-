# V13 POD 小体系无热源稳定性筛查

日期：2026-11-24（UTC）

## 结论

V13 已完成拟合，但**没有通过小体系稳定性筛查**，目前不能用于长时间加热或冷却。筛查是探索性短跑，目的是排除明显失稳；失败说明模型组合不合格，不足以单独确定微观根因。

## 结果

| 结构 | 设置 | 结果 |
|---|---|---|
| Ag 固态，32 原子 | 300 K，NVE，1 fs，0.1 ps | 保持全部原子；总能漂移 `1.99×10⁻⁷ eV/atom`；温度升至 501 K，需结合初始结构热扰动理解 |
| 液态 Ag，32 原子 | 1300 K，NVE，1 fs，0.1 ps | 温度升到 4066 K；最近距离由 2.435 Å 降到 1.237 Å；能量漂移 `3.48×10⁻⁵ eV/atom`；严重结构塌陷 |
| Ti₃SiC₂，48 原子 | 300 K，NVE，1 fs | 约 0.098 ps 从 48 个原子丢到 46 个 |
| Ag/Ti₃SiC₂ 界面，64 原子 | 900 K，NVE，1 fs | 约 0.034 ps 丢原子（64→51） |
| Ag-rich Si，64 原子 | 1100 K，NVE，1 fs | 约 0.043 ps 丢原子（64→44） |

单独对 Ti₃SiC₂ 训练构型做步长敏感性检查：用 0.1 fs 跑到 0.09 ps 前，总能仍约为 `−381.466 eV`；之后力和动能迅速增长。到 0.1 ps 温度约 `4.64×10⁸ K`、总能约 `2.82×10⁶ eV`、最大力约 `1.14×10⁴ eV/Å`。降低步长不能消除该构型的失稳。

## 判断

- Ag 固态短跑表现稳定，但一个相态通过不足以证明四元势可用。
- 液态 Ag、MAX 骨架、界面和 Ag-rich Si 均未通过。当前 V13 不能用于长时热循环。
- Ag 液态和 Ti₃SiC₂ 在塌陷前的总能漂移较小；局部势能面使结构向非物理塌缩演化的可能性高于单纯的积分能量误差。仍需针对性分析局部原子对和力方向后确定根因。
- 训练数据与六帧验证集拟合误差不能替代动力学稳定性验证。

日志、输入、终态和汇总保存在同目录 `small_cold_screen_v13/`。测试用的是拟合副本，没有改动原始几何、DFT 标签或势系数。
