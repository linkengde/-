# 150³–300³几何分辨率检查

## 范围

本轮保留既有150³模型，并另外生成200³、300³的QSGS体素几何；每个网格使用种子1105、1136、1182。Ti₃SiC₂保持30 vol%，Ag保持70 vol%。两种物理RVE（10 μm超细组织、200 μm微米组织）由同一二值结构按比例映射，所以表中的超细组织长度乘20即为微米组织的对应长度。

细化时按体素体积换算成核概率：`P0_N = 1 - (1 - P0_150)^((150/N)^3)`；按网格线性尺度换算生长概率：`Pxyz_N = 1 - (1 - Pxyz_150)^(150/N)`；高斯相关滤波宽度按 `σ_N = 4N/150` 格设置。这样固定的是名义物理相关尺度和预期成核密度，不是逐体素相同的随机组织。200³和300³数据存放在 `geometries/`，生成参数及耗时记录在 `geometry_generation/generation_summary.json`。

## 汇总结果

下表是超细RVE中三个随机种子的均值；厚度和通道统计先对每个种子独立计算，再取均值。微米RVE的长度值为表中数字的20倍，界面面积密度则为1/20。

| 网格 | Ti₃SiC₂内接球直径 P10 / P50 / P90（μm） | Ag沿X弦长 P10 / P50 / P90（μm） | 界面面积密度（10⁶ m²/m³） | 骨架最大连通分量范围 | 两相XYZ贯通 |
| ---: | ---: | ---: | ---: | ---: | --- |
| 150³ | 0.288 / 0.544 / 0.829 | 0.400 / 1.244 / 3.400 | 2.129 | 99.544–99.603% | 3/3种子 |
| 200³ | 0.300 / 0.548 / 0.814 | 0.400 / 1.233 / 3.383 | 2.104 | 98.334–99.249% | 3/3种子 |
| 300³ | 0.275 / 0.536 / 0.815 | 0.389 / 1.211 / 3.433 | 2.103 | 97.742–99.132% | 3/3种子 |

骨架P50在三种网格间变化约2%以内，P90变化约2%以内，界面面积密度变化约1.2%以内；Ag弦长统计也相近。这支持当前几何生成在主体尺度统计上的可比性。它不是热传导或FVM网格收敛证据。

## 连通性和细颈限制

两相在200³与300³的所有种子中均沿X、Y、Z贯通。不过骨架最大连通分量没有达到既有150³基线的最低值99.54%：200³为98.334–99.249%，300³为97.742–99.132%。因此只能判定“贯通”，不能判定严格连通性验收通过。Ag相最大分量均≥99.994%。当前候选参数需要继续校准；在校准后的多种子结果达到同一门槛前，不把连通性列为通过。

所有网格的主骨架最小局部内接球直径仍为2个体素。换算到10 μm超细RVE分别为0.133、0.100、0.067 μm；换算到200 μm微米RVE分别为2.667、2.000、1.333 μm。此局部极值随网格变化，且该统计不是严格的连接颈宽度测量；局部最细结构仍未证明被充分解析。正式热流和熔化分析前，应先处理细颈几何和连通性，并做数值网格收敛。

## 当前判定

- **几何候选生成：GO（用于主体形态统计对照）**：三种网格精确保持70/30体积分数，主结构尺度和界面密度相近，两相都有三轴贯通分量。
- **连通性门槛：未通过**：200³/300³骨架最大连通比例低于既有150³最低值99.54%。
- **细颈解析：NO-GO（定量局部热流/熔池用途）**：最小局部球径仍只有2格，且物理最小值随网格变化。
- **热求解和相变验证：未执行**：本目录只包含几何生成与审计；未运行FVM传热、熔化、流动或凝固。
