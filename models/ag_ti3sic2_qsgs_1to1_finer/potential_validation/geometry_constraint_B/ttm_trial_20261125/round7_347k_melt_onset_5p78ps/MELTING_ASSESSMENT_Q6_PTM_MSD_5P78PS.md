# 347,464 原子 TTM 加热：5.78 ps 局部 Ag 熔化判读

## 结论

**热源区 Ag 呈持续的液态样局部熔化/强烈无序迁移，Q₆、PTM、去漂移 MSD 三项指标一致。** 最清楚的判据出现在 5.0–5.5 ps：q̄₆ 中位数维持 0.235，PTM 不再识别 FCC/HCP，热区去整体平移 MSD 从 8.851 增至 10.168 Å²，RMS 位移为 3.189 Å，约一个 Ag 最近邻距离。

这只支持预先定义热源区的**局部液态样状态**，不代表 80,674 个 Ag 原子整体熔化，也不证明块体 Ag 熔点。全运动 Ag 温度约 1,107 K、热源加权晶格温度约 1,121 K，低于块体 Ag 熔点附近；该尺寸与高界面结构可能发生低于块体熔点的局部失序。初始构型未弛豫，且热区初始 PTM-FCC 只有 7.70%，所以结论限于探索性结构判读。

## 稳定性和能量记录

- 请求 8 ps；在全部液态样指标持续后，于 5.78 ps 主动发 SIGINT 停止，不继续过热。
- 末次记录：step 11,560，运行约 2,013.5 s；最近已保存完整原子帧为 5.5 ps。
- 累积源能量 19,686.50 eV；电子到晶格转移 6,719.23 eV；能量账本残差 0.0511 eV。
- 移动 Ag 的记录峰值力 13.03 eV/Å，低于 50 eV/Å 安全中止线；未出现力值 runaway 或原子丢失。
- 最近邻距离有短程压缩：初态 Ag–Ag 最短 2.885 Å；5.5 ps 最短 2.220 Å，1% 分位 2.400 Å，811 个 Ag 的最近邻小于 2.4 Å。这不是灾难性塌缩，但属于需要在后续模型/热应力解释中保留的风险信号。

## 物理模型边界

Ag–Ag 使用 Foiles Ag EAM。Ti/Si/C 骨架完全固定，仅作理想刚性几何支撑，不振动也不导热；Ag–骨架用 WCA 排斥边界，没有真实黏附或化学界面。TTM 是 Python 参考实现，不是生产级 LAMMPS 原生 `fix ttm`。因此结果用于探索局部 Ag 结构是否液态样，不可作为完整 Ag/Ti₃SiC₂ 触头真实熔池的定量预测。
