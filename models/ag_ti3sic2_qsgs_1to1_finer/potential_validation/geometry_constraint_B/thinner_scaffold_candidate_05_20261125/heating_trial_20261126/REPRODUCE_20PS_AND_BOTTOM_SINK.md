# 重现：20 ps Ag 加热与底部理想热沉冷却

以下命令在 `heating_trial_20261126` 目录执行。模型和输入文件位于同一候选 05 仓库路径。

## 运行到 20 ps

```bash
bash run_heating_3ps_to_20ps.sh
```

脚本从已保存的 `continued_2p5_to_3p0ps` 配对检查点继续，保持 0.5 fs 步长和原 XY 圆对称高斯 × z 向指数衰减热源，每 0.5 ps 写一份原子/TTM 配对检查点。完成后得到 `continued_19p5_to_20p0ps`。

## 从 20 ps 关闭热源并冷却 0.6 ps

```bash
bash run_ideal_sink_cooling_20ps_to_20p6ps.sh
```

热源在冷却脚本中关闭；z≤50 Å 内有 Ag 的电子网格单元钳制为 300 K。TTM–晶格交换按 5 个子步执行，并以每个网格单元相连 Ag 原子的现有动能限制抽热，避免负动能。将 z 上界扩至 500 Å 是为了保留飞出原始 300 Å 盒子的 Ag；原子坐标不做重映射。

## 结果与数值审查

- 本次运行终点：加热 20.0 ps、冷却 20.6 ps。
- 加热总输入约 59,723.98 eV；冷却结束累计热沉移除约 22,056.10 eV。
- 冷却结束能量账本残差约 0.622 eV；累计 Fmax 为 49.221 eV/Å。
- 冷却结束原子数 276,658；本轮新增文件与最终检查点的 SHA-256 收录在 `SHA256SUMS_20PS.txt`。
- 该理想热沉只钳制 Ag 的 TTM 电子网格。Ti₃SiC₂ 原子坐标固定，不能据此声称骨架发生了晶格振动导热；该模型也不是四元素物理界面势。
