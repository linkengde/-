# Ag 横向高斯 × 深度指数热源：静态预检

日期：2026-10-24。此记录只核对热源参数包和当前几何，不包含 TTM 或 MD 运行。

参数来源为用户上传的 `Ag_TTM_processed_20261024.zip`，SHA-256：`1b5d18a5934e4678d345df032fc04c3c617abd21ead66691b22b5ab037473e38`。包内处理报告、配置和生成的剖面表彼此一致。

## 候选热源

当前选择的空间分布是横向高斯乘深度指数，而非三向高斯：

```text
q_e(x,y,z,t) = f_Ag(x,y,z) * (I0/l_skin)
               * exp(-((x-x0)^2+(y-y0)^2)/R^2)
               * exp(-(z_surface-z)/l_skin) * S(t)
```

| 参数 | 候选值 | 定义/状态 |
|---|---:|---|
| `I0` | 5 eV/(ps·Å²) | 暂按中心处峰值表面能流解释 |
| `R` | 30 Å | `1/e` 特征半径；等效标准差 `sigma=R/√2=21.213 Å`，不是硬截断半径 |
| `l_skin` | 20 Å | 深度指数衰减长度 |
| `q0=I0/l_skin` | 0.25 eV/(ps·Å³) | 中心、表面处的体积源项幅值 |
| `S(t)` | 自适应开关 | Ag 稳定熔池和骨架稳定条件均满足后关热；总观察时长100 ps，不固定加热10 ps |

`f_Ag` 应表示电子网格中 Ag 的体积分数/掩码。上传包没有当前模型的电子网格或 Ag 掩码，因此包内 CSV 仅是连续源项剖面，尚未给出实际沉积到本模型 Ag 相的功率。

## 连续积分核对

在横向无限、深度半无限近似且保持峰值通量 `I0` 时，解析总功率为：

```text
P = I0 * π * R² = 14137.16694 eV/ps
```

按当前材料厚度 `L=158.6115 Å` 截断深度后为 `14132.08350 eV/ps`，比半无限结果低约0.036%。如果仅作对照并固定加热10 ps，总能量会是141,321 eV（有限厚度）；这只是校核值，不代表当前自适应关热方案的目标能量。半径R内包含横向总功率的63.21%，深度 `l_skin` 内包含指数沉积能量的63.21%。

这些是连续体、未乘 Ag 掩码的解析数值。正式实现必须对实际网格求和：`P_grid=Σ_j f_Ag,j q_j V_j`，并分别报告掩码前后总功率。保持 `I0` 峰值通量不变时，不应在乘 Ag 掩码后再将总功率强行归一化，否则会改变热源物理含义。

## 与当前几何的坐标对应

仓库模型材料范围为 `z=0–158.6115 Å`，模拟盒高度258.6115 Å，顶部真空100 Å；Ag 原子最高z约157.465 Å，骨架原子最高z约157.339 Å。此前项目笔记中的 `z_surface=150 Å` 比材料上边界低8.6115 Å；若把它当表面，名义表面源强只剩 `exp(-8.6115/20)=0.6501`。对当前模型暂以几何材料上边界 `158.6115 Å` 作为 `z_surface` 候选，并在离散网格中核对真实表面单元；不把真空单元当作有热容或 Ag 电子的材料网格。

横向中心暂置于盒中心 `(149.8175, 150.9287) Å`。横向周期盒半宽约150 Å，是R的5倍，高斯在周期边界处权重约 `1.4×10⁻¹¹`，边界尾项可忽略；垂直方向仍为自由表面边界。

## 参数和实现限制

- `Ce(Te)`、`G(Te)`、`ke(Te)` 是跨论文近似读图拟合的探索性候选，不是已验证的生产级、自洽 Ag 参数集；温度范围仅300–20,000 K，超界应停止，不能静默外推或夹断。
- 当前候选 `ke` 是 `ke(Te)` 近似，不包含完整 `ke(Te,Tl)`；电子能量更新应使用 `Ue(Te)=∫Ce dTe` 并核对每步能量守恒。
- 当前没有可直接运行的 LAMMPS TTM 实现，能同时兼容 `boundary p p f`、横向高斯×深度指数、Ag 相掩码和 Ag-only 电子—晶格交换。参考 `fix ttm/mod` 不满足这些条件。
- 需要另行定义电子网格尺寸/单元体积、Ag 体积分数、真空/自由表面电子边界，以及固定层/恒温层/牛顿层中哪些 Ag 原子参与电子—晶格交换；恒温浴和 TTM 耦合不能重复作用于同一原子。
- 即使完成热源离散化，也不能绕过冷态门槛：当前 K=100 冷态续跑显示 Ag 与骨架显著分离，且现有力筛查没有达到<1 eV/Å目标；目前不运行实际加热。

正式热源编码前的无MD验收项：连续剖面积分与解析值一致；有限盒和实际网格求和与预期截断值一致；Ag 掩码后的功率单独报告而不重归一化；单电子单元升温测试满足 `ΔUe=Ce` 积分；电子—晶格交换在每步等量反向；并验证无 `Ce≤0`、非单调 `Ue` 或温度越界。
