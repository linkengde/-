# Case A 3×3 横向周期域有限尺寸验证

日期：2026-10-27。该算例沿 x、y 方向各重复原生 QSGS 单胞 3 次，只在中央单胞施加原高斯热源。计算使用独立目录和 `codex/single-temperature-study` 分支；原双温求解器、分支及检查点均未改动。

## 模型与预检

- 原几何输入为 `qsgs_morphology.npz`，SHA-256：`7e0e1509b414597ce4e2a1c9fc387ed9656caf507f1186e2d28de79c3c1bfc43`。3×3 网格 `300×300×50` 是原始 `100×100×50` 掩膜的精确横向重复，未生成新 QSGS 结构；网格间距为 `(2.99635, 3.01857, 3.17223) Å`。
- 沿用 Case A：Ag 真实六邻面导热；Ti₃SiC₂ 骨架为零热容、零导热绝热极限；x/y 周期，z 绝热。峰值热流 `8.01088317×10¹³ W/m²`、横向高斯半径 `30 Å`、吸收深度 `20 Å`，对原始 Ag 体素解析积分，热源只落在中央单胞。
- 3×3 总热源功率为 `0.886217924228131 mW`，中央单胞为 `0.886217924225677 mW`；中央以外占总功率 `2.77×10⁻¹²`。中央源图相对原单胞的 L1 差为 `4.82×10⁻¹⁵`。原生步长上限保持 `0.0404211 fs`。
- 光滑温度场上的积分扩散功率相对能量残差为 `2.87×10⁻¹⁹`。预检短时加热能量误差：单胞 `4.62×10⁻³³ J`、3×3 域 `−6.93×10⁻³³ J`。5 fs 预检实测 3×3 用时约为单胞的 `13.2` 倍；该数仅代表预检硬件与短算例。

在 0.2–0.6 ps 的测试区间内，中央单胞峰温、Ag 液相分数、`f_l≥0.5` 团簇掩膜、体积、位置和主团簇持续时间与原单胞结果高度一致。0.6 ps 最大质心偏移约 `0.065 Å`，小于一个原生网格间距；两者液态阈值掩膜的交并比为 1.0。中央液态区横向尺寸约从 `24×27 Å` 增至 `51×54 Å`，未接近约 `300×300 Å` 的单胞横向边界。

整个中央单胞温度场则会逐渐显示有限尺寸差异：Ag 加权温差 L1（以单胞升温场 L1 归一化）从 0.2 ps 的 `0.27%` 增至 0.6 ps 的 `4.44%`。0.6 ps 最大局部温差为 `17.93 K`，位于距热源约 `156 Å` 的中央单胞边缘位置；热源半径 50 Å 内的最大温差仅 `0.975 K`，100 Å 内为 `4.12 K`。液相分数字段的相对 L1 差为 `0.0116%`，阈值液态掩膜仍完全重合。差异随时间增加且集中在远离热点的边缘扩散尾部，符合 1×1 周期单胞较早接入相邻热源影像、3×3 中央单胞距重复热源更远的边界影响；没有通过调整源或物性去拟合。故本轮支持“局部熔池指标对横向尺寸不敏感至 0.6 ps”，但不能称中央全温度场已完全收敛，也不构成空间网格收敛证明。

3×3 全域 Ag 液相分数以九个单胞的 Ag 体积为分母，不能直接与上述中央值混比。例如 0.6 ps 的中央值为 `2.46829×10⁻³`，全域值为 `2.74254×10⁻⁴`；差异主要来自全域归一化分母增加九倍。全域液态团簇体积与中央主团簇体积也分别报告在 `tile3_comparison.json`。

## 关热与凝固

两支路分别从 0.5 ps、0.6 ps 的 3×3 加热检查点重启并关掉外部热源，保留 Ag 内部导热、焓法相变和绝热边界。采样步距为 0.01 ps；完整检查点每 0.05 ps 保存一次。凝固时间按全域 Ag 液相分数首次为零定义，另单独记录 `f_l≥0.5` 团簇消失。

| ---: | ---: | ---: | ---: | ---: | ---: | --- |
| 0.5 | 12940.0424 | 0.0021708592 | 1.42555×10⁻¹⁷ | 0.86 ps | 0.36 ps | 注入 `4.43109×10⁻¹⁶ J`；全程最大绝对误差 `3.88×10⁻²⁹ J` |
| 0.6 | 14661.5558 | 0.0024682904 | 1.62086×10⁻¹⁷ | 1.00 ps | 0.40 ps | 注入 `5.31731×10⁻¹⁶ J`；全冷却段最大绝对误差 `7.12×10⁻²⁹ J` |

0.5 ps 支路在 0.855 ps 仍有极小非零液相分数 `2.48×10⁻⁸`，但无 `f_l≥0.5` 连通团簇；在 0.86 ps 液相分数和潜热均为零。之后继续至 1.00 ps 未见液相重现。0.6 ps 支路在 0.99 ps 尚有 `4.15×10⁻⁷` 的 Ag 液相分数，1.00 ps 首次为零；至 1.20 ps 仍无液相，最终峰温为 `546.01 K`，全域能量闭合误差为 `7.12×10⁻²⁹ J`（相对注入能量 `1.34×10⁻¹³`）。

0.5 ps 关热支路的最大液态连通组件随冷却缩小并碎裂：总时刻 0.50、0.60、0.70、0.80、0.85 ps 的最大组件体积依次约为 `12940`、`10329`、`5365`、`143`、`28.7 Å³`；0.86 ps 后不再检出液相。最大组件在分裂时会换用新 track ID，因此这些体积是逐帧最大组件，而不是把不同子团簇假装成同一实体；完整父子关系见 `.clusters.csv` 和机器可读汇总。

0.6 ps 支路总时刻 0.60、0.70、0.80、0.90 ps 的最大组件体积约为 `14662`、`11592`、`7489`、`2152 Å³`，到 1.00 ps 全固态。主线 ID 1 连续记录到 0.80 ps（累计 `0.624 ps`），随后最大组件由分裂子团簇接替；这表示液态连通形态在缩小/分裂，并不意味着同一尺寸的池稳定维持。

在 0.01 ps 输出采样精度内，两条 3×3 支路的首次全固态时刻分别与原单胞结果的 0.86 ps、1.00 ps 一致。该一致性只说明本组绝热候选模型下的有限横向周期尺寸影响很小，不代表真实材料外部散热或凝固动力学已验证。

在两个关热瞬间，主团簇连续时长分别约为 `0.324 ps` 和 `0.424 ps`：均通过用户指定的暂定 0.3 ps 筛查，均尚未达到 0.5 ps 增强筛查。关热后的追踪显示，0.5 ps 支路全程最长单一 track 为 `0.494 ps`（主组件身份期 `0.474 ps`），未到 0.5 ps；0.6 ps 支路的原主 track 在冷却缩小过程中延续到总时刻 0.80 ps，最长单轨迹 `0.634 ps`（仍为最大组件 `0.624 ps`），跨过暂定 0.5 ps 门槛。与此同时，该主组件体积从关热时 `14662 Å³` 降到 0.80 ps 的 `7489 Å³`，之后碎裂并于 1.00 ps 完全消失。这只说明 0.6 ps 支路里同一连通液态谱系在冷却期间持续可追踪，不能单凭时长称作热学稳定熔池。

因此更准确的结论是：本模型形成了可追踪、会缩小并凝固的局部连通液态 Ag 区域；0.6 ps 支路达到用户设定的 0.5 ps 连续性筛查，但该时长包含关热冷却段，且期间团簇明显收缩。尚未证明稳态或真实物理意义上的稳定熔池。关热后的“凝固”表示当前焓模型中液相分数降为零；绝热边界下潜热转为 Ag 显热并在域内重新分布，不代表向真实环境放热，也不等同真实接触焊凝固时间。

## 结论与未完成验证

本轮完成了 3×3 周期重复域初始化、中央局部精确源映射、扩散守恒预检、0–0.6 ps 加热以及 0.5/0.6 ps 关热冷却。短时加热中央指标与单胞一致，两个候选关断态在该理想模型中都可以在约 0.36/0.40 ps 后达到全固态。结果尚不能外推到真实 Ag–Ti₃SiC₂ 熔池：骨架没有储热或导热，界面热接触不真实，外边界绝热，材料参数仍待文献溯源，模型也没有熔体流动、表面变形、汽化和真实外部散热。

本算例最大温度 `2264.23 K` 低于所采用的 Ag 常压沸点参考 `2435 K`；这只说明本次数值轨迹没有越过该参考值，不能弥补当前相变模型缺少汽化描述这一限制。

本轮没有做熔化区间的 2× 空间细分，所以不能声称尺寸、寿命或凝固时间已通过网格收敛。按显式稳定步长随网格细化近似按 `Δx²` 缩小估算，三维 2× 细分约需 32 倍于原生单胞的步进工作量；应先完成物性溯源和资源评估，再选代表性短时窗口做空间/时间步联合验证。
