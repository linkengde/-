# P1H 电弧压力载荷与表面响应复核

## 结论

四档算例中的电弧压力确实进入了自由表面法向应力计算。用保存的同一时刻 VOF 场和压力侧场重算 z 向压力合力，与求解器记录值相差不超过 `6.1e-8`（相对值）；所有非零载荷时段的积分 z 向合力均为负，方向为向下。压力幅值提高时，合力和冲量近似按比例增加。

这组结果仍没有形成绝对向下凹陷。共同时间 `t = 0.504856397 ps` 的固定网格快照中，所有压力档位在热源半径 5 nm 范围内都没有低于初始表面的网格列。167 MPa 算例的中心区域相对无压力算例少上移约 `0.0140 nm`，而 5–8 nm 环带平均多上移约 `0.2745 nm`；这表示压力改变了表面响应/材料重分布，但不足以证明已解析出凹坑。关热和凝固后的中心高度指标也仍为负值，即表面相对初始状态仍轻微上凸。

因此，可确认的是“载荷实现及力账本有效、形貌有响应”；尚不能确认“压力形成了永久熔坑”。本复核没有重跑任何加热冷却算例，也没有改变压力档位。

## 载荷独立复核

复核时刻为四组都有快照的 `0.504856397 ps`。根据 P1H 的 z 面压力离散，使用固定网格投影场独立计算：

\[
F_z = \sum_{i,j,k} p_{f,z}\,\frac{f_{i,j,k}-f_{i,j,k-1}}{\Delta x}\,\Delta x^3.
\]

| 压力峰值 | 快照最大有效界面压力 | 有效压力非零网格数 | 独立重算 `Fz` | 求解器 `Fz` | 相对差 | `|Fz|/p0` |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 0 MPa | 0 | 0 | 0 N | 0 N | 0 | 0 nm² |
| 1.8 MPa | 1.7961 MPa | 621 | −6.3314×10⁻¹¹ N | −6.3314×10⁻¹¹ N | 4.84×10⁻⁸ | 35.174 nm² |
| 16.7 MPa | 16.6652 MPa | 622 | −5.8744×10⁻¹⁰ N | −5.8744×10⁻¹⁰ N | 6.01×10⁻⁸ | 35.176 nm² |
| 167 MPa | 166.8054 MPa | 620 | −5.8776×10⁻⁹ N | −5.8776×10⁻⁹ N | 4.74×10⁻⁹ | 35.195 nm² |

三档载荷的等效投影面积基本相同，说明压力场按设定比例缩放，掩膜与离散合力计算一致。完整压力历史中的最大合力分别为 −8.84×10⁻¹¹、−8.20×10⁻¹⁰ 和 −8.21×10⁻⁹ N；对应的 `|Fz|/p0` 约 49.10–49.16 nm²。载荷冲量分别为 −3.62×10⁻²³、−3.36×10⁻²² 和 −3.36×10⁻²¹ N·s。负号表示向下。最大合力晚于最大局部压力出现：压力峰值在早期界面已有液体时达到，而可受力的液态 Ag 外表面面积随后继续增长。

## 等时刻响应

四个场快照在同一时间 `0.504856397 ps` 比较，热源仍工作，网格间距为 `0.301857485 nm`。表面高度由固定网格 VOF 场中每个 x-y 列的最高样品位置提取。位移指标为 `初始高度 − 当前高度`，正值代表向下凹陷，负值代表上移。

| 压力峰值 | 中心 5 nm 区平均位移 | 相对无压力中心变化 | 5–8 nm 环带平均位移 | 相对无压力环带变化 | 向下位移网格列 | 时刻最大速度 | 液态 Ag 体积 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 0 MPa | −0.1292 nm | 0 | −0.0065 nm | 0 | 0 | 38.779 m/s | 78.3100 nm³ |
| 1.8 MPa | −0.1292 nm | 0 | −0.0072 nm | −0.0007 nm | 0 | 38.741 m/s | 78.3100 nm³ |
| 16.7 MPa | −0.1289 nm | +0.00035 nm | −0.0481 nm | −0.0416 nm | 0 | 38.402 m/s | 78.3097 nm³ |
| 167 MPa | −0.1152 nm | +0.0140 nm | −0.2810 nm | −0.2745 nm | 0 | 35.889 m/s | 78.3071 nm³ |

167 MPa 下，中心相对无压力状态略向下、周边环带略向上，但中心仍高于初始位置（位移是负值），并且周边响应约为一个固定网格高度步长。当前固定网格快照能支持“压力驱动了表面/流场响应”的判断，不能支持凹坑深度的收敛定量值。共同时间的液态 Ag 体积差小于约 0.004%，熔池体积未显示明显压力依赖。

## 加热关断与凝固结果

原四档对照给出的热源中心指标在关热与完全凝固后仍全部为负：

| 压力峰值 | 关热中心指标 | 凝固后中心指标 | 最大连通熔池体积 |
| ---: | ---: | ---: | ---: |
| 0 MPa | −0.2269 nm | −0.2479 nm | 175.583 nm³ |
| 1.8 MPa | −0.2269 nm | −0.2465 nm | 177.491 nm³ |
| 16.7 MPa | −0.2273 nm | −0.2476 nm | 177.491 nm³ |
| 167 MPa | −0.2052 nm | −0.2164 nm | 177.486 nm³ |

压力组中心相对无压力算例的最终变化仍小于 `0.105 Δx`，且中心没有低于初始表面。连通熔池体积各档差异约 1.1% 以内且不随压力单调变化；由于各算例关热时间略有差异，这个范围不能归因于压力单一因素。

## 对“为何没有形成熔坑”的回答

1. 不是因为压力没有进入计算：压力侧场、压力掩膜、向下合力和独立积分复核彼此吻合。
2. 压力确实改变了响应；167 MPa 在等时刻使中心相对位移和速度峰值发生变化，但没有把中心推到初始表面以下。
3. 计算中 Ag 总量守恒，也没有蒸发或喷出。若要留下坑，Ag 必须在计算域内向周边重新分配并在冷却时固定；当前结果没有显示足够且可分辨的中心下凹。
4. 当前网格间距约 0.302 nm，而压力导致的净中心响应低于一个网格步长。固定网格投影与表面指标不适合给出更细的坑深结论；同时这一尺度已接近原子间距，连续介质流动结果属于探索性结果。
5. 压力只施加在模型能识别的外露、朝上、液态 Ag/气体界面；内部孔道界面不在这套外部 VOF 表面中。因此不能将结果解释为所有熔池界面都受到了电弧压力。

## 下一步

先保留当前四档结果，不再盲目上调压力。下一项最有区分力的工作是：从同一个已熔化状态建立成对的压力开/关短时机械响应对照，输出中心与环带的二维高度差图、Ag 速度矢量和周边液态 Ag 体积变化；随后用更细的自由表面网格做数值敏感性对照。细化时必须明确材料掩膜如何映射，不能将 0.302 nm 的原始几何伪装成更精细的真实结构。
