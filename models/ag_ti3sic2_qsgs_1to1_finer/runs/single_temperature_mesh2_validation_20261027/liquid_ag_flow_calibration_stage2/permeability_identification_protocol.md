# 独立渗透率识别协议（未执行）

本协议是后续方法设计，不是已经计算的流场，也不把驱动值解释为真实电弧压力。

1. **冻结输入。** 只读加载 SHA256 `03ef47b1dd534b3215cf03f42c8cf7e887dcdfcc185b33bab7453cd838c1faac` 的 Ag70 mask。定义两种几何状态并分开出报告：全部 Ag 视作液体的几何上限；给定热态下实际连通液态 Ag 掩膜。后者需由经验证相场/焓状态导出。
2. **求解器。** 独立有限体积 Stokes/MAC 试验代码，固体表面无穿透；分别用无滑移数值基线及后续实测/MD 校准的 Navier-slip 条件。连续介质资格不过关时，结果仅标记为“体素网络导流敏感性”，不称材料渗透率。
3. **三方向驱动。** x、y 用周期掩膜及周期压降/等效恒定体力；z 用独立诊断夹具压力入口/出口。z 诊断夹具改变第一阶段生产流动边界，仅用于识别 Kzz。若强制套用 z 无穿透生产边界，则测出的 Qz=0 是边界定义结果，不是 Kzz=0 的材料结论。
4. **受控驱动和线性检验。** 每个轴施加正、反方向驱动，并按 `g/2,g,2g` 做数值幅值扫描。`g` 仅为数值识别输入；报告单位压差流量与线性回归/零驱动极限。不能换算成电弧压力、实际流速或预测熔池运动。
5. **计算量。** 记录体积流率 Q、均速、截面通量、压降、压力/速度残差、最大散度、壁面法向通量和质量不平衡；计算 `K_ij = μ <u_i> /(−∂p/∂x_j)`，或用端到端压降写成 `K_ij = μ L_j <u_i>/Δp_j`。必须报告张量主轴及非对角项，不预设各向同性。若 μ 尚未定量校准，只报告几何导流率，待 μ 定标后再转为 K。
6. **网格和代表体积。** 在不改变目标几何哈希的条件下，对同一体素界面做 cut-cell/距离场 1×、2×、4×离散；比较相体积、通量、K、压力残差。再扩展域长或用多个独立 QSGS seed 检验 RVE 收敛。若单纯细化二值 stair-step 会系统性改变界面，须报告该偏差，不能宣称网格收敛。
7. **停止门槛。** K 对测试幅值不线性、对离散网格/RVE 不收敛、质量/能量账本不闭合、或液态连通区在热状态中未形成时，不提供单一 K 张量。需要区分实验/MD 校准、数值离散和几何统计三类误差。

当前阶段没有独立流动求解器，因此没有执行上述压力梯度试验；不得将本文件当作数值结果。
