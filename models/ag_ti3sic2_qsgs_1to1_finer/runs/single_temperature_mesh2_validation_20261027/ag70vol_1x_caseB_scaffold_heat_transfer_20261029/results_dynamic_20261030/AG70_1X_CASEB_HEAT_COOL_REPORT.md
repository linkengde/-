# Ag70 1× Case B 加热—局部熔化—关热凝固结果

## 结果

Ag 70 vol% / Ti₃SiC₂ 30 vol% 的原始 QSGS 几何上，Case B 理想界面、绝热边界单温焓法计算已经完成一个加热—关热—全固态闭环。计算仅证明候选模型下的热传导与相变结果，不代表真实环境散热、熔体流动或动熔焊连接。

- 热源加热期间首次出现 Ag 液相：10.189 ps；首次多体素连通液态团簇：10.255 ps。
- 由于 Ti₃SiC₂ 候选物性表上限为 1473.15 K，下一步试算将越过该范围，因此在最后一个有效检查点 **14.506 ps** 安全停止加热。该检查点仍在物性范围内：Ag 峰温 1472.80 K，Ti₃SiC₂ 峰温 1431.53 K。
- 关热时 Ag 内液相体积分数为 0.332701%。逐段指标显示有 2 个连通团簇，最大团簇 1161 个体素、33.311 nm³。
- 关热时总焓 E_off = 2.250401e-14 J；全 Ag 固态、均处 Ag 熔点时的总焓 E_s = 3.800797e-14 J。E_off < E_s，因此绝热 Case B 的全固态平衡在能量上可行；均匀平衡温度估算为 880.23 K。
- 关闭热源后仅计算了内部热量再分布；Ag 在 **14.666 ps** 全部固化，即关热后约 **0.160 ps**。此时 Ag 峰温 1209.76 K，骨架峰温 1156.31 K。
- 全程能量残差 1.561e-25 J，相对误差 6.937e-12。热源关闭后总焓保持不变，模拟没有向外界散热。

## 验证与续算文件

Case B 单元测试 6 项全部通过；加热末态和全固态冷却末态均用求解器 `load_checkpoint()` 回读，模拟时间、温度、液相场及焓/热源能量账本一致。

## 模型限制

Case B 采用 Ag 与 Ti₃SiC₂ 理想热接触、骨架储热导热、外边界绝热；候选物性尚未完成充分文献溯源。模型没有有限界面热阻、外部热沉、液态 Ag 流动/喷溅、汽化、热膨胀或骨架力学响应。因而“关热后全固态”仅是当前绝热连续介质模型中的相变结果，不是实际触头冷却时间或焊接结论。
