# Reproduce the pinned Basilisk P1b reference run

The recorded run used the CoMPhy Lab `basilisk-C` release snapshot `v2026-07-20`, peeled Git commit `9bb4f30aaf195feaa7a3a613468a1c888f5a4b9e`. This is a downstream-patched snapshot based on the Basilisk/Darcs source, not an untouched upstream snapshot. The Linux archive SHA256 is `4686294e8f649a424ca437a7fa94bfac9984c32bea5e9f33a27a5783cc692829`.

After extracting the archive and building AST/qcc/Tiny GL, set `BASILISK_SRC` to its `src` directory. The official source is archived as `basilisk_marangoni.c` with the source SHA256 in `p1b_source_manifest.json`. The run copy is generated by adding only the event in `stop_event.patch`, which stops the official recurring `adapt` and `logfile` events after the official `t=3*t0` measurement. No physical or numerical method parameter was changed.

```sh
export BASILISK_SRC=/path/to/basilisk/src
export BASILISK="$BASILISK_SRC"
export OPENGLIBS=-lfb_tiny
cp basilisk_marangoni.c marangoni.c
patch -s -p1 < stop_event.patch
"$BASILISK_SRC/qcc" -O2 -Wall -autolink marangoni.c -o marangoni -lm
timeout 900 ./marangoni > official_stdout.log 2> official_stderr.log
```

At this snapshot the prerequisite build sequence used was:

```sh
make -C "$BASILISK_SRC/ast" libast.a
make -C "$BASILISK_SRC" qcc
make -C "$BASILISK_SRC/gl" libglutils.a libfb_tiny.a
```

The 3 runs are built into the reference source: `LEVEL=7,8,9` (8, 16, 32 cells per droplet radius). Basilisk prints the final measured and theoretical `u_drop/U` values to stderr. `fields_Rdx16.png` is the source test's image from the 16-cells-per-radius run.
