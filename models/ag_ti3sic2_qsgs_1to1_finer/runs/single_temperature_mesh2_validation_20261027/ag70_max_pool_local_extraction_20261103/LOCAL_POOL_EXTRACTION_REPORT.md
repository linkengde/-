# Ag70 最大连通熔池：局部结构提取与流动可行性审查

## 结论和来源选择

按用户给出的包围盒尺寸检索到精确匹配的热态检查点：`heating_complete_2300K.npz`，时间 `0.8495860511825916 ps`。保存的最大液相跟踪簇是 track 1 / 当前分量 1，`f_l ≥ 0.5` 的六面连通规则下有 **7,370 个体素**，体积 **211.459 nm³**，周期性坐标展开后的包围盒为 **12.2850 × 11.7724 × 4.1239 nm**。该包围盒不是液体填满的长方体。

有一个必须保留的来源差异：这个与目标尺寸精确吻合的检查点来自 **2026-11-02 新生成的 64×64×50 QSGS 几何**，不是早期 **100×100×50** Ag70 几何。该 100×100×50 的另一套 4× 复合热源算例在 `1.116191744 ps` 的最大团簇为 6,112 个体素，记录的尺寸约 **11.0865 × 11.1687 × 4.4411 nm**。两者不得拼接或互相替代。本次为按尺寸匹配而提取 64×64×50 的数据，原始的两套几何和检查点均未改动。

交叉核对可见所选 run 的 [`RUN_REPORT.md`](../ag70vol_1x_regrown_64x64x50_caseB_4x_composite_sc2300K_20261102/RUN_REPORT.md) 和 [`liquid_clusters.csv`](../ag70vol_1x_regrown_64x64x50_caseB_4x_composite_sc2300K_20261102/liquid_clusters.csv)；早期 100×100×50 比较行来自 [`liquid_clusters.csv`](../ag70vol_1x_caseB_4x_composite_source_sc2300K_20261102/liquid_clusters.csv)。

所选 run 的热源是覆盖 **Ag 与 Ti₃SiC₂ 复合体**的 4× 高斯源，关热事件是骨架达到 2,300 K；热边界为底部 Ag 接触区 300 K 理想热沉，其余 z 面绝热。它不是早期“仅 Ag 加热”的 100×100×50 设置。Ti₃SiC₂ 物性在高温区有外推，模型假设骨架在 2,300 K 仍完整。此处只提取已有热态场，不重算热历史。

## 最大池结构和状态定义

Ag 和 Ti₃SiC₂ 分布来自同一原始 `skeleton` 掩膜；温度、焓和液相分数直接来自同一 checkpoint。为免混淆，报告分别保留“纯相状态”和已有簇追踪规则：

- 完全固态 Ag：`f_l ≤ 1e-12`。
- 固液共存 Ag：`1e-12 < f_l < 1−1e-12`。
- 完全液态 Ag：`f_l ≥ 1−1e-12`。
- 连通熔池识别：Ag 且 `f_l ≥ 0.5`，六面连通，x/y 周期，z 非周期。这个门槛是原运行追踪规则，不等同于“完全液态”。

主簇的原网格索引范围为 x `10–50`、y `12–50`、z `37–49`（上界包含在内）。对应原始域坐标包围范围约 x `2.996–15.281 nm`、y `3.622–15.395 nm`、z `11.737–15.861 nm`；体积加权质心为 `[94.1804, 93.4408, 144.1088] Å`。主簇不跨越 x/y 周期接缝；它触及 z 顶部的原始非周期边界，但不触及 z 底部。

包围盒共有 `41×39×13 = 20,787` 个网格单元，其中 Ti₃SiC₂ 为 6,699、Ag 为 14,088，追踪主簇只占包围盒 **35.45%**。因此包围盒中的其余区域保留了固态 Ag 和骨架，不可填成液体。

按六面相邻计算，主簇与 Ti₃SiC₂ 骨架的体素界面面积估计约 **506.51 nm²**（分别按三种各向异性体素面的面积求和）。这是阶梯状体素面的几何估计，不是原子级表面面积或界面能。

## 流动可行性和边界限制

这次提取确认的是单温连续体焓法网格结构，不是原子坐标：checkpoint 没有 Ag/Ti₃SiC₂ 原子位置、晶面终止或局部原子应力。因此不能把它直接称作“保留真实原子结构的 MD 初态”；若路线 A 需要 MD，仍需另行构造并验证原子级骨架/液态 Ag 界面，那将是一个新原子模型。

主簇是局部连通液态 Ag 体，不跨 x/y 周期接缝，也没有从 z 底部贯通到顶部；它的上表面碰到计算域顶部。现有热模型只给出绝热热边界，不包含流体压力、自由表面或对外出流条件。没有已校准的实际驱动力，不能据此指定速度或预测 Ag 迁移。局部瓶颈约一格宽，且前一阶段的液态 Ag 黏度、Ag/Ti₃SiC₂ 壁面摩擦及滑移仍未校准：当前孔道尺度 NS/Darcy–Brinkman 不适合直接定量；MD 路线也必须先解决跨界面势函数验证。
