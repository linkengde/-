# P1G 焓法与流动能量耦合审计

## 实现路径

隔离的 P1G 原型把温度相关材料焓密度 Hvol 和 Ag 材料标记作为守恒 tracer 对流；之后由 Hvol 反算温度，再进行隐式导热、相变焓和热源更新。材料焓包括 Ag 的显热与潜热、Ti₃SiC₂ 表列焓以及气体显热。骨架材料标记固定，Ag 标记可随流动输运。底部热沉排热量与累计热输入和总焓一起进入能量账本。

这比“先对流温度、再导热”的非守恒分裂更适合当前探索用途。它是单温连续体的混合焓近似，不是原子级 MD 或双温模型。生产焓法求解器没有修改。

## 数值短测

Case A（Marangoni 关闭）和 Case B（开启）均从 300 K 冷启动至 0.01 ps，使用相同 64³ 网格、输入几何、材料物性、热源和边界。两组最高温度为 435.807 K，Ag 液相体积为 0，Ag 标记体积漂移为 0；温度、焓、VOF、速度和压力场逐项完全相同。由于尚无液相，这只能验证开关和冷态路径，不是 Marangoni 动态效果验证。

在 A 组 0.01 ps 检查点上续算至 0.02 ps 后，Ag 体积仍为 4130.42566868 nm³，骨架体积仍为 1784.17049967 nm³，样品 VOF 体积仍为 5914.59616833 nm³。历史中最大 |能量残差|/输入能量 为 2.99×10⁻⁸，最大绝对残差约 4.00×10⁻²⁴ J。短测账本闭合良好。

## 已修复的恢复问题

原恢复路径载入检查点时体积正确，但续算第一步因 CLSVOF 从已红距离化的 level set 重建 VOF，样品体积从 5914.596 降至 5889.661 nm³，热源积分也随之变化。隔离副本新增 P1G 专用 two-phase-clsvof-p1g.h：恢复时跳过仅用于冷启动的 f(d) 重建，保留检查点中的保守 VOF；同时在新输出目录中补写 CSV 表头。修复后的短续算保持体积不变，并成功产生 HDF5 和 CSV。

## 适用性限制

总能量账本闭合不等同于每种材料的局部能量输运都经验证。当前 Hvol 是复合混合焓，并整体随流体速度对流，而 Ti₃SiC₂ 标记固定。高阻力会抑制骨架内速度，但这种处理仍可能把复合焓中的骨架贡献随流动搬运；它不是严格的 Ag 液相焓与固定骨架焓分开输运模型。故结果只用于探索性比较，不能作为定量焊接预测。

加热阈值应控制热源关闭，不能终止之后的冷却阶段。当前这份经过审计的短测程序阈值为 2100 K；实际长算例尚未在该版本下运行。超过阈值后的冷却/凝固行为也未验证。
