# P1P 阶段检查报告

## 结论

**独立通量/守恒内核和隔离 P1M 源项接入检查通过；Ag70 P1P 尚未通过，当前没有运行 Ag70 蒸发算例。** P1M 副本已实现外部气体连通筛选、PLIC 暴露面积、界面温度重构、VOF/Ag/焓同步更新和逸出质量/能量账本。但项目中没有有来源的 Ag `p_sat(T)` 与 `L_v(T)` 数据，因此没有生成可解释为真实 Ag 的蒸发通量或质量损失结果。没有实现 P1Q 反冲压力。

## 已验证内容

运行 `tests/run_kernel_tests.sh`（C99，`-Wall -Wextra -Werror`）得到 37 项内核检查通过，覆盖属性表读取、log(p) 插值、表外拒绝、Hertz–Knudsen 解析通量、分压差归零、参数边界、液态质量上限、能量上限、溢出拒绝、失败更新不改写状态及单元质量/焓闭合；AddressSanitizer 和 UndefinedBehaviorSanitizer 复跑也通过。明细在 `tests/p1p_kernel_validation.csv`。

额外的合成平面界面源项测试覆盖网格 N=8、16、32、64 以及每个固定总时长内 1、2、4 个时间步，共 12 组通过。解析通量质量相对误差最高为 `6.51e-14`，质量残差最高为 `9.41e-14`，能量账本残差最高为 `6.39e-14`；明细在 `tests/p1p_flat_interface_validation.csv`。这是显式标为合成物性的有限体积源项测试，不是 Ag 材料结果，也不等同于完整 CLSVOF 求解器的运行验收。

隔离 P1M/Basilisk 源码副本通过固定版本 qcc 编译检查（`-DP1H_RECT_NZ=76 -DP1H_TOP_OPEN=1 -disable-dimensions -fopenmp -O2 -Wall -autolink`）。随后用 P1M 原始 Ag70 几何输入和合成物性表运行了一步软件 smoke：真实 PLIC 暴露面/气体连通搜索及 P1P 源项执行成功，记录面积 `2.98320138895e-16 m²`、合成通量 `1.55501282076 kg/(m²·s)`、移除质量 `1.25317752386e-30 kg`，质量残差 `-4.58e-13%`。该测试在源项后有意停止，且合成物性不能解释为 Ag 结果。对应日志和 CSV 位于 `tests/solver_smoke/`。

另一个非 smoke-only 的短运行也执行了源项，但随后继承的非线性焓求解从人工 1400 K 初始场出发，经过 81 次迭代仍有 `48.952 K` 更新，在 `0.001818 ps` 停止。失败日志已保留在 `tests/solver_smoke/synthetic_thermal_failure.stderr`。因此，P1P 在完整热—流时间步中的运行验收**未通过/未完成**；这不是 Ag 参数运行，也没有进入后续长算例。

测试所用 `tests/synthetic_property_table.csv` 是**纯合成数值夹具**，只用于代码测试，不代表 Ag 数据，不能用于 Ag70 计算。

## 未验证内容和准入阻塞

1. 还缺有来源、有效温区覆盖实际表面温度的 Ag 饱和蒸气压和汽化焓数据；无此数据不能计算真实 Ag 蒸发。
2. 目前只完成单步的源项软件 smoke，完整 Basilisk 时间步在人工高温初态下未通过继承的非线性焓求解；移动界面下的空间守恒、完整时间步耦合和网格收敛验收仍未完成。
3. Ag 暴露面积以复合 VOF PLIC 面积乘局部 Ag 覆盖率和液相率估算；真实 Ag 微表面未独立解析，内部孔道气相输运未建模。
4. 尚无 Ag 蒸气分压 `p_Ag,v` 的实际气氛数据。`p_Ag,v=0` 只代表自由蒸发上限情景。
5. `alpha_ev` 缺少特定系统的校准值；可做标明假设的敏感性范围，但不能称为实测值。
6. 因而 P1P 尚未达到 Ag70 算例准入，不能用当前结果判断熔坑形成。P1Q 仍未实现。

## 继续计算所需资料

下一步需要有来源的 Ag `temperature_K,p_sat_Pa,L_v_J_kg` 表（或关联式及其有效温区、单位和不确定度），覆盖目标算例的表面温度。另需给出 Ag 蒸气分压；若只有 `p_Ag,v=0`，只能标作自由蒸发上限。数据到位后再运行完整 P1P 的静态界面、时间/网格、质量/能量验收和短时 Ag70 算例，通过后才进入 P1Q。
