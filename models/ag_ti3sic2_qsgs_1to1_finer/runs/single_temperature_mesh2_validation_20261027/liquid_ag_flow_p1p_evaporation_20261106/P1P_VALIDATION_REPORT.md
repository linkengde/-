# P1P 阶段检查报告

## 结论

**独立蒸发数学内核测试通过；Ag70 P1P 尚未通过，当前没有运行 Ag70 蒸发算例。** 没有真实 `p_sat(T)` 和 `L_v(T)` 数据，也没有将守恒界面质量移除和焓更新接入 P1M，因此没有生成可解释为真实 Ag 的蒸发通量或质量损失结果。没有实现 P1Q 反冲压力。

## 已验证内容

运行 `tests/run_kernel_tests.sh`（C99，`-Wall -Wextra -Werror`）得到 16 项通过：属性表读取、log(p) 插值、汽化焓插值、表外温度拒绝、Hertz–Knudsen 解析值、零/负分压差归零、非法蒸发系数拒绝、单步质量上限、潜热乘积、质量账本代数闭合和恒定通量下的时间步减半一致性。逐项记录在 `tests/p1p_kernel_validation.csv`。

测试所用 `tests/synthetic_property_table.csv` 是**纯合成数值夹具**，只用于代码测试，不代表 Ag 数据，不能用于 Ag70 计算。

## 未验证内容和准入阻塞

1. 项目目录中未找到可追溯的 Ag 饱和蒸气压温度表或关联式，也未找到可直接用于该温度段的 Ag 汽化焓温度表。没有物性表时不能算真实蒸发通量。
2. 尚未从 P1M 的 `f`/Ag 标记构造外露 Ag–气相 PLIC 面积；未实现气体连通筛选、界面温度重构或组分质量移除。
3. 尚未同步更新凝聚相 VOF、Ag 组分和焓场，因此“仅从 Ag tracer 扣质量”的错误路径没有被实现。
4. 尚无 Ag 蒸气分压 `p_Ag,v` 的实际气氛数据。`p_Ag,v=0` 只代表自由蒸发上限情景。
5. `alpha_ev` 缺少特定系统的校准值；可做标明假设的敏感性范围，但不能将其说成实测。
6. P1P 尚未完成界面移动、空间守恒、能量平衡、网格敏感性和时间步敏感性测试，因此还不能用 P1P 输出熔坑结果。
