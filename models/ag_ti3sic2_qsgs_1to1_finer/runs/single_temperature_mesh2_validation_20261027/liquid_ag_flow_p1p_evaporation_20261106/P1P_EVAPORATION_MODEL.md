# P1P 纳米尺度 Ag 蒸发模块：接口与边界定义

## 当前实现

本分支新增了独立 Hertz–Knudsen 数学内核 `p1p_evaporation.h`。它支持有来源的温度表、禁止超表外推、单向蒸发通量、单步可用液态 Ag 质量上限，以及潜热账目。P1P 不包含反冲压力；反冲仍属于后续 P1Q。

质量通量采用

\[
J=\alpha_{ev}\frac{\max(0,p_{sat}(T_s)-p_{Ag,v})}
{\sqrt{2\pi R_{Ag}T_s}},
\]

单位为 kg m⁻² s⁻¹。局部步长质量移除为

\[
\Delta m=\min(JA\Delta t,m_{Ag,liq,available}),
\qquad E_{latent}=\Delta m L_v(T_s).
\]

`p1p_evaporation.h` 的属性表输入格式为 `temperature_K,p_sat_Pa,L_v_J_kg`。饱和蒸气压在 log(p)-T 空间作分段线性插值，汽化焓作线性插值；温度超出表格范围时返回错误并停止调用，不外推。

## 与现有 P1M 自由表面的对应

P1M 使用 `P1H_TOP_OPEN=1` 的开放环境压力顶面。CLSVOF `f` 表示复合凝聚样品与外部气体的界面；Ag、Ti₃SiC₂ 和孔隙标记是其内部组分。当前几何没有把骨架内部孔道逐个表示成气相自由表面。因此，首版集成若继续使用该求解器，只能处理与上方外部气体相接的 Ag 表面；不能把 Ag/Ti₃SiC₂ 接触面、被骨架遮挡区域或未表示的内部孔道计入蒸发面积。

界面单元需同时满足 CLSVOF 外界面、Ag 覆盖率和液相率条件。面积应由同一个 VOF 重构得到，不能用整个格子面面积代替 PLIC 界面面积。现有代码尚未实现此面积和连续 Ag 组分移除。

## 下一步必须完成的耦合

1. 以 VOF/PLIC 界面法向和界面平面面积找出外部气体连通的 Ag 液面，并重构界面温度。
2. 从有来源的 Ag `p_sat(T)`、`L_v(T)` 表取值；环境 Ag 蒸气分压和蒸发系数作为独立输入。
3. 用一个守恒通量同步减少液态 Ag 组分和总凝聚相 VOF 体积，不允许只减 Ag tracer；每步不得超过可用液态 Ag 质量。
4. 在焓更新中一致地移除离开单元的液态 Ag 焓，并另扣汽化焓差。只有这样才可避免把质量移除与 `J L_v` 重复或漏记。
5. 以 `M_Ag,0 = M_Ag,condensed + M_Ag,escaped` 审计质量；总能量账本计入逸出蒸气携带的焓，并与域内焓变化核对。
6. 完成 VOF 平面界面移动、解析通量、零分压差、步长/网格敏感性、质量和能量平衡测试后，再对现有 Ag70 热场做短时 P1P 测试。

目前以上耦合尚未实现；本文件不代表 Ag70 已经在计算蒸发。

## 参数状态

- `p_sat(T)`：尚无项目提供的 Ag 来源数据表。
- `L_v(T)`：尚无项目提供的 Ag 来源数据表。
- `alpha_ev`：可在来源不足时作为探索性敏感性参数，但必须逐档标记，不得称为实验标定。
- `p_Ag,v`：未给出。零分压仅可作为自由蒸发上限情景，不能称为实际保护气氛工况。
- Kelvin 曲率修正：保持关闭。
- 反冲压力：未实现，也未启用。

## 科学范围

0.302 nm 左右的离散网格不解析气相边界层或 Knudsen 层。Hertz–Knudsen 在这里仅作为 Ag 外露界面的分子动理学边界通量；自由面面积、热边界层和孔道蒸气回流仍然是模型近似。本 P1P 工作只作探索性验证，不作真实电弧蒸发量的定量结论。
