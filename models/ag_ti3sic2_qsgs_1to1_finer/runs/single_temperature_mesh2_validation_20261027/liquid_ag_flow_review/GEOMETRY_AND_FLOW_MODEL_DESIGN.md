# Ag70 液态 Ag 内部流动：几何审查与独立模块设计（阶段一）

## 范围与结论

本阶段只读审查现有 Ag70 QSGS 二值几何并设计独立流动模块。没有改动原始几何、材料掩膜或生产热求解器，也没有启动加热算例。审查对象是 `runs/single_temperature_mesh2_validation_20261027/qsgs_morphology_ag70vol.npz`，SHA256 为 `03ef47b1dd534b3215cf03f42c8cf7e887dcdfcc185b33bab7453cd838c1faac`；其 QSGS 种子为 20261024。

**结论：该网格适合做拓扑和热传导计算，不适合直接把每个 3 Å 体素当作可解析的 Navier–Stokes 流体网格。** 真实流动模块在选择物理参数前，需先做液态 Ag 与 Ag/Ti3SiC2 界面的 MD 或实验校准，并明确流动驱动力。当前最合理的后续方向是经校准的 Darcy–Brinkman 等效模型；若目标是孔道尺度速度场，则需另建有原子尺度壁面校准的孔道模型，而不是直接在此热网格上开启 NS。

## 连续介质适用性

网格步长约 0.30 nm，接近原子间距；z 向贯通路径的估计瓶颈约 1.55 nm，仅约 5 个网格单元宽。QSGS 掩膜描述的是二值形貌，不包含真实 Ag/Ti3SiC2 晶面、原子粗糙度、吸附层、润湿重构或滑移边界。因而：

- 直接在当前 3 Å 网格上求解连续介质 Navier–Stokes，会把原子尺度体素误当成宏观流体控制体；壁面边界和输运系数没有足够的尺度分离依据。
- 仅细化该网格并不能补出缺失的原子界面物理；孔道尺度 NS 需要有真实表面结构和经验证的液态 Ag 壁面参数。
- Darcy–Brinkman 可作为后续粗粒化路线，但渗透率张量 `K(T,f_l)`、有效黏度、滑移/壁面摩擦及随熔化变化的连通性必须由实验、经验证的 MD 或有尺度收敛证据的独立孔道计算确定。
- 现有设置是封闭 z 流体边界及 x/y 周期边界，用户尚未给出压差、体力或其他流动驱动力。无驱动力的静止初态应保持 `u=0`；不能为获得可见流动而补造压力或速度。

## 独立模块方程与接口

优先设计为与生产热求解器分离的模块，不覆盖热求解器。候选接口：

```text
AgFlowSolver(geometry_mask, FlowParameters, FlowBoundary)
    .advance(T, h, liquid_fraction, dt, forcing=None)
        -> FlowState(u_faces, p_cells, diagnostics)
    .advective_enthalpy_flux(h, FlowState)
        -> face_flux / cell_divergence
```

`FlowState` 使用面心速度和单元中心压力（MAC 网格），热求解器继续持有单元中心温度、焓和 Ag 液相分数。几何掩膜只读传入；Ti3SiC2 和完全固态 Ag 的速度严格置零。固液共存 Ag 使用焓–孔隙率阻尼，液态 Ag 才允许移动。流动模块只返回焓对流通量，由后续集成层将其加入热方程。

孔道尺度候选方程为不可压缩动量方程：

\[
\nabla\cdot\mathbf u=0,
\qquad
\frac{\partial(\rho\mathbf u)}{\partial t}
+\nabla\cdot(\rho\mathbf u\otimes\mathbf u)
=-\nabla p+\nabla\cdot[\mu(\nabla\mathbf u+\nabla\mathbf u^T)]
-S_{m}(f_l)\mathbf u+\mathbf F_{drive}.
\]

焓–孔隙率阻尼候选形式为
\(S_m=A_m(1-f_l)^2/(f_l^3+\epsilon)\)。其中 `A_m` 和 `epsilon` 是数值正则/阻尼参数，须做网格、时间步和参数敏感性测试，不可直接称作材料常数。若采用均质化 Darcy–Brinkman 路线，另需 `-μ K^{-1}u` 多孔阻力；它与解析固体壁面的孔道 NS 属于不同尺度模型，不能重复计入同一阻力。

热方程保持用户给定的焓对流形式；在二相总能量账本里，总储能为 `H_tot = f_Ag*rho_Ag*h_Ag(T,f_l) + f_SC*rho_SC*h_SC(T)`，但对流项只包含 Ag：`div(f_Ag*rho_Ag*u*h_Ag)`。这样 Ti3SiC2 不会被错误地当成随流体移动。

\[
\frac{\partial(\rho h)}{\partial t}
+\nabla\cdot(\rho\mathbf u h)
=\nabla\cdot(k\nabla T)+Q.
\]

Ti3SiC2 保留现有固体热传导方程，不加速度项。Ag 热源继续调用现有 Ag-only 高斯横向分布和深度指数衰减配置；热源倍率、形状、材料数据和当前热边界均不由流动模块改写。现有焓函数继续提供 Ag 的固液相分数及潜热；`u` 在完全固态 Ag 中为零，在固液共存区受焓–孔隙率阻尼，在全液态 Ag 中允许流动。

流体边界与热边界分开设置：流体 x/y 周期；z 两端不穿透、无滑移；Ag/Ti3SiC2 壁面先设无滑移，待 MD 给出滑移长度或壁面摩擦后再决定是否改用 Navier slip。热边界原样保留当前生产配置（含底部理想热沉及其他面设置）。封闭域不允许 Ag 离开，流动模块不得改变热沉的材料掩膜。

## 新参数来源门槛

| 参数 | 当前状态 | 允许来源/确定方式 |
|---|---|---|
| 液态 Ag 的 `ρ_l(T)`、`μ_l(T)` | 现有热焓输入不足以确定完整流变参数 | 经验证实验数据或经过势函数/尺寸/界面验证的 MD；记录温度范围与不确定度 |
| Ag/Ti3SiC2 壁面滑移、摩擦、润湿 | 未知 | 对应真实表面终止、化学状态的 MD/实验；不得套用通用宏观值 |
| Brinkman 渗透率张量 `K(T,f_l)` | 未知 | 基于保留的真实骨架几何并经 MD/独立孔道流动标定；做多种子和尺寸收敛 |
| 糊状区 `A_m`、`epsilon` | 尚未选择 | 焓–孔隙率文献形式仅作候选；通过数值收敛和零速度回归确定，不拟合成材料性质 |
| 流动驱动力 `F_drive` 或压差 | 未给定 | 必须由实验边界、压力条件或明确的体力机制给出；默认零 |
| 热膨胀/浮力与固液密度差 | 本阶段不指定 | 只有明确采用 Boussinesq/变密度假设并找到数据后才加入 |

## 独立验证计划与当前结果

目前已执行且通过的是只读几何审查：几何哈希读取、相掩膜互补、体积分数、周期连通、三方向贯通、界面面积及距离阈值计算均完成。`ag70_geometry_audit.json` 记录了结果和算法。

以下是独立流动求解器实现后的测试计划；当前均为 **未执行**，因为尚无流动离散器且物理参数/驱动力未校准：

1. **静止液体**：零压差、零体力、初始 `u=0`；检查速度保持零、质量不漂移、压力规范固定。
2. **直通道 Poiseuille**：使用无量纲合成流体参数测试解析抛物线速度和流量；这是离散器单元测试，不代表 Ag 的实际压力或速度。
3. **骨架约束流动**：固定 Ti3SiC2 掩膜；验证骨架内部速度为零、壁面无穿透、流体区质量守恒和压力残差。
4. **热–流耦合**：用显式给定的无散速度场检查焓面对流通量守恒、潜热输运和总能量账本；物理流速须另有来源。
5. **零速度回归**：令 `u=0`，流动模块对焓的对流通量严格为零；温度、焓、液相分数应与当前生产焓法逐位一致或落在预先登记的求解容差内。

验收量包括相对质量误差、能量残差、压力残差、速度残差、CFL/扩散稳定数和骨架穿透通量。建议先用机器精度/解析解验证数值单元测试，再给出受物性不确定度约束的物理误差预算；不在没有离散器时伪报测试结果。

## 与生产求解器兼容和集成门槛

流动模块只接收热状态并返回面焓通量与诊断，不直接写热检查点、不改热源、不改材料物性、不改热边界。零速度时对流算子关闭，因此原纯热传导路径可逐位回归。生产集成前需先完成：

1. 液态 Ag 与界面参数来源审查；
2. 物理流动驱动力定义；
3. 冻结几何和掩膜哈希；
4. 独立解析测试与质量/能量闭合；
5. 零速度对现有生产算例回归；
6. 提交集成差异和风险供确认。

本阶段未修改生产求解器，未更改 Ag-only 热源或理想热沉，未启动热算例，也未启用 TTM、自由表面、蒸发或出流边界。
