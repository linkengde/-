# VOF 求解链路试验：静态液滴与网格敏感性

## 目的和范围

为“液态 Ag 流动—自由表面变形—熔坑/喷溅”研究先验证独立 VOF 求解链路。本试验使用 OpenFOAM 2406 的 `interFoam`，在无重力、无外部载荷下计算二维圆柱液滴的静态表面张力平衡。它是**无量纲数值方法试验**，不是 Ag 物性算例，不是电弧计算，也不代表熔池或喷溅结果；没有使用 MD。

两组计算保持相同域、液滴半径和无量纲参数，只加密网格：

- 80×80×1，`dx=0.025`；
- 160×160×1，`dx=0.0125`；
- 液相、气相均设 `rho=1`、`nu=0.01`，`sigma=1`，`g=0`，液滴名义半径 `R=0.4`；
- 网格单元中心二值初始化液相，计算至无量纲 `t≈0.2`。

二维圆柱界面的解析压差为 `Δp=σ/R_eq`，其中 `R_eq` 按数值守恒的液相面积求得。

## 结果

| 网格 | 面积相对漂移 | 解析压差 | 数值液/气体相平均压差 | 压差误差 | 最终瞬时最大速度 | 轮廓长短轴比 |
|---|---:|---:|---:|---:|---:|---:|
| 80×80 | `5.03×10⁻¹³` | 2.4880 | 2.1075 | −15.30% | 0.2816 | 1.0000 |
| 160×160 | `−1.51×10⁻¹¹` | 2.4957 | 2.1674 | −13.16% | 0.2979 | 1.0000 |

两组的累计连续性误差约 `10⁻²⁰`，液相面积守恒良好，液滴质心居中且轮廓保持圆形。但加密一倍后压差误差只从 15.3% 降到 13.2%，没有显示充分收敛。最后三个输出时刻的最大速度约为 0.28–0.30，且压力/速度仍变化，因此还不能视作静态平衡，也不能把速度变化解释成有物理驱动的 Ag 流动。结论是：**VOF 求解器能运行，质量守恒链路通过；表面张力/曲率平衡验证未通过，不能进入 Ag 熔池预测。**需要先调查曲率离散、初始界面分辨率和时间收敛，再重复静滴及毛细波/润湿测试。

各保存时刻的面积、压力跳跃和最大速度见 `static_drop_time_history_80.csv`、`static_drop_time_history_160.csv`；汇总见 `mesh_sensitivity.csv`。

## 与 Ag 熔池模型的关系

本试验不含 Ag 真实密度、黏度、表面张力，不含 Ti₃SiC₂ 骨架、焓法、传热、界面润湿、蒸发、反冲压力或电弧载荷。现有 64×64×50 焓法数据只提供温度、液相分数和骨架掩膜；它不能直接提供自由表面流动条件。即使静滴基准通过，后续也要先建立更大且包含气相的物理域，并用实验/文献校准液态 Ag 与电弧边界参数。熔坑喷溅阶段还必须加入自由表面和气相耦合；若要预测蒸发喷溅，需要再加入质量损失与蒸气反冲模型。

## 复现

使用的容器镜像为 `opencfd/openfoam-default:2406`，下载时解析出的镜像 digest 为 `sha256:dd5aa20630a55722663bf83ba0cb74870cba130081303e32e3865007fa2aa35a`。运行环境需安装 Docker 并已有此镜像。

```sh
python prepare_case.py --resolution 80
./run_case.sh static_drop_case
python analyze_case.py --resolution 80

python prepare_case.py --resolution 160
./run_case.sh static_drop_case_160
python analyze_case.py --resolution 160
```

`static_drop_metrics_80.json` 和 `static_drop_metrics_160.json` 是运行后的指标；`static_drop_benchmark_80.png`、`static_drop_benchmark_160.png` 显示液相轮廓和末时刻速度；`static_drop_final_fields_80.npz`、`static_drop_final_fields_160.npz` 保存末时刻液相分数、压力、速度和网格坐标。完整输入字典分别保存在两个 `static_drop_case*` 目录中；CSV 保留各写出时刻的统计，不需要把全部中间场上传到仓库。
