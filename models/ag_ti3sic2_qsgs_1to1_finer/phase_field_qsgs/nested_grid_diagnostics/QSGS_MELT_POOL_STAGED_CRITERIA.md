# Ag 局部熔化与熔池三级判据

状态：本轮 `1 ps` 加热筛查使用的操作性判据。阈值用于结果判读和敏感性检查，不是 Ag 的固有材料常数。

## 三级判定

### 1. 初始熔化

至少一个原生 Ag 体素节点的液相分数满足 `f_l > 0`，记录首次出现时间、Ag 液相分数加权总体积 `sum(f_l V)` 和最大液相分数。该信号只称为“初始熔化”，不称为熔池。

### 2. 初步局部 Ag 熔池

使用 `f_l >= 0.5` 作为液态连通分析的操作阈值，并只沿 QSGS 原生 Ag 网络中的真实共享面（六邻接，x/y 周期接缝也计入）寻找连通簇。候选簇需要：

- 是一个真实连通簇，不能把互不连通、节点数并列的簇合并计算；
- 至少包含 50 个原生 Ag 体素，约 `1.44e3 Å^3`；
- 在至少连续 3 个采样时刻均达到最小规模。采样间隔为 `0.025 ps`，首末时刻跨度为 `0.05 ps`；
- 相邻采样记录主簇共享节点数，辅助确认团簇延续关系；
- 检查其相对热源中心的位置、周期边界下的 x/y 包围范围、z 范围、占总 Ag 体积比例，以及全场液相体积。局部性依据这些空间量判读，不擅自增加未约定的数值阈值。

满足尺寸和至少 `0.05 ps` 持续采样条件后，可称为“初步局部 Ag 熔池候选”；若空间范围显示其已扩展为全网大范围液化，则不按局部熔池报告。建议对 20、50、100 个体素门槛做敏感性比较。

### 短时持续性等级

- 连续至少 `0.3 ps`：短时持续性通过。
- 连续至少 `0.5 ps`：较强的短时持续性证据。

这两级都表示液态主区域在持续加热模拟中持续存在，不表示体积已达到平台。应同时报告持续窗口内团簇体积的峰峰变化、主团簇重叠和能量残差。若熔池在持续长大，只称“持续存在的熔池”，不称“体积稳定的熔池”。若首次达到熔化时间较晚，剩余的 1 ps 窗口不足以满足 0.3 或 0.5 ps，则只报告已观测的较低等级。

这里分别记录两种体积，不能混用：

- 全域液相分数加权体积：`sum(f_l,i * V_i)`；
- 阈值连通液态簇体积：对最大连通簇内 `f_l >= 0.5` 的原生体素体积求和。

### 3. 稳定熔池

沿用项目中待验证的候选标准：同一主液态团簇持续至少 `3 ps`，且最近 `2 ps` 的体积波动不超过 `5%`。这是后续稳定性研究标准，并非本次 1 ps 试算的硬性要求。

## 本轮加热决策

当前任务的加热上限是总模拟时间 `1 ps`。达到上限即停止加热并保存状态；本轮主要判断是否初始熔化、是否达到初步熔池候选，以及是否通过 `0.3 ps` 短时持续性门槛，并额外报告 `0.5 ps` 增强门槛。若出现液相但不满足尺寸、连通或持续性条件，只报告观察到的级别，不延长到任务上限以外，也不称为稳定熔池。

由于 3 ps / 2 ps 稳定性窗口长于 1 ps，本轮不能据此确认严格稳定熔池。是否继续加热或转入关热冷却，应在 1 ps 结果出来后另行评估。
