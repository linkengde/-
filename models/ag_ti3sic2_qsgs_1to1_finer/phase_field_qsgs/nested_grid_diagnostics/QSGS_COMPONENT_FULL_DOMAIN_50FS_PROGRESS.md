## 目的

在 20 fs 全域联调通过的基础上，将相同模型延长到 50 fs，比较连通组分输运模型与原生 Ag 体素参考。筛查通过后，按用户确定的顺序继续局部加热，观察是否形成局部 Ag 液相；不把数值筛查本身当作熔池结果。

## 固定条件

- 几何：仓库中的 `qsgs_morphology.npz`，单胞在 x/y 方向各重复 3 次。
- 网格：约 3 Å 的原生 QSGS 体素；连通组分模型按 `(2,1,1)` 聚合，参考模型按 `(1,1,1)` 原生体素建节点。
- 边界：x/y 周期（包含超胞边缘接缝），z 绝热；边界 A。Ti₃SiC₂ 在本计算中仅作为几何掩码，不储热、不导热，也没有跨相传热。
- 热源：峰值通量 `5 eV/(ps·Å²)`；横向 `exp(-r²/R²)`、`R=30 Å`；从顶部沿深度以 `20 Å` 特征长度指数衰减。对原生二值 Ag 体素精确积分，再守恒汇总到连通组分节点，不对掩码后的源项二次归一化。
- 候选 Ag 电子物性表：300–20,000 K；超出范围不外推。
- 对照时间步：`0.3125 fs` 和 `0.15625 fs`，每组物理时长 `0.05 ps`。
- 对照组：连通组分 `(2,1,1)` 与原生 Ag 体素 `(1,1,1)`，共四组计算。

## 验收标准

1. 两种输运表示下总源功率一致。
2. 连通组分相对原生参考的电子过剩能量场、晶格焓场和累计电子—晶格传能场相对 L1 误差均不超过 5%。
3. 能量账本相对残差不超过 `1e-10`。
4. 时间步减半后，电子能量场、晶格焓场、累计耦合能量场、峰值温度和液相分数变化均不超过 5%。

## 复现

先安装仓库中列出的可选 AMG 依赖，然后在仓库根目录运行：

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
python models/ag_ti3sic2_qsgs_1to1_finer/phase_field_qsgs/qsgs_component_full_domain_match_parallel.py
```

该并行驱动默认启动四个 worker。若运行机器的 CPU 或内存资源不足，应调低 worker 数；不要同时运行多个全域匹配任务。

## 模型解释范围

本计算是 QSGS 几何上的 Ag 连续介质双温—焓传输筛查，不是原子动力学模型。它不含固定层、牛顿层、溅射层或蒸发层，也不含 Ti₃SiC₂ 骨架的热容量、导热、机械约束或真实界面传热。即使该数值筛查通过，也只表示当前几何掩码假设下输运离散达到本轮操作标准；是否形成 Ag 熔池仍须由之后的液相场计算判断。
