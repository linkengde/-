## 验证范围

导出格式重新读入、坐标/元素/晶胞/化学计量/质量、两相原子连通、周期绕行与厚度贯通均通过。
原版仓库EAM + TSCBOP/Tersoff + Morse calibration-v0逐字节复制，未修改势参数。
LAMMPS仅run 0，最大原子力矢量模约**3.98779 eV/Å**，底层力未遮蔽。
**仍为未弛豫初始几何，未验证300 K稳定性，未运行MD、加热或TTM。**
细颈力学稳定性和生产级势验证不在这次几何检查结论内。

另有一个与 Ag/界面分开的 Ti₃SiC₂ 母相 TSCBOP 静态晶胞检查，输入、日志和结果见[独立检查记录](potential_validation/ti3sic2_bulk_tscbop/README.md)。母相晶体可在该势下弛豫到低力状态；各向异性零压弛豫后的晶胞比 CIF 初始尺寸大约 0.5–0.8%。这项结果不等于 QSGS 骨架或复合冷态基线通过，也没有将弛豫晶胞代入复合模型。

后续静态力定位显示，QSGS 骨架体素内部仍有大量 Ti/C 原子承受约 2.67/2.04 eV/Å 的力，与未经弛豫的母相 CIF 在同一 TSCBOP 下的受力吻合。分箱方法和限制见[骨架力空间定位记录](potential_validation/qsgs_force_localization/README.md)。另一个保留完整势函数、固定 Ag 的 100 步骨架弛豫虽降低了多数骨架原子的力，但最大骨架力仍为3.32 eV/Å，Ag释放约束后最大力为4.05 eV/Å，并有两个 C 原子脱离3.25 Å连通分量。因此候选未通过，当前模型仍不能加热；下一步应从与 TSCBOP 平衡晶格相容的 parent basis 重建一个独立候选，再复核界面间距、质量比、连通性和冷态受力。

随后已按 TSCBOP 零压弛豫晶胞另建一个独立 QSGS 候选，原始模型未改动。新候选几何仍通过双连续与约1:1质量比检查，但两段共200步全体系 FIRE 弛豫后出现少量断连；固定整个骨架再做 Ag-only 弛豫，也没有消除高受力。更严格的刚性骨架、无热源 300 K NVT 短测中，Ag 温度升至约1067 K（80 fs），最大 Ag 力升至约11.5 eV/Å。因此新候选也**未通过冷态基线**，没有接入 TTM 或施加热源。方法、日志和指标见[弛豫母相 QSGS 候选记录](potential_validation/relaxed_backbone_candidate/README.md)。

补充的同坐标 `run 0` 力分解显示，关闭交叉 Morse 项仅用于诊断时，Ag 的最大力由3.780降至1.851 eV/Å，95分位由1.740降至1.041 eV/Å；约27.3%的 Ag 原子交叉项力大于1 eV/Å。交叉项显著影响界面力尾部，但去掉该项后仍有残余力，故不能把问题归结成单一参数，也没有把诊断参数用于任何动力学。分解数据和可复算脚本也收录在上述候选目录中。

后续将 Ag-only 刚性骨架 FIRE 优化延长200步后，Ag受力95分位小幅下降，但最大力升至3.845 eV/Å，且153个 Ag 原子离开最大连通分量。该末态的无热源、300 K 目标 NVT 测试运行25 fs后升至351.44 K，势能减少约1205 eV、动能增加约1192 eV，说明结构仍在明显释放势能。该候选仍未通过冷态验收，不进行局部熔池计算；细节见候选报告。

逐原子定位显示，最高移动 Ag 力位于材料内部 Ag/C 界面（Ag id 767369，z=123.224 Å，最近 C 间距2.349 Å），不在顶部自由表面；离骨架超过8 Å的 Ag 原子最大力约0.20 eV/Å。交叉 Morse 诊断项解释了最高 Ag 原子力的大部分，同时 Ti 骨架最大力中仍有较大部分来自无交叉诊断下的骨架内力。详见候选目录中的 `high_force_localization_after300.json` 和复现脚本。

继续逐对计算后，最高力 Ag 的交叉作用由多个 C/Ti 近邻合成；最大单个 Ag–C 原子对的力约1.35 eV/Å，解析的 Morse 对力总和与 LAMMPS 力差残差小于1.1×10⁻⁵ eV/Å。这支持“界面多近邻累积”是当前校准版下高力尾部的直接来源，不支持把它简化成一个异常短接触。

已完成一次有限的 B 路线试验：固定 Ti₃SiC₂ 骨架，用 WCA 纯排斥壁取代 Ag–骨架 Morse 项，保留 Ag EAM。100步静态优化后移动 Ag 最大力降至1.45 eV/Å且仍连续；连续100 fs无热源NVT未发生温度/受力爆发，但温度降至184 K、Ag 有63个原子离开最大连通分量，因此仍未达到冷态验收。该模型只验证几何约束可行性，不代表真实界面；没有进行TTM或熔池计算。完整设置、结果和复现输入见[几何约束型 Model B 试验](potential_validation/geometry_constraint_B/README.md)。

## 后续局部熔化—凝固路线

由于复合体系原子冷态基线和界面势尚未通过验证，后续改用分开的多尺度路线：纯Ag原子模型提供熔化/凝固机制参照，QSGS几何进入连续介质双温—焓法模型。纯Ag真实MD TTM参考耦合短测见[纯Ag TTM试验](pure_ag_classifier/TTM_MD_PILOT.md)；QSGS网格映射、焓函数、一维Stefan基准与单温筛查见[连续相变模块记录](phase_field_qsgs/README.md)。双温—焓求解器现使用守恒半隐式导热和隐式逐格电子—晶格交换，并修正Ag总热导率重复计入；通过0D、1D及10 Å QSGS短时能量收支检查。边界 A、无底部热沉条件下已完成0.1、1和5 ps加热筛查，仍未形成 Ag 液相；尚未运行100 ps计算。方法、筛查数据与残余限制见[QSGS双温焓法报告](phase_field_qsgs/QSGS_TTM_ENTHALPY_PILOT.md)。
