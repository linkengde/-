# Ag–TTM 网格离散预检（映射方案候选）

日期：2026-10-24。只做原子坐标读取、Ag 体积映射和热源能量守恒检查。另有一项独立 Python 参考求解器单步 smoke test；没有运行 LAMMPS、MD 或复合材料加热。

## 计算对象和假设

- 输入为当前仓库的 `ag_ti3sic2_qsgs.data.gz`，从实际原子坐标读取 Ag（type 4）。
- 按分层方案只统计 `z≥40 Å` 的牛顿层 Ag；共 154,705 个原子。这与“固定层/恒温层中的 Ag 不参与电子—晶格耦合”的候选设置一致。
- Ag 原子体积暂按模型 FCC 晶格常数 `a=4.09 Å` 估算：`V_Ag=a³/4=17.104482 Å³`。这只是从原子求积到连续源项的体积代理，不是对界面自由体积的测量。
- 使用 `I0=5 eV/(ps·Å²)`、`R=30 Å`（`exp(-r²/R²)`）、`l_skin=20 Å`、热源顶面 `z_s=158.6115 Å`。横向中心为当前周期盒中心。
- 源项在每个 Ag 原子位置求值，再乘 `V_Ag` 求和。
- 网格映射采用 cloud-in-cell：每个 Ag 原子的体积与对应源能量按三线性权重分配给相邻单元，保证映射前后 Ag 体积和源能量守恒。
- 少数单元的原始占据体积若略超单元体积，就把超量体积及对应能量移到邻近已有 Ag 占据且有空间的单元。该局部修正不改变总量；实际空间分配会有轻微平滑，需作为离散化近似记录。

可复现命令：

```bash
python preflight_ttm_grid.py
```

## 结果

未乘 Ag 掩码的连续材料层积分为 `14,132.0835 eV/ps`。只对牛顿层 Ag 积分，原子求积为 `3,170.6687 eV/ps`，约为连续全材料源的 22.436%。因此 Ag 选择性源的实际总功率低于未掩码解析值；不可把全材料值误报为 Ag 实际吸收功率。若仅作固定 10 ps 对照，牛顿层 Ag 的候选注入量约 `31,706.7 eV`；项目当前采用熔池稳定后自适应关热，这个数字不是运行目标。

## 不能直接作为正式 LAMMPS TTM 的原因

cloud-in-cell 与局部守恒修正仍是粗粒化映射候选，不是真正的 Ag 界面几何体积分割；它会在一个网格尺度内平滑 Ag 界面。独立 Python 参考实现已定义 x/y 周期、z 自由表面零通量以及电子能量与 Ag 之间的映射，但映射对网格偏移/尺寸的敏感性尚未检查，也没有接入 LAMMPS 原子积分。因此，这些结果不能当作正式 TTM-MD 模拟。

参考 TTM 的网格方程、自由表面边界、能量账本、低温假设和限制见 [TTM_REFERENCE_IMPLEMENTATION.md](TTM_REFERENCE_IMPLEMENTATION.md)。实际几何的单步参考 smoke test 结果记录在 `ttm_geometry_one_step_smoke.py` 输出中：10 Å 网格、0.5 fs operator step、348 个显式电子子步、峰值电子温度约 594.54 K，源注入 1.585334 eV，电子—晶格传能约 `4.18×10⁻⁴ eV`，TTM 能量账本残差约 `1.0×10⁻¹⁴ eV`。测试使用合成 300 K 速度，不含势函数或 MD 积分；它只验证数值路径，不是加热结果。

原子坐标到网格的映射与总热源积分已通过静态检查；复合模型冷态基线和校准版界面势仍未通过验收，因此没有启动复合材料的实际 TTM/MD 加热或熔池计算。
