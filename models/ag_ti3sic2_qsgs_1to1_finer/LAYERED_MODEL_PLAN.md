# Ag–Ti₃SiC₂ QSGS 分层方案与静态核验

本方案按仓库中当前模型的实际尺寸定义，而不是照搬示意图的 400 Å 厚度。当前材料厚度为 158.6115 Å，盒子 z 长度为 258.6115 Å，顶面上方有 100 Å 真空。研究对象是微观尺度的局部 Ag 熔池及其关热后在连续 Ti₃SiC₂ 骨架约束下的局部凝固，不是整体熔化，也不研究溅射、蒸发、熔坑或烧蚀。骨架的预期作用是限制液态 Ag 迁移和熔池扩展；通过熔池连通区域、Ag 位移/扩散、形貌变化及骨架连续性观察这一作用。交叉势和骨架势的适用性不足会限制束缚作用的定量可信度。

## 分层定义

| 分区 | z 范围（Å） | 静态原子数 | 后续用途 |
|---|---:|---:|---|
| 固定层 | 0–20 | 117,618 | 固定底部基体；包括 32,633 Ag 与 84,985 个 Ti/Si/C 原子 |
| 恒温层 | 20–40 | 119,063 | 冷态平衡时作为热沉；包括 25,658 Ag 与 93,405 个 Ti/Si/C 原子 |
| 牛顿层 | 40–158.6115 | 680,697 | 活动复合材料区；包括 154,705 Ag 与 525,992 个 Ti/Si/C 原子 |
| 自由表面真空缓冲区 | 158.6115–258.6115 | 0（初态） | 保留自由表面；仅监测意外逸出原子，不把它作为溅射/蒸发分析对象 |

全模型 917,378 个原子均位于材料区。固定、恒温、牛顿三组没有交叠，材料区没有未分配原子，材料区外没有初始原子。质量比 1:1 是全材料的全局约束；不要求每个 z 分层各自达到 1:1，以免改变双连续形貌。

## 后续输入中的分组规则

- 固定组施加零速度和零力约束。
- 恒温组在冷态基线阶段作为 300 K 热沉；它与 Ag 的 TTM 电子—晶格耦合组互斥，避免对同一原子重复控温。
- 牛顿组自由积分；其中的 Ag 子组才接收 Ag 电子—晶格耦合，Ti₃SiC₂ 子组不施加直接热源，并监测温度、配位/有序度和骨架连通性。
- Ti₃SiC₂ 连续骨架作为 Ag 熔融和凝固过程中的结构约束相；加热时观察它对局部液态 Ag 迁移与扩展的限制，关热后跟踪骨架中的局部凝固结构。当前势函数不能定量验证真实界面束缚强度。
- 顶部真空不是材料层，也不需要再划分溅射/蒸发分析区。保留 atom count/lost-atom 作为安全监测；若持续出现逸出原子或表面下陷，停止该预检并降低热源。

## 稳定熔池与热源控制

- 热源沿用静态预检定义：`q_e=(I0/l_skin) exp(-r²/R²) exp(-d/l_skin)`，其中 `R=30 Å` 按横向权重降至中心值 `1/e` 定义，`l_skin=20 Å`，`I0=5 eV/(ps·Å²)` 暂按中心峰值面功率密度解释；不改写为 `exp(-2r²/R²)` 或重新解释半径。
- Ag 掩码及网格离散应守恒映射前的源能量，并分别报告未乘掩码的连续源功率与 Ag 掩码后的实际功率。按当前原子位置求积，未乘 Ag 掩码的有限厚度连续源约为 `14,132.0835 eV/ps`，牛顿层 Ag 候选功率约为 `3,170.6687 eV/ps`；这些是静态预检值，不是已运行的 TTM 功率。`I0` 按峰值通量解释时，不得在乘 Ag 掩码后再强行将总功率归一化回未掩码值，否则会改变峰值通量的含义。映射前后能量守恒检查见 [热源静态预检](TTM_SOURCE_STATIC_PREFLIGHT.md) 和 [网格离散预检](TTM_GRID_DISCRETIZATION_PREFLIGHT.md)。
- 能量先注入 Ag 对应的电子系统，再通过 Ag 电子—晶格耦合传给牛顿层 Ag 原子；不直接给 Ag 原子加外部热量，Ti₃SiC₂ 不施加直接热源。
- 10 ps 仅作为参考加热时长。总模拟时长为 100 ps，达到熔池关热判据后立即关闭热源，余下时间用于冷却和凝固。
- 预检中分级增加热源幅值，先验证温度响应与能量守恒，再逐步接近名义值。加热期间同时监测最大连通液态 Ag 团簇、液态判据、熔池体积/温度、骨架有序度和连通性。
- 熔池关热判据先采用操作性试行值：最大连通液态 Ag 团簇持续存在至少 3 ps，且最近 2 ps 的熔池体积没有持续增长；骨架仍保持贯通且结构指标没有持续恶化。液态判定不只依靠温度，需结合局部结构序参量或扩散性指标。
- 安全停止条件：出现持续表面下陷、骨架失去贯通、局部结构快速破坏或原子逸出时，停止当前预检并回退热源幅值。上述持续时间和容差需在小规模预检中做敏感性检查，不当作材料常数。

热源参数与模型坐标的静态核对见 [TTM_SOURCE_STATIC_PREFLIGHT.md](TTM_SOURCE_STATIC_PREFLIGHT.md)；原子坐标到候选网格的源功率离散比较见 [TTM_GRID_DISCRETIZATION_PREFLIGHT.md](TTM_GRID_DISCRETIZATION_PREFLIGHT.md) 和 [preflight_ttm_grid.py](preflight_ttm_grid.py)。这些静态预检本身没有运行 TTM。之后建立了独立 Python 参考求解器并完成单步能量账本 smoke test。2026-10-25 又通过 LAMMPS Python API 在单独的刚性几何约束 Model B 上做了真实 MD–TTM 联调：0.05 ps 和延长至0.25 ps的试跑均未形成熔池；0.25 ps末端热源加权局部晶格温度约253 K。把峰值通量提高到15 eV/(ps·Å²)再跑0.25 ps后，电子最高温度约2585 K，但热源加权晶格温度仍约255 K，也未形成熔池。修正账本重复计入后，名义源强0.25 ps累计残差约0.05890 eV，与同长度无源 NVE 漂移0.05795 eV相差约0.00095 eV。这些不是原始 Morse 主模型的加热验证，也不是生产级 LAMMPS TTM fix；详见 [B 路线试验](potential_validation/geometry_constraint_B/B_TTM_SOURCE_SENSITIVITY_3X.md)。

## 核验方式和结果

使用 `in.layered_static_check` 读取仓库的压缩 LAMMPS 数据和当前候选势，仅运行 `run 0`。LAMMPS 版本为 22 Jul 2025 – Update 4。结果：

- 固定层 / 恒温层 / 牛顿层：117,618 / 119,063 / 680,697 个原子。
- 三组交叠数均为 0；材料区未分配数为 0；材料区外原子数为 0。
- 顶部 100 Å 真空缓冲区初始原子数为 0。
- 当前未弛豫结构的最大力矢量模为 3.9877933 eV/Å，势能为 −4,883,783.9 eV。
- 这只是分层和静态受力检查；没有积分、恒温、TTM 或加热。

复核命令（在本目录执行）：

```bash
lmp -in in.layered_static_check -log log.layered_static_check
```

## 当前路线与限制

按当前研究范围，保留仓库现有 EAM + TSCBOP/Tersoff + Morse calibration-v0，不把彻底解决界面势作为前提；预期结果只能解释为当前候选势下的探索性观察。当前分层静态力检查通过几何分层核验，但没有通过力学基线验收。

2026-10-24 的 Stage 1 松弛筛查未通过：初始最大力 Ag 原子 717010 的力主要来自 Ag–骨架 Morse 交叉项；固定 Ti/Si/C、仅松弛 Ag 200 次 CG 后，Ag 最大力仍为 4.081 eV/Å、最短 Ag–C 距离为 1.919 Å；固定骨架 Ag-only FIRE 200 次后仍为 3.806 eV/Å、最短 Ag–C 为 1.968 Å。骨架谐和约束 K=1、10、100 eV/Å² 在解除约束后，骨架最大物理力仍为 3.111、3.252、3.492 eV/Å，Ag 最大力为 3.704–3.833 eV/Å。

后续静态诊断还发现，牛顿层中距离所有 Ag 至少 8 Å 的 84,154 个 Ti 和 56,429 个 C，受力中位数仍有 2.675 和 2.041 eV/Å，且 Morse 力为零；因此骨架内部几何/势能也存在明显重排需求。Ag 固定、Morse 暂置零的骨架 FIRE 弛豫后，一恢复原界面势，`run 0` 最大 Ag/骨架力升到 18.705/16.522 eV/Å，出现 1.930 Å 的 Ag–Si 接触。将 Morse 参数从 0 逐级升至原值后，完整势下最大力为 4.556 eV/Å；再延长 100 次 FIRE 后，牛顿层最大力升至 7.522 eV/Å，追踪 C–C 对缩短到 2.534 Å。另用原始完整势和 K=100 eV/Å² 骨架弹簧做 200 次 FIRE，Ag 最大力仍为 3.820 eV/Å；解除弹簧后骨架最大物理力为 5.679 eV/Å。之后做了干净的0.1 fs、0.025 ps K=100冷态敏感性短跑，917,378个原子均保留；有效restart和末帧逐原子核对一致。另做0.025 ps受限冷态续跑，Ag升至约537 K而骨架约96 K，说明主路线基线仍未平衡，不能为主模型加热放行。详情见 [STAGE1_MINIMIZATION_DIAGNOSTICS.md](STAGE1_MINIMIZATION_DIAGNOSTICS.md) 和 [STAGE2_COLD_K100_PILOT.md](STAGE2_COLD_K100_PILOT.md)。原始 Morse 主模型仍不启动正式加热；B 只完成短时参考联调，未形成稳定熔池，强约束几何模型不能作为真实柔性复合材料熔化/凝固的定量证据。

另做了从已松弛 Ag 坐标开始的刚性骨架 300 K 无源早期检查：50 步（0.005 ps，0.1 fs）后 Ag 温度为 301.03 K，Ag 最大力 3.847 eV/Å；仅解除骨架约束的终点 `run 0` 显示活动骨架最大物理力仍为 6.355 eV/Å。测试时长不足以证明平衡，CNA 还出现高邻居数警告；它只说明刚性骨架下 5 fs 短跑完成，不能作为稳定熔池初态。输入、坐标快照、日志和判断见 [固定骨架冷态检查](cold_pilot/RESULTS_20261024.md)。

2026-10-25 又将无源冷态筛查延长到 0.025 ps：K=10 弱骨架弹簧下活动区末温约339 K，撤除弹簧后活动 Ag/骨架最大物理力约4.277/4.274 eV/Å，最大骨架位移约0.538 Å；刚性骨架下 Ag 末温约331.6 K、MSD约0.00436 Å²、最大位移约0.204 Å。两条轨迹均完成且没有丢原子，但只有25 fs，温度仍有漂移，不能验收为平衡冷态起点。刚性骨架只作为数值对照，不能代表骨架热响应；详情见 [K=10 弱约束延长筛查](cold_pilot/RESULTS_COLD_K10_0P025PS_20261025.md) 和 [刚性骨架延长筛查](cold_pilot/RESULTS_RIGID_SCAFFOLD_0P025PS_20261025.md)。当前冷态准入仍未通过，不接入 TTM 加热。

将 K=10 无源筛查原计划延至0.1 ps时，第0.03 ps活动区/Ag/骨架/恒温层温度为约379/363/384/358 K，骨架最大位移约0.594 Å，较前一输出窗口仍上升，因此在第300步提前停止。它不是完整0.1 ps轨迹，但进一步说明当前冷态起点未达到稳态；部分日志与判断见 [提前停止记录](cold_pilot/RESULTS_COLD_K10_0P1PS_EARLY_STOP_20261025.md)。目前仍不接入TTM加热。

另外测试了全活动区 300 K NVT 加 K=10 骨架弹簧的0.025 ps预平衡：末态 Ag/骨架温度约341/340 K，撤除弹簧后 Ag/骨架最大物理力约4.444/4.271 eV/Å，未建立冷态平台。该预平衡分组也未通过冷态验收；详情见 [全活动区 NVT 预平衡筛查](cold_pilot/RESULTS_ALL_MOBILE_NVT_K10_0P025PS_20261025.md)。

同一全活动区 NVT 条件计划延长至0.1 ps，但在0.03 ps活动区/Ag/骨架温度升至约381/364/386 K、最大骨架位移约0.594 Å后停止。该部分轨迹未到0.1 ps终点，进一步说明短时预平衡没有建立冷态平台；输入和早停日志见 [NVT 延长筛查](cold_pilot/RESULTS_ALL_MOBILE_NVT_K10_0P1PS_EARLY_STOP_20261025.md)。冷态基线仍未通过，不接入TTM。

独立的无热源步长对照使用 0.5 fs 和 0.25 fs 分别运行至 0.05 ps，未丢失原子，但两组均升温至约 615–669 K，牛顿层最大力约 50 eV/Å，追踪 C–C 距离缩短至约 2.165 Å。该短跑说明异常演化不能简单归因于 0.5 fs 步长；它不构成 0.5 fs 对 TTM 或高温过程的验证。记录见 `/workspace/runs/ag_ti3sic2_selected/baseline/COLD_BASELINE_STEP_SIZE_COMPARISON.md` 和 `/workspace/runs/ag_ti3sic2_selected/baseline/RIGID_SKELETON_CONTROL.md`。

当前模型使用 `boundary p p f`。仓库参考的 LAMMPS `fix ttm/mod` 明确拒绝非周期边界，且其原生热源形式也不是所需的横向高斯乘深度指数形式。正式 TTM 还需要可处理自由表面、Ag 选择性耦合和指定热源分布的实现。若改用 z 周期加真空，必须先解决逸出原子穿越盒顶后绕回底面的影响；不能只把边界改成周期就开始计算。

因此，本分层输入是可以复核的几何配置，不代表势函数已验证、冷态起始状态稳定或 TTM 加热已就绪。现阶段保留模型和势文件原样，不从未通过 Stage 1 的状态开始加热。
