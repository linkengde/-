# Ag–Ti₃SiC₂ 枝状形貌候选审计

## 结果范围

已按用户给出的参考图生成 3 个可复现的几何候选：蓝色代表 Ti₃SiC₂，浅灰色代表 Ag；形貌为中等尺度的互穿枝状/迷宫状两相结构。候选采用相关随机场阈值法生成，**仅用于探索形貌**，不是经校准的 Cahn–Hilliard 相场计算，也不是 Ag–Ti₃SiC₂ 真实旋节分解预测。

没有读取或复制旧模型坐标。此次只交付连续体素几何，不创建原子坐标或 LAMMPS data，也没有运行 MD/LAMMPS。

## 输入与体积分数

- 盒子：X×Y×Z = 150.1×300×300 Å；网格 76×150×150，共 1,710,000 个体素。
- 体素间距：约 1.975×2×2 Å。无孔隙，两相掩膜互补。
- 质量目标 Ti₃SiC₂:Ag = 0.4:0.6，采用用户给出的密度 ρ(Ti₃SiC₂)=4.53、ρ(Ag)=10.4976 g/cm³：

  `phi_Ti3SiC2 = (0.4/4.53) / ((0.4/4.53)+(0.6/10.4976)) = 0.6070573540`。

  目标 Ti₃SiC₂ 体积分数为 60.7057354%，Ag 为 39.2942646%。体素数取最接近目标的整数，所得质量分数约为 40/60 wt%。密度来源按用户提供的材料输入说明记录，本次未独立复核 DOI 原文。

## 形貌生成与显示

使用固定随机种子生成三维标准正态噪声，经高斯平滑（σ=3、4、4 个体素，约 5.92、8、8 Å）后，按排序阈值选取目标数量的 Ti₃SiC₂ 体素。σ 是几何尺度控制参数，不代表材料参数。边界采用反射平滑，模型不是周期边界。脚本可复现随机场与图像。

`morphology_reference_view_2d.png` 为中央 YZ 切片，最近邻放大为 300×300 像素；蓝色 `#2563eb` 是 Ti₃SiC₂，浅灰 `#d2d4d8` 是 Ag。`geometry_preview.png` 另含三维相区表面点渲染及三个正交中心切片。

## 文件与限制

- `generate_geometry.py`：候选生成和图像导出脚本。
- 每个 `candidate_NN` 中：`morphology_reference_view_2d.png`、`geometry_preview.png`、`phase_masks_and_field.npz`、`geometry_stats.json`。NPZ 保存有符号几何场、两相掩膜、体素间距和盒长。
- `candidate_comparison.json`：机器可读汇总。

此交付不含晶格、原子坐标、界面注册或经验证的势函数，因此不能直接用于原子模拟，也不支持关于真实熔化、旋节分解或熔坑演化的结论。
