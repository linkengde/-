# Ag–W V11 冷态平衡与界面热耦合专项验证报告

日期：2026-11-25
基线：`40d6b5676c447c204026346957fee05714561817`
软件：LAMMPS `22 Jul 2025 - Update 4`，4 MPI ranks，1 OpenMP thread
模型：V11 理想 Gyroid，`p p f`，200 × 200 × 300 Å，Dai 2006 Ag–W EFS

## 判定

**冷态 300 K 基线：FAIL。**

这次诊断解决了几项可疑的温度统计与续跑问题，但没有得到稳定的 300 K 原子结构。NVE 总能量守恒很好，然而动能和势能仍持续交换，局部力热点仍明显，Ag/W 的分组动能温度在末段重新分离。因此当前构型不作为激光加热初态。

本报告只评估经典原子 MD 冷态行为。它不测量 Ag/W 的电子界面热导，也没有运行 TTM、激光源或熔化/凝固过程。

## 保持不变的基线

- 从 V11 已提交 Gyroid 结构开始，原子数 `462,180`，Ag `291,274`，W `170,906`。
- Ag/W 质量比 `0.9999950`；未增删原子，原始盒子与 V11 几何数据未修改。
- 仅在本目录写入诊断产物。V5–V10 和 `v11_generated_data/` 均未修改。
- 底部 `z < 20 Å` 的固定原子 ID 在本次续跑中冻结为 `47,323` 个；后续阶段通过 `v11_cold_fixed_ids.include` 重用同一 ID 集合，没有按每段移动后的坐标重选固定层。
- 其余 `414,857` 个原子参与动力学。共用一个 300 K NVT 温控器；Ag、W 子群只用于温度诊断，没有分别施加温控。
- 时间步长 `0.25 fs`，NVT 阻尼时间 `0.1 ps`。每段 0.5 ps NVT 后接 0.05 ps NVE。

## 输入与温度定义核查

1. 初速度由质量相关的 Maxwell 分布生成并移除整体动量。初始移动原子的 Ag/W 统计温度分别为 `299.615/300.661 K`。
2. 势函数元素映射与质量一致：LAMMPS type 1 为 W (`183.84 u`)，type 2 为 Ag (`107.8682 u`)；`pair_coeff * * ... W Ag`。
3. 总移动组与 Ag/W 子组的温度统计均使用 `temp/com`，自由度为 `3N−3`，去除各组质心漂移。独立从速度重算后与 dump 中记录值一致。
4. NVT fix 施加在整个移动组上，目标均为 300 K。日志中的 `Temperature for fix modify is not for group all` 是因为温度 compute 绑定到 `mobile`，而非默认 `all`；它不是分相恒温，也没有使用 NPT。
5. 早期续跑曾按当前 z 坐标重选固定层，导致固定原子集合与初段相差 94 个 ID。本轮为力弛豫后的起始构型建立固定 ID 清单，并在所有续跑中保持不变。

以上核查排除了初始相温度错误、类型/质量映射错误、分别恒温以及本轮固定组变化等解释。它们不能单独证明界面传热充分或体系已经达到平衡。

## 力弛豫

从 V11 生成结构独立运行 FIRE，关闭能量容差停止条件，力容差 `0.01 eV/Å`，最大 2,000 迭代。计算达到最大步数上限后停止，而非达到力收敛：

| 指标 | 结果 |
|---|---:|
| 势能变化 | `−10,544.87 eV` |
| 移动原子 RMS 力 | `0.158` → `0.009995 eV/Å` |
| 移动原子最大力 | `2.636` → `1.239 eV/Å` |
| Ag RMS 力 | `0.007886 eV/Å` |
| W RMS 力 | `0.012827 eV/Å` |
| FIRE 停止条件 | 2,000 步上限；未满足最大力容差 |

因此它是一个更低 RMS 力的候选结构，不是已完全静态收敛的结构。

## 末态结构与力诊断

精确 NVE 末态仍有明显力热点：移动原子最大力/RMS 力为 `5.003/0.825 eV/Å`。移动 Ag 中有 170 个原子、移动 W 中有 5,105 个原子的力大于 `2 eV/Å`。

| 相 | 最近同相距离最小值 (Å) | 最近异相距离最小值 (Å) | 移动原子最大力 (eV/Å) | 移动原子 RMS 力 (eV/Å) |
|---|---:|---:|---:|---:|
| Ag | `2.274` | `2.407` | `3.807` | `0.541` |
| W | `2.442` | `2.407` | `5.003` | `1.161` |

从更低力候选到最后末态，移动原子位移均值 `0.315 Å`、P99 `1.580 Å`、最大 `5.063 Å`。原子数未变，没有原子越过 `z=200 Å` 顶面。短距离和力热点是结构仍在调整的额外信号。

## 研究边界与下一步

- **通过：** LAMMPS 冷态计算可以运行；固定 ID 续跑一致；原子没有丢失；短 NVE 能量守恒良好。
- **未通过：** 已建立的 300 K 冷态平衡基线。末态总体温度约 `286 K`，Ag/W 温差约 `20.7 K`，势能仍向动能转化，力热点仍多。
- **未测试：** 本轮没有执行真实结构 TTM mapping、无热源 TTM、激光热源、熔化或冷却模拟。

建议下一步先空间定位强力原子与局部配位/结构重排，查清它们集中在 Ag/W 界面、Gyroid 曲率高区还是相内缺陷；同时检查共同 NVT 下势能持续变化的来源。保持固定 ID 和 V11 几何不变，完成诊断后再决定是否做一轮有明确停止条件的冷态续跑。不要用 Ag、W 两个独立恒温器掩盖温差，也不要据本轮结果撰写熔焊或界面热导结论。
