# Ag–W QSGS Interface Reconstruction v2 审计

日期：2026-11-23

结论：**v2 尚未生成合格的 Ag–W 初始结构。停止在静态结构阶段；不进入 300 K MD、TTM 或激光加热。**

原始 QSGS 输入没有被覆盖，SHA-256 仍为 `204961ff92491b02d3517a172377b997b378f47e74c47541457ca9b6e76d25f0`。原子计数、质量比和双连续形貌的要求均保留在独立的 v2 目录中。

## 1. 质量平衡冲突图筛选 + Dai EFS

将 W、Ag 原有晶格位点组成二部冲突图。Ag–W 径向 pair 项在 2.8 Å 的力幅值约为 0.850 eV/Å，在 2.3 Å 约为 6.569 eV/Å；2.8 Å 仅用于构造前筛除短接触，不是最终验收阈值。最终判断仍看无临时约束的 Dai EFS 静态结果。

- 在 133,879 条短接触边中，质量平衡贪心覆盖删除了 18,369 个 W 位点和 31,300 个 Ag 位点，共删去 49,669 个原子（约 10.3%）。筛选后剩 432,802 个原子，Ag/W 质量比 0.999762。
- 几何筛选后的跨相最短距离为 2.800 Å；W–W 与 Ag–Ag 最短距离保持在原晶格的 2.745/2.886 Å。两相均保持 x/y 贯通和 z 向贯通，最大连通组占比分别为 98.53% 和 99.98%。
- 无弹簧 Dai EFS CG 共做了 2,700 步（1,200 + 1,500），两段都到迭代上限。末态移动原子 RMS 力约 0.0287 eV/Å，最大力范数约 1.969 eV/Å；能量仍在下降，尚未收敛。
- 末态最短 Ag–W、W–W、Ag–Ag 距离分别为 2.535、2.516、2.429 Å；无原子逸出 z=0–200 Å，拓扑仍贯通。**距离改善不构成通过：力残差仍高且结构仍在演化。**
- 更关键的是，删掉约 10.3% 原子会降低材料原子密度。质量比虽被保住，但这种空位型候选不是目标材料初态，故拒绝。

独立最大二部匹配的大小为 48,150，这给出一个下界：若不移动原始晶格位点，仅靠删除位点消除 2.8 Å 内的跨相冲突，至少要删除约 48,150 个原子。也就是说，固定晶格位点筛除本身无法满足“保留材料密度”的要求。

## 2. 保留全部原子的几何投影

同步投影 160 轮后仍有 107,820 个 Ag–W 短接触，另有 189,044 个 W–W、157,505 个 Ag–Ag 原子对低于 2.6 Å 几何底线。末态最短距离为 2.603/2.440/2.453 Å（Ag–W/W–W/Ag–Ag），最大原子位移 2.283 Å。筛除异相冲突时把挤压传到了同相晶格，拒绝；没有送入 EFS。

顺序投影 80 轮后仍有 66,415 个 Ag–W、117,141 个 W–W、92,713 个 Ag–Ag 短接触。末态最短距离为 2.749/2.539/2.562 Å，最大位移 3.118 Å；W 最大连通组占比降至 97.69%，低于当前双连续几何检查使用的 98% 下限。拒绝；没有送入 EFS。

这些 2.6/2.8 Å 数值仅是几何预处理约束，**不是材料验收标准**。v2 的两种投影路线都未满足其自身几何约束，因此没有理由继续做静态势能优化。

## 3. 同相晶格弹簧 + EFS

从原始结构出发加入临时的 W–W、Ag–Ag 最近邻谐键后进行 1,500 步 EFS 最小化。末态最大力分量约 11.77 eV/Å、RMS 力约 0.80 eV/Å，谐键能约 65,513 eV。几何仍有 221 个 Ag 原子的最近 W 邻居短于 1 Å，跨相最短距离为 0.37 Å。临时弹簧阻止了局部晶格塌缩，却没有清除跨相接触，拒绝。

## 4. v2 决定

- 质量平衡位点筛选候选可用于分析短接触来源，但 10.3% 的原子删除和未收敛的 EFS 力使它不适合作为材料模型。
- 全原子投影与同相弹簧 EFS 路线都未能同时解决跨相接触、同相晶格完整性和静态力残差。
- 没有启动任何积分或热输运模拟；旧坐标下的热源功率不适用于 v2。

本轮没有通过临时放宽力、距离或密度阈值来判定通过。2.8 Å 与 2.6 Å 只用于几何筛选路线的诊断；实际 EFS 候选因未收敛且删掉约 10.3% 原子而被拒绝。原始 QSGS 文件及 v1 审计均保留。

后续方法必须同时处理**位点选择和局部原子重排**，并避免仅以删除原子换取最短距离改善。建议先在局部界面小胞中验证候选重构规则，再扩展到完整 QSGS 结构；验收阈值继续依据 Dai EFS 纯相和界面参考计算校准。当前 v2 目录中的候选数据一律标为未验收。

## 5. 可复核文件

- `rebuild_collision_aware.py`、`project_all_atoms.py`、`project_sequential.py`：三种几何构造/投影实现。
- `in.*` 与对应 `*.log`：EFS 运行输入及 LAMMPS 输出记录。
- `geometry_precheck_report.json`：位点筛选阶段的几何预检结果；`geometry_report.json`：加入 EFS 结果后的最终拒绝决定及 checkpoint 哈希。
- `projection_report.json`、`sequential_projection_report.json`：两种全原子投影的逐轮结果。
- `ag_w_qsgs_interface_v2.prepruned.data.gz`、`ag_w_qsgs_interface_v2.efs_static.data.gz`、`ag_w_qsgs_interface_v2.efs_static_final.data.gz`：主要 v2 候选/失败检查点，均**不是已验收初态**。弹簧路线的原始临时结构保留在 v1 的 `../overlap_repair_v1/bonded_precondition.data.gz`，供 v1/v2 两份输入共享。几何投影候选坐标和逐原子诊断 dump 未归档；其构造代码、完整逐轮/汇总指标、运行输入和日志均已保留，可重新生成。
