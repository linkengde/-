# V16 window-b training acquisitions

Three fixed input acquisitions assigned to window-b; original six-candidate geometry
bytes preserved. Window A approved production integration after V15 FAIL and B
localization review. These sample complementary distance/registry axes; they do
not prove broad framework/thermal coverage. No V16 model is trained yet.

Run `bash run_assigned_labels.sh` on the registered window-b environment, with
GPAW_PYTHON pointing to the existing MPI/ScaLAPACK venv. Four MPI ranks, one BLAS
thread each; no concurrent MACE training. Outputs/checkpoints go to the explicit
workspace run root. Existing outputs are refused; completed labels are skipped.
Each compact archive is verified and published through the owner task. No .gpw
checkpoint is published. Method and reference-energy convention match prior
acquisition; full-precision native/free energies recorded separately.
