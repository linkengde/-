# DFT data supplement preparation — E window

This package advances the audit into a reviewable first tranche of geometry-only inputs. It contains six Ti₃SiC₂ bulk response candidates, their derivation script, source/parameter provenance, environment preflight and validation, and a request for C to freeze roles and execution details.

No DFT calculation, relaxation, MD, training, or source-data edit was performed. The candidates have no labels and remain unassigned. The PAW/GPAW environment already exists, so no software was downloaded or installed.

Start with [C review request](C_REVIEW_REQUEST.md), then inspect [`ti3sic2_bulk_p0/DFT_SUPPLEMENT_PREP.md`](ti3sic2_bulk_p0/DFT_SUPPLEMENT_PREP.md), [`PACKAGE_VALIDATION.md`](PACKAGE_VALIDATION.md), and the candidate manifest/checksums.
