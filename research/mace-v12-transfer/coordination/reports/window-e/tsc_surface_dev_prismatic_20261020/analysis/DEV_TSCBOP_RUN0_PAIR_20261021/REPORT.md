# DEV Ti₃SiC₂ 表面参考/位移对：TSCBOP 静态力对照

## 结论

两份固定几何 DFT 标签均已收敛，且使用未修改的 TSCBOP 完成 LAMMPS `run 0`。绝对力误差仍主要由 Ti、C 项贡献：参考点全体系力矢量 RMSE 为 1.9152 eV/Å，位移点为 1.9130 eV/Å；Si 分组误差约 0.080 eV/Å。对这一次预先定义的端层 Ti ±0.02 Å 对称位移，TSCBOP 与 DFT 的差分力响应误差全体系矢量 RMSE 为 0.01348 eV/Å，位移原子 3.3 Å 内为 0.04101 eV/Å。

结果支持“该单一几何家族上的局部差分响应较接近”，但不消除约 1.9 eV/Å 的绝对力偏差，也不证明跨来源泛化。两点来自 COD 9009647 派生的同一父族；它们仍是几何族 DEV 候选，未分配 TRAIN/DEV/TEST 角色，也不是独立晶体学来源盲测。

## 位移响应误差

响应误差定义为 `(F_TSCBOP_RESP − F_TSCBOP_REF) − (F_DFT_RESP − F_DFT_REF)`，按相同 source atom ID 逐原子计算。局域集合为距离任一位移 Ti（ID 3、90）小于 3.3 Å 的原子。

| 区域 | N | 分量 RMSE (eV/Å) | 矢量 RMSE (eV/Å) | P95 (eV/Å) | 最大 (eV/Å) | 最大误差 atom ID |
|---|---:|---:|---:|---:|---:|---:|
| 全部 | 96 | 0.00778 | 0.01348 | 0.02788 | 0.07914 | 96 |
| 距位移原子 <3.3 Å | 9 | 0.02367 | 0.04101 | 0.07914 | 0.07914 | 96 |

这项差分检验只覆盖一个位移方向、一个幅度和一个父族，不能替代不同表面家族、不同位移模式及独立来源上的验证。绝对力偏差仍明显，不能据此放行 TSCBOP 为定量准确或生产势。
