# 拟合目标函数与数据角色设计

## 目标函数草案

所有输入必须有收敛证据、来源、参数/结构 SHA、统一单位与一致 DFT 方法。目标函数只使用物理可比的观测，归一后按目标组加权：

`J = wF J_force + wE J_relative_energy + wDisp J_displacement + wStress J_stress + wEq J_equilibrium + wSurf J_surface + wReg J_regularization`。

- **力**：以原子三维力矢量残差为主。先分别对 Ti、Si、C 计算分量，并按元素等权，再在不同 parent family 间等权；不能让较多原子数的 114 原子 slab 自动压过 48 原子 bulk。同时报告 RMSE、P95、最大矢量误差，不只优化 RMSE。
- **能量**：仅对同化学计量、同原子数且相同父族/一致 DFT 设置的构型差值评分（例如相对父构型的 `ΔE`，并用每化学式或每原子归一）。不得把未校准零点的 DFT 绝对总能直接减 LAMMPS 绝对势能。跨组成数据需有明确、受约束的化学势/参考能校准后才可纳入。
- **位移响应**：使用 Ti/C 现有 ±0.02 Å 对和未来 Si 对得到的力恢复/有限差分响应；同一母构型的正负位移必须留在同一角色。
- **应力/弹性**：只在体积与剪切构型有收敛 DFT 应力和同一方法下的响应后纳入。当前 48 原子记录无 stress；不得用零值替代。带真空 slab 的三维 stress 不能当 bulk stress。
- **平衡晶格与内部坐标**：当前 48 原子结构是固定 CIF-derived 近父几何且 Fmax≈0.0879 eV/Å，未被证明是 PBE 平衡结构。须有可信 PBE 平衡结构/晶格参考；结构误差、晶格参数、内部坐标和残余力要各自明示。
- **表面**：clean Ti/Si 终止表面及局部扰动的力/相对能量可约束表面响应。114 原子去 Ag slab 是从 Ag 界面派生的冻结结构，只能做诊断，不能当 clean surface 标签。
- **正则化**：可用 `log(p/p0)` 距离约束候选参数靠近已核验的原始值；正则系数由参数先验和留出 DEV 确定。没有来源证据前不设数值边界或权重。必须检查 Tersoff tied/symmetry 约束和有效格式。

权重选择应先按 DFT 数值误差/收敛不确定度归一，再按物理目标和结构族平衡；不能按原子总数或总能绝对值直接定权。权重和边界须在训练前冻结，不能用 TEST 调参。

## 当前角色和未来拆分

`role_freeze.json` 中 TRAIN、DEV、TEST 仍为空。现有 48 原子 mesh 与 Ti/C 位移同属一个父族；七种 k 网格是同一个几何的数值控制，不是七个训练结构。114 原子 slab 是一个从 135 原子界面派生出的单独诊断族。不得因本报告改角色。

未来只有在 C 审核 split manifest 后，才可把整个父族一次性分配到一个角色：同一 bulk parent 的 baseline/k-grid/±位移不可跨 TRAIN/DEV/TEST。训练几何须包含体相/扰动与至少一个 clean-surface 家族；DEV 与 TEST 必须来自不同且不与训练共享母结构的来源家族，最好各含参考和确定性局部响应点。若只有同族留出，不能称独立验证。
