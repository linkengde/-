# 参数可辨识性限制与待授权 run 0 响应方案

## 当前可用数据

E2 JSON 的每条 `directional_scores` 包含结构 ID、参数列、方向、比例因子、全体系及 Ti/Si/C 力 RMSE 和坐标对应误差；没有逐原子 LAMMPS 力向量。E2 包中没有每个参数变体的 per-atom force dump。现有 DFT 原子力及基线误差文件可核对基线，但不是参数扰动响应。

所以当前无法从逐原子向量建立 `dF_atom/dp`，无法计算可解释的行级 Jacobian、矩阵秩、奇异值或参数置信度。对 13 个列级 RMSE 曲线做相关分析也不等价于原子力响应矩阵的可辨识性。

E2 已观察到 A/B/lambda1/lambda2 全列扰动影响较强；Ti/C/Si 及 bulk/slab 对方向的偏好不一致。这说明存在跨目标冲突，不能认定任一参数导致误差，也不能从全列探针决定某个 Ti–C、Ti–Si 或 Si–C 行参数。

## 最小判别测试建议（未执行）

若后续要确定三种异核径向 pair block 是否能区分，建议做同几何、同单位、原子 ID 固定的静态 `run 0` 中心差分力响应：

- 12 个坐标：3 个异核无序 pair（Ti–C、Ti–Si、Si–C）× 4 个径向字段（A、B、lambda1、lambda2）；
- 每坐标只扰动该 pair 的来源确认后 tied block，其余文件数值不动；每个坐标做 `-1%` 和 `+1%` 两个方向。±1% 在此只作诊断步长，不作为拟合界限；
- 在 E2 的六个现有结构几何上逐原子导出力：单一 48 原子 parent 基线、Ti/C ±0.02 Å 四个位移点、114 原子界面派生 slab；同时校验坐标 SHA/ID、参数 SHA 和力单位；
- 需要 12×2×6=144 个变体 `run 0` 评估；若原子级基线力无法从既有归档复用，再对六个几何各导出一次基线，共至多 6 次。现有基线 RMSE敏感性计算不替代这些逐原子输出。

对每个结构形成中心差分响应列后，才可构造力响应矩阵并报告秩/奇异谱；还要按结构家族及元素检查数值条件和相关方向。此方案只覆盖三种异核径向块，不能约束所有同核块或角向参数。若首轮只打算测试一个候选块，可先做 4×2×6=48 个变体评估，但它无法给三种异核 pair 块排他归因。

本方案需另行授权；当前没有生成参数副本或启动 LAMMPS。
