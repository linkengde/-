# 局部环境归因：Ti₃SiC₂ (11-20) TSCBOP 力误差

## 范围与方法

仅使用已归档的 REF/RESP 输入、收敛 DFT 标签及 LAMMPS `run 0` 力，不运行新 DFT、LAMMPS、MD 或拟合。重点检查前一报告中 REF 最大误差 Ti ID 29、RESP 最大误差 Ti ID 30，以及两种几何中误差最大的 C ID 46。

所有距离使用 ASE minimum-image convention。报告 2.8、3.0、3.3、3.5 Å 几何邻居数；这些只是局部环境审计半径，不宣称等同 Tersoff 实际开关截断。表面距离采用原子 z 坐标到 slab 最低或最高原子 z 平面的较小值，属于几何近似，不是重构表面识别。

输入 SHA：REF `fd5ff5c1cae1490bcbde9ffd08f329c7ec8cac687555f29568d725f4230cc5c3`；RESP `6f91573bcb4a0feb7e9f05329f6eca422d3e7aac723763e961b52c7b83ddf9b6`。两者均为 120 原子，符号、坐标、晶胞、PBC 和 source ID 与各自收敛标签一致；逐原子力 CSV 又与 `RESULT.json` 中按输入顺序保存的 DFT 力逐项核对。TSCBOP 参数文件 SHA-256 为 `729273a6488d75756ed7927432c77c7347a1b115cecbaefae4981bafcec80fd7`。

## 误差与表面/配位关系

以 z 平面距离 ≤3.3 Å 定义几何表层后，每个结构有 72 个表层原子及 48 个内部原子。REF 的力误差矢量 RMSE 为表层 `1.9073` eV/Å、内部 `2.0006` eV/Å；RESP 分别为 `1.9071` 和 `2.0000` eV/Å。表层误差没有高于内部误差。

在这一个高度周期且具有对称性的结构族内，逐原子误差范数与 3.3 Å 配位数的 Pearson 相关系数约 `0.04`，与到 z 表面距离的相关系数约 `0.01`（REF 与 RESP 均相近）。相关性受同族对称等价原子影响，不能当作一般性统计检验；但本数据不支持“误差只来自最外层/低配位原子”的解释。

## 结论

1. 最大绝对误差点处于合理的第一近邻距离，且具有 13 个 3.3 Å 几何邻居；简单欠配位或异常短距不是已发现的直接原因。
2. 高误差同时出现在近表层 Ti 和更靠内的 C，整体表层误差没有高于内部层；当前证据更符合 TSCBOP 在该冻结结构族上的骨架力响应存在较广泛偏差，而非单一表面原子缺陷。
3. 现有证据不能把偏差唯一归因于某个 Tersoff 参数或三体项；单一 slab、两个很近的几何和一个位移方向不足以识别根因。不得据此调整势参数。
4. DFT slab 未松弛，最大 DFT 力约 1.71 eV/Å。结构未平衡是重要限制，但高误差原子本身的 DFT 力较小；因此不能只用整块 slab 未松弛解释这些原子上的差异。
5. TSCBOP 实现与 ID/坐标对应检查均通过；这份诊断显示的是当前势在所测几何上的物理力偏差，不构成新的实现审计或生产放行。
