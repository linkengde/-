# 39,486 原子方案 A：冻结 MACE 全模型静态力对照

## 结论

两套模型均已在未松弛的原始坐标上完成 float64 全模型静态推理，39,486 个原子逐 ID 覆盖。MACE-MP 的全模型 Fmax/P95/P99 为 4.3362 / 1.4931 / 2.0978 eV/Å；MACE V17 为 4.4022 / 1.6240 / 2.1486 eV/Å。同一原子上两模型力向量差范数的 Fmax/P95/P99 为 0.6641 / 0.3487 / 0.4796 eV/Å。它衡量模型分歧，不是真实误差。

MACE-MP 有 544 个原子力超过 2 eV/Å，V17 有 698 个；超过 3 eV/Å 的分别为 22 和 28 个。全模型最大值为 Ti ID 1247/3609：MP/V17 为 4.3362/4.4022 eV/Å，最近 Ag 距离 2.5257 Å，Ti₃SiC₂ 2.75 Å近邻图度为 3/6。这是欠配位的相界面位点。当前几何审计最小 Ag–Ti 距离为 2.5009 Å，没有证据表明最大力点有原子重叠；仅凭冻结力不能区分相界面几何影响和交叉势误差。

对满足 dAg>8 Å、dX>5 Å、2.75 Å骨架图度 CN=6 的 9,560 个 Ti₃SiC₂原子，MP/V17 的 Fmax/P95/P99 分别为 0.3126/0.1748/0.1880 和 0.5209/0.4244/0.4450 eV/Å，均无力超过 2 eV/Å。但再要求 dAg>18.1 Å 且 dX>18.1 Å 后，符合条件的骨架原子数为 0；因此该结构没有完全避开保守 MACE 邻域内表面和异相影响的骨架体相样本。

界面势风险仍未解决。E窗口单一 135 原子 DFT 对照显示两模型的 Ag 法向交互力仍显著偏强；当前 39,486 原子结构没有 DFT 力标签。较低的 P95/P99 或部分区域残余力不能作为更准确的证据。

## calibration-v0 与 E窗口证据

同一原始几何 calibration-v0 run 0 的 Fmax/P95/P99 为 3.8003/2.7570/3.2390 eV/Å，F>2 有 15404 个，F>3 有 1230 个。MACE 的 P95/P99 和超限数量明显较低，但全局 Fmax 反而高于 calibration-v0。所有这些都只是势预测的冻结残余力分布，不是相对真实力误差。

参考 E窗口统一静态对照提交 dbcf2f7d6bf966b8fc0476224d2cba52c3866de0 的一个 135 原子匹配构型，MP/V17 的全力 RMSE 为 0.2433/0.2388、TSC-only RMSE 为 0.5040/0.3069、交互力 RMSE 为 0.4233/0.4267 eV/Å。该数据只适用于一个 DFT 标注构型。对应 Ag 法向交互力为 -3.2548/-2.2490 eV/Å，DFT 为 -0.1710 eV/Å，说明该构型中的跨相作用仍偏强。不能把该单构型 RMSE外推为当前大模型的 DFT RMSE。

## 最终判断

- MACE_MP_BACKBONE_RISK=NOT_CLEARED。较严格骨架候选的残余力低，但没有完全隔离的有效邻域骨架集合，也没有当前结构 DFT 力标签。
- MACE_V17_BACKBONE_RISK=NOT_CLEARED。V17 是 provisional，E窗口只有单构型比较；冻结力低并不能验证准确性。
- INTERFACE_FORCE_RISK=HIGH_UNRESOLVED。最大力与多数高力在欠配位 TSC–Ag 接口；无法仅凭静态力拆分几何终止效应与交叉势误差。
- STATIC_COMPARISON_COMPLETED=YES。
- READY_FOR_RELAXATION_ASSESSMENT=NO；READY_FOR_300K_TEST=NO；PRODUCTION_READY=NO。

完整逐原子比较见 MACE_ALL_ATOM_FORCE_COMPARISON.csv；任一模型 F>2 eV/Å 的 798 个原子见 MACE_HIGH_FORCE_ATOMS.csv；分区及距离阈值敏感性见 MACE_FORCE_REGION_METRICS.csv。没有启动松弛、300 K、TTM、DFT 或 MACE训练。
