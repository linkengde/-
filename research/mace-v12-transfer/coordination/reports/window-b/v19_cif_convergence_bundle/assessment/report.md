# V19 CIF Ag–Si k-point mesh ladder assessment

## Result

**Mesh sensitivity exceeds the provisional numerical budgets.** All four fixed-geometry calculations converged and their compact archives verify PASS. The same CIF-derived 52-atom geometry and input hash were used throughout; only the in-plane k-point mesh changed. These results do not establish an equilibrium slab or MACE accuracy.

The large Gamma jump and the odd/even changes show no demonstrated monotonic trend. Native and free-energy shifts differ because the latter retains the finite-smearing free energy; both are reported.

## Recommendation

Do not use one of these meshes as a converged numerical reference for this geometry yet. If A authorizes a follow-up, run the same frozen geometry at 5×5×1 and 6×6×1 with every other setting unchanged. Compare 5×5 against 6×6 and 4×4 using the same budgets. If the denser pair still fails, vary smearing separately; assess vacuum and dipole effects as a separate study. No follow-up DFT was started here.

This fixed-ion pilot is not evidence of an equilibrium surface, training suitability, or model accuracy. It does not establish convergence for another geometry and does not reclassify historical isolated-cluster labels.

## Reproducibility

Pairwise JSON files were generated by the existing `compare_mesh_results.py`, which re-runs the archive verifier and asserts identical species, positions, cell, IDs, and label role before calculating differences. `assessment.json` records full archive inventory hashes and verification checks; `pairwise.csv` contains the comparison table. File hashes are in `SHA256SUMS.txt`.
