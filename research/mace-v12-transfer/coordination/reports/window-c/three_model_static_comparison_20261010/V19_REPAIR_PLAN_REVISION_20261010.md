# V19 修复实验方案修订版（追加记录）

状态：**仅据三模型静态诊断更新候选策略；未启动训练、DFT、MD、LAMMPS 或 TTM。** 本文追加到上一版设计之后，不能覆盖或替代 `../v19_controlled_repair_design_20261010/PLAN.md`。

## 因新证据而更新的决策

1. **初始化优先级：** 授权后第一候选仍为精确哈希 `2f2be696351ac9e94fbe01cdfb6f017679acdbd2db7645209ef55fec9826b012` 的 MACE-MP-0b3-medium，从基础权重独立重启；冻结 V18 (`757586…3cb62`) 只作固定回归参照。基础模型在纯 Ti₃SiC₂ 基准、已完成 Ti 位移对、Ag 小位移/变形和公开 Ag–Si slab 诊断上明显更能保持骨架/固相力。不得从 V18 接着微调或把 V18 选成默认起点。
2. **保留受控臂，不提前挑赢家：** R30 原配方重启、F30 冻结低层与 R30+S 骨架回放沿用上一版实验设计，使用新目录和匹配 seed。R30 vs R30+S 检验骨架数据贡献；R30 vs F30 检验参数冻结贡献。V18 作为不训练基线。静态结果支持安排实验，不证明任何修复臂能达到验收门槛。
3. **骨架训练标签角色仍是硬阻塞：** 用于本次比较的纯 Ag 与 Ti₃SiC₂ 标签仍由登记标为 `numerical_pure_phase_control_not_training_or_independent_validation`；SCF 收敛和 SHA 通过没有改变用途。不得把它们复制进训练文件。只有另一项明确授权和正式数据角色复核才可允许 R30+S；否则此臂不建集、不运行，先设计/等待新获准训练标签。
4. **界面必须双指标评估：** V18 在六个已用开发父族上的全原子 RMSE 较低，但两个模型都未达暂定 0.05 eV/Å；三种接触的标记对分离力 MAE 均由基础模型较低。实验报告必须分别设全原子向量误差、Ag–X 投影、Ag 层广义力/响应、元素 xyz 与最大逐原子误差，不能用单一 pooled force 指标做模型选择。六个旧 acquisition 点仍标记为开发诊断，不能评成 fresh validation。
5. **不要从单边 slab 算刚度：** A −0.20 Å slab 端点已通过归档验证，可加入点态回归；A +0.20 Å 尚未归档，所以不计算 Ag 层成对斜率。B 的 C +0.02 Å 仍在计算；C−仅用于点态误差，不推导 C 刚度。Ti ID3 ±0.02 Å 已构成同 parent 配对回归，但仍属开发诊断。
6. **MATPES 暂不进入执行矩阵：** MACE-MATPES-PBE-0 的官方卡片数据理论与当前 PBE DFT 更同名（PBE、无 +U），可在许可范围明确、权重可合法取得后增加一个新的候选模型对照；当前 ASL 许可范围未核，元数据 HTTP 403，artifact/hash/元素表/cutoff 未验证，故没有数值结果，也不以“同 PBE”推断它一定更准。若后续新增此臂，应新增方案修订并在相同公开参考、相同父族与冻结门槛下推理；不是本轮默许下载。

## 训练和验证切分的约束

本次 22 个模型评分结构及全部复用结构都应登记为已看过的诊断 parent families，不得转称独立测试。Ag 的不同 k 网格、同一父结构位移/体积/shear、同一 slab 的真空变化与层位移、Ti₃SiC₂ 的同 parent 正负响应必须整体归组。训练、调参开发集和锁定测试集按原始 CIF/parent/轨迹 seed、DFT source hash 与原子 lineage 分组。当前已有封存标签保持不读、不复制、不改变角色。

任何未来测试只能在模型、配方、特征口径与验收阈值冻结后由独立 evaluator 执行。应另外形成未用于这些静态诊断的新纯骨架、新界面、新 Ag 缺陷/热结构 parent。拿不到这些父族时，标记 `BLOCKED_NO_INDEPENDENT_VALIDATION`，不以数值 mesh 控制或既有配对点替代。

## 新增熔化/凝固门

本轮所有计算都是固相或静态接触。开始面向复合触头熔池/凝固的生产候选前，需另行授权提供并审核：

- 多初始 seed、温度/密度与局部配位覆盖的 Ag 液态及过冷液态 DFT 标签；轨迹整体按 seed/parent 分组。
- Ag 固/液两相共存盒的至少多个尺寸/晶向/相比例及独立 DFT 参考，不把一个高速淬火轨迹当作熔点证据。
- 高温 Ti₃SiC₂、Ag–骨架高温接触、近接触短程排斥标签，以及固液界面迁移/复原验证。
- 物性门：液固密度、RDF、扩散系数、热焓/潜热、晶序与界面速度/熔点区间；评估尺寸、速率和初值依赖。

静态力回归通过不能替代任何熔化—凝固门。LAMMPS 性能、势格式支持、TTM 力调用、能量收支和重启一致性仍是独立工程门；这份修订未安装、启动或验证其兼容性。

## 停止/授权边界

此前设计的停止条件保持有效，并增加：

- 如纯相训练数据角色未获批，停止 R30+S；不把“审计报告有数据”视作使用授权。
- 如 interface 选择只依赖已评分的六个 acquisition 开发父族，停止声称泛化通过；没有独立开发父族则停止超参数选择和模型推荐。
- 如 MATPES ASL 许可或权重来源未澄清，继续不下载/不推理；不经代理、镜像或缓存绕开。
- 如 A/B 对称端点未完成验证，停止成对刚度报告，不估算缺失侧标签。
- 若静态固相指标通过但液体、共存及凝固物性门未完成，模型状态最高只能是“固相/界面开发候选”，不能称为熔池—凝固势或生产势。

本修订只决定后续实验设计方向。训练、DFT、MD、TTM、运行性能基准与数据角色变更均未获本轮授权，也未执行。完成归档后停止并等待下一步指令。
