# 云端 C：V18 界面受力根因审计

审计范围：只读取冻结 V18、原始 MACE-MP-0b3-medium、非封存训练文件及已公开核验的 DFT 归档。当前独立机器复用现有 MACE 环境；未创建或接管 A/B 实例，没有修改任务卡、训练集、模型或计算结果，未运行 DFT、训练、MD、TTM 或 V19。本公开发布版本包含经过路径与敏感信息检查的报告、CSV、来源记录和复现脚本。所有数值来自本次实际 CPU 推理，不是摘录后当作重算。

## 结论与证据强度

**已确认：V18 相对原始基础模型发生显著的 Ti₃SiC₂ 骨架受力退化。** 10×10×4 的同一 48 原子公开参考上，基础模型全原子力向量 RMSE 为 0.038173 eV/Å，V18 为 2.888854 eV/Å，约 75.7 倍。V18 平方误差的 99.999992% 来自 z 分量；Ti 和 C 是主要贡献者。这不是从 V18 单独失准推断微调退化，而是由同输入、同 DFT、同双精度的直接前后对照支持。

**强支持但未证明为唯一原因：训练覆盖不足及微调遗忘。** V18 的 30 个训练帧全部含 Ag，纯 Ti₃SiC₂ 帧为 0。覆盖主要来自狭窄的混合界面父族，不能用成分矩阵 rank=4 证明周期骨架覆盖。6 Å 截断下，体相 Ti/C/Si 邻居数分别为 71–74/73/80，训练中分别为 11–73/11–69/14–74；体相 C/Si 环境超出这项简单描述符的训练范围。邻居数不是完整网络描述符，也不是因果检验；部分训练 Ti 已有零 Ag 邻居，所以不能简单声称所有局部骨架环境都未出现。要证明补标签能修复，仍需独立受控训练实验；此次不执行。

**已排查的实现因素：** 精确模型哈希、实际 epoch79 状态张量、元素映射、截断、显式原子 ID/顺序、输入输出 positions/cell/PBC、双精度、能量导数、重排和整体平移均核验。两模型 cutoff 都为 6 Å，均有两个 interaction；V18 元素为 C/Si/Ti/Ag 对应原子序数 6/14/22/47，基础模型为完整元素表，按原子序数映射。两者 scale=0.8140724313304148、shift=0、average_neighbors=61.964672446250916 相同，因此差异不能由这些标量被意外重设解释。逐元素常数 E0 影响能量基准，不能单独解释固定原子组成的力导数异常。没有发现整体单位倍率或原子顺序错误的证据。

## 旧候选 EAM+Tersoff+Morse：与 MACE 分开评估

候选02旧混合势诊断实际执行了 LAMMPS run0，覆盖16个已核验参考：6个正负局部界面扰动及10个同一 slab 的 mesh/宽度/边界数值控制。这里“候选02”来自已发布的 heating calibration-v0 文件包；handoff 明确表示 Stage69 参数、ZBL 和原始运行输入没有齐全，故不能称为 Stage69 的已认证复现。它包含 Ag EAM（SHA256 `cb3d605c…a44d807`）、Ti–Si–C TSCBOP（`729273a6…cec80fd7`）及8 Å、无额外 energy-shift 的三组交叉 Morse。类型表为1 Ti/2 Si/3 C/4 Ag，metal 单位。

分离力列是绝对误差 eV/Å；力向量单位也是 eV/Å。V18 在这六个相关点明显优于旧混合势的全原子力 RMSE，但仍 6/6 超过 0.05 eV/Å 向量门槛，分离力 6/6 超过 0.10 门槛；偶有 Ag–Ti 单点投影低于门槛也不改变整组失败。基础 MACE 在这组六点也失败。因此这个结果支持统一 MACE 相对旧候选的局部力改进，却不证明界面通过，更不能推成液态/凝固有效。

旧势相内分解显示，固定 EAM/Tersoff 后，任意独立径向幅值的 Ag–C Morse 交叉项仍有约0.906–0.909 eV/Å 的全原子必要力误差下界；调该交叉 Morse 的 D/alpha/r0 不可能单独修复这两个 Ag–C 结构。该下界只针对固定相内项、中心交叉配对及8 Å 截断，不代表所有 hybrid 形式均不可能。单独 Ti₃SiC₂ TSCBOP bulk run0 在 k4/k6 两个同几何 DFT 档案上的 RMSE 为1.997/1.987 eV/Å，主要是 Ti 2.211/C 2.125，Si 0.003–0.004；所以失败并非只在 Morse 界面项。Ag EAM 纯 fcc 局部 ±0.01 Å 静态控制 RMSE 约0.000888 eV/Å，但体积 ±2% 的能差趋势与 DFT 相反。这些分开诊断揭示的是候选项特定缺陷；不能把其误差归给 MACE，也不能由纯 Ag 小位移 PASS 推出熔化正确。

更早的 TTM step0–10 烟测报告过最大力上升及约1.0002 Å 的 Ag–Ti 接触，当时保守势力与 TTM 随机力没有分离。它支持“旧热分支存在危险近接触且能量异常未诊断完”的历史结论；候选02静态 run0 不能证明 10 步异常的单一来源或精确能量释放。Stage70 的486行 rigid scan 是经典模型自身的能量扫描，不是 DFT 真值。

## 熔池—凝固的分阶段修复及验证设计

1. **先固相/骨架。** 在相同 MACE 配方下追加一个已核验 Ti₃SiC₂ parent 及现存 Ti/C ±z 标签；同一 parent 不拆到 split 中。添加独立的纯 Ag 体积/小位移约束时优先复用现有 Ag DFT。冻结来源和 energy/free-energy 口径；评估逐元素 xyz 力、Ti4f/C4f 方向刚度、弹性/恢复趋势和原界面回归。新 DFT 先不必增加，等待已在 B 运行的 C+ 标签后再判断。
2. **再补界面。** 复用所有来源和方法匹配且 verifier 通过的 Ag–Ti/C/Si 结构，但去掉已用于 model selection 的父族作为新测试。若出现真实未覆盖距离/配准或框架差分，用审定且统一的 DFT 方案做训练点；每种 Ag–X 至少预留多个独立 parent/term/配准的开发和冻结测试样本，不把同一 slab 的 mesh/真空点当不同界面。报告界面分离投影、元素分力和最大原子误差。
3. **建立液 Ag 数据，而非假定静态 fcc 就够。** 先从经确认的 Ag 熔点附近参考态设计不同 parent/seed 的液体采样方案；以 DFT 抽帧复核液体快照，覆盖液相平衡密度、略过热以及物理合理的过冷温区，并包含不同局部配位和体积。训练用多 seed 液体帧；开发/测试按 trajectory seed/父液体盒整体分组，不能把同一轨迹相邻帧拆开。实施要先选择 DFT-AIMD 或以预势生成候选、DFT 单点标注的成本路线及可负担盒尺寸。本轮没有生产配置/参考轨迹，不能写出已经生成的液体数据。
4. **显式固–液界面与凝固检验。** 在可靠 Ag 固/液相各自过关后建立独立双相共存盒，界面法向/晶向、盒长和两个初始相分数至少有对照；用多个冷却速率只作动力学敏感性分析，不把单一高速淬火温度当平衡熔点。先用多尺寸、多初始化的 solid–liquid coexistence 检查界面向哪侧迁移，估算固液转变温度区间；再测 RDF、扩散、密度、潜热/焓、晶序参数、偏析/缺陷及界面速度，对照 DFT 小盒参考、实验和数值尺寸/速率不确定性。无核化不等于熔点，过冷液相存在滞后，需报告滞后范围。
5. **映射到双连续复合触头。** 获得纯 Ag 相变基础后，构造实际 Ti₃SiC₂/Ag 接触的多个界面和 Ag 孔隙/双连续局部几何。检验高温骨架是否保持预期晶相/表面，Ag 是否迁移/润湿/偏析，凝固后的孔洞/键合是否随界面方法稳定。静态原子力门槛、可视化或轨迹不爆炸只是一关。把同源训练 parent 排除后才有解释力。
6. **LAMMPS 与 TTM 另作工程门。** 先冻结可执行的 MACE-LAMMPS 接口/插件版本与模型格式，benchmark 实际大模型原子数、6 Å 邻居数、CPU/GPU、MPI ranks、步长和吞吐/内存；比较工程估算的完整加热/冷却时长。TTM 要确认耦合求解器兼容外部多体势每步原子力、metal 单位、热点源项/边界、随机项、能量交换和 checkpoint restart。做无源/纯原子守恒检查、空白 TTM、固定短程耦合及重启一致性；与独立实现交叉验证能量账本。MACE 能在普通 LAMMPS run 中推理不自动代表当前 TTM 插件可调用它；本轮没有安装 LAMMPS、也无兼容性实测。

该路线推荐“固相和旧势诊断通过→数据源及切分冻结→液 Ag 小批→独立凝固物性检查→融合界面/双连续形貌→性能与 TTM 接口门”。训练与 DFT 只有在授权并确定后续预算时才启动。MACE 是优先验证候选，不因误差比旧势小就预定最终采用；若其液体/相变、骨架或 TTM 性能门失败，应保留换模型路线的决策。

## 数值与实现核验

同一 bulk 的 10×10×2 → 10×10×4 DFT 力差向量 RMS 仅 0.000955 eV/Å，远小于 V18 的 2.889 残差。仓库的 8→10 横向 mesh 对照也已达到该固定基线的 0.01 eV/Å 数值预算；不需要重复该基线 DFT。但这些证据不保证所有位移、应变或 slab 的 mesh 收敛。

两模型的 1e−4 Å 中心能量差分与自动微分力差小于 9e−8 eV/Å；倒序原子后重排回的力差小于 5e−15，整体平移后力差小于 2e−14。实际参数与推理均 float64。验证是模型内部的能量力一致性检查，不证明它与 DFT 一致。DFT 使用 PW500/PBE/0.10 eV smearing，保留 native extrapolated energy 与 force-consistent free energy 的区别；未来拟合必须统一目标，不能用有限温 native energy 的导数直接指控归档力错误。

全部选中归档重新检查 SHA256SUMS、summary.scf_converged、verification PASS、输入源哈希、结构/元素/原子顺序/cell/PBC 与结果哈希；未把正在计算的输出当标签。实际来源清单和完整方法记录在 `audit.json`。

Ti 的实际移动是零基索引 2，显式 local_new_id=3；所有 ID/元素/顺序/cell/PBC 保持一致，成对跨度 0.04 Å。恢复斜率定义 Kz=−(Fz(+0.02)−Fz(−0.02))/0.04：

| DFT | V18 | 基础模型 |
| ---: | ---: | ---: |
| 17.471248 eV/Å² | 6.292036 eV/Å² | 13.868116 eV/Å² |

V18 斜率低约 64.0%，基础模型低约 20.6%；除了大静态偏置，还存在局部响应退化。这是沿一个 4f 原子的有限差分有效刚度，包含高阶截断，不是完整 Hessian、声子谱或热稳定性。C 的对称响应标记 PAIR_INCOMPLETE，不能用单边结果冒充成对导数。三个已完成位移点上，V18 RMSE 2.881–2.897，基础模型 0.039–0.041。

## 推荐方案 A：保持网络结构，先恢复骨架覆盖

优先选择 A，作为后续授权实验，不立即训练。最小首轮是在新的可审阅数据副本中复用 **5 个骨架帧**：10×10×4 的 parent，加 Ti/C 各 ±0.02 Å；现在只有其中 4 个完成，等 B 的最后一个归档真正完成并验证后再组装。相同 parent 的不同 k 网格不能当多个新覆盖帧。与现有接口训练数据联合训练，保持网络结构与受控对照配方；这五个相关帧全属于训练家族，不可分散到 train/dev/test 冒充独立性。每个标签先检查方法匹配、duplicate/parent lineage、有限性、能量约定及所有原子力。

首轮利用现有资产，**无需 C 再启动新 DFT**。若新增覆盖审查仍显示缺口，第二批仅提议最多 4 个纯骨架训练点：体积 ±2%、合适晶格剪切 ±0.5%，须先做距离安全检查、数据去重和数值预算审查，再另行授权 DFT；数值只是候选设计，不是已验证的计算输入。Ti 2a、Si 和横向响应仍未由现有 Ti/C 4f z 标签充分约束，应由后续残差决定是否替换上述候选点，不能宣称 5 帧足以覆盖全部物理空间。

预期收益：直接提供目前缺失的无 Ag 周期骨架力及响应约束，最容易检验覆盖假说；可能显著降低 Ti/C z 偏置。风险：五帧过拟合同一 parent，损害既有界面力，能量目标不一致以及能量/力权重竞争。收益未通过训练实验证实，不保证达到生产阈值。

## 方案 B：A 仍不足时，调整微调策略

网络结构先保持不变。从已核验的基础模型独立初始化，以骨架/接口分组采样或 replay 防止遗忘，考虑冻结低层 interaction/embedding、分阶段解冻、较小学习率（例如 1e−5 对照现有 1e−4），以及基于分元素/分组残差的损失平衡。不要同时改变全部参数；A 数据固定后，一次改变一个因素，保留 seed、训练预算和可复现版本。必要时比较从 V18 温启动与从基础模型重启，才能区分数据补充和初始化效果。

只有独立开发集可以选择超参数；冻结 test 在最终模型确定后一次性使用。若所装 MACE 0.3.16 CLI 不直接支持冻结/分层学习率，应先核验其官方 API/实现，在另行授权的代码任务中实现并测试，不把未经验证的 flag 塞进生产训练脚本。知识保持正则可作为后续试验，但基础模型本身的界面误差也大，不能把其界面输出作为真实标签强制模仿。

预期收益：保护基础骨架表征并限制微调漂移；风险：冻结过多导致接口欠拟合，replay 权重过高保留基础模型的接口偏差，多参数搜索造成开发集过拟合。方案 B 会增加实验预算和实现审查，当前证据不足以推荐直接换网络结构。

## 独立验证与停止条件

所有本次读取、分析的公开 bulk/slab 家族已用于诊断和方案设计，今后不再称 untouched test；它们可作为回归诊断。原有封存数据未读取，不修改、不重新分配。

在新拟合前预先冻结 group-based split：训练、开发、最终测试的父结构/生成种子/缺陷或界面构型家族互不交叉，±位移、同一 parent 的不同 mesh、真空扩展和对称复制归为同组。不同文件名、不同 DOI 或共用 CIF 的三种终止面本身不构成统计独立性。

建议开发组与最终测试组分别至少包含：一个未进入训练的纯骨架 parent 及两个不同响应模式；一个独立纯 Ag 缺陷/应变 parent；Ag–Si、Ag–Ti、Ag–C 各一个不同于训练和已诊断家族的界面 parent，每个至少两个几何点。缺少实际独立 parent/目标 morphology 资产时标记 BLOCKED，不能用原 parent 小位移替代。该规模是风险覆盖方案，不是严格统计样本量保证；补充原子坐标、来源、cell/PBC、phase masks 与 parent hashes 才能落实。

预注册指标包含全原子与 Ti/C/Si/Ag 分元素向量 RMSE、xyz 分量、最大原子误差、分离投影和 bulk 恢复响应。沿用现有 0.05 eV/Å 向量、0.10 eV/Å 分离暂定门槛并明确其适用范围；额外约束骨架不比基础模型回归显著恶化、独立响应方向正确、数值参考误差小于验收预算。不能只优化总平均，把 Ti/C 或少量 Ag 的错误掩盖。纯 Ag 完美晶格零力通过不代替回复斜率和缺陷检查。
