# Ag64 暖机热化 QA 建议

当前评价对象仅为 D 的 `C-D-AGL-1250K-rho097-seed01` step 0–1000 归档。完整数值和来源见 `REPORT.md`；本文件是 QA 建议，不是计算放行。

## 当前 QA 标签

| 标签 | 当前值 | 下一步解释 |
|---|---|---|
| `INITIAL_TRANSIENT` | YES | step 0–80 的热峰与势能/压力快速下降同现；随机装填需要松弛 |
| `THERMALIZATION_NOT_ESTABLISHED` | YES | 最后 200 步均温 1838.35 K（设定1600 K），温度、势能、压力仍在下降 |
| `NUMERICAL_INSTABILITY` | NO EVIDENCE | 所有已保存值有限，最小距离未越过原阈值，归档和 checkpoint 校验通过 |
| `THERMALIZATION_CANDIDATE` | NOT YET | 时间、帧数及有效独立样本不足，未作液态判定 |

## 后续离线验收建议

若单独批准 1000→2000 段，验收前先确认输入 checkpoint 与 D 原归档 SHA 完全一致。采样仍处于原方案 1600 K 热段，记录器继续每20步保存温度/势能/压力，每100步保存坐标。第2000步必须形成完整 checkpoint、新的不可覆盖归档，并完成 GitHub 新分支提交、fresh-fetch、解包和成员 SHA 验证。

C 审阅时建议将 step 0–1000 与 1000–2000 的温度、势能、压力按时间窗作图，同时比较末段两个非重叠 200 步窗的均值、离散度、线性漂移及考虑自相关后的不确定度；结构侧核对最小距离、密度/盒/PBC、RDF 首壳、配位数及局域 Q6 在后两个窗口是否稳定。若任一热力学量继续明显单向漂移，或窗口差异大于基于相关时间估出的不确定度，则保持 `THERMALIZATION_NOT_ESTABLISHED`。

本次只有一个 1000 步追加段的设计预算，无法保证得到足够长的平稳时间序列。若到 step2000 看似平稳，也只标为 `THERMALIZATION_CANDIDATE` 待 C 复核，不自动申请下一段，不称作液态，不作为 DFT 训练/验证标签。液态判定仍需更长时间序列、去相关采样、MSD/扩散与稳定 RDF 等专门 QA；本次数据不具备这些证据。

不能只用末帧温度偏离15.95%作失败条件。64原子、FixCom 后189自由度，在1600 K 的单帧正则温度标准差约165 K；当前末温偏差约1.55个该估计标准差。决策应由时间窗均值和趋势、自相关修正以及结构稳定性共同决定。

## 严格停止及保持 HOLD

- 现行 `--stage continue` 会继续到全局 step120000，绝不能直接运行来做短段。
- 只在之后有新的 C 签署配置和新执行器 SHA 时，才考虑显式终点 step2000；起点必须精确为 step1000，新增步数最多1000。
- 完整恢复坐标、动量、PCG64状态和原科学参数；禁止重新装填、重新抽速或更改温度、摩擦、步长、密度、势函数。
- 对 NaN/Inf、原1.8 Å距离停止线、资源/墙钟超限、checkpoint 及远端归档恢复的任何失败均立即停止。归档失败时不可积分下一步。
- step2000 后先交 C 离线复审；未收到后续签署不得继续到120000，也不放行其余五项暖机、DFT或训练。
