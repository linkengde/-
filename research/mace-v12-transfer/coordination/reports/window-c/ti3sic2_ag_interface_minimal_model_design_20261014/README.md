# Stage C-D4 minimal interface model design

Offline design only. The existing 15 DFT inputs are unchanged. No minimal-model coordinates or DFT calculations were generated.

The preferred 77-atom design retains a seven-plane Si-terminated Ti₃SiC₂ slab and four Ag(111) layers in an area-7 hexagonal cell. The proposed shared-strain version compresses the substrate about 3.00% and stretches Ag about 3.10%; it drops the 12.51983° low-mismatch twist, so it is a local-contact screening proposal rather than a substitute for the 217-atom model. A substrate-fixed 77-atom alternative and a 52-atom compact alternative are documented with their strain and finite-size caveats.

The nominal geometric gap series is 2.16, 2.40, and 2.64 Å, where 2.40 Å is inherited as a reference plane gap and is not claimed to be an equilibrium distance.

No structure is executable until a later offline geometry generation/validation stage and a fresh compute resource gate. No DFT, fitting, or TSCBOP modification occurred.
