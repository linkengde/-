# Stage C-D resource/k-point gate

This directory records the read-only resource gate for the two proposed fixed-geometry GPAW k-point comparisons. Resource safety did not pass, so neither pilot SCF ran. `BLOCKED_RESOURCE_REPORT.md` records the stop reason; `PILOT_STATUS.json` gives machine-readable status.

No structure, DFT input, TSCBOP, or fit was changed. No energy, force, or stress labels were generated. The two pilot comparisons remain pending a separately provisioned and measured safe resource allocation.
