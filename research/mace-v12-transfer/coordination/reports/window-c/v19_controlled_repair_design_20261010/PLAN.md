# 云端 C：V19 受控修复实验准备方案

状态：**仅完成设计与来源核验；训练、DFT、MD、LAMMPS、TTM 均未启动。** 本方案以已发布审计提交 `e455b71f6ef91a0955495001765e659aaee12174` 为基准，归档在独立目录，不修改该审计、冻结模型、原训练集或 A/B 任务。

## 1. 证据基线与当前阻塞

同一 48 原子 Ti₃SiC₂、同一公开 DFT 力参考上，原始 MACE-MP-0b3-medium 的力向量 RMSE 为 0.038173 eV/Å，冻结 V18 为 2.888854 eV/Å，约 75.7 倍差异；V18 平方力误差的 99.999992% 在 z 分量，主要贡献者为 Ti、C。该证据支持微调后发生显著负迁移，但尚不能单凭一份骨架构型断定唯一原因或推广到其他晶相。

V18 训练输入有 30 帧、纯 Ti₃SiC₂ 帧为 0，训练时由原始基础模型初始化。原配方为 seed 45、CPU、batch 1、80 epochs（最后选 epoch 79）、lr 1e-4、weight decay 5e-7、energy/force 权重 100/1000、`REF_energy`/`REF_forces`。输入哈希为 `20279d8aae53baf186546eb4a4dc396bb71e92de9d1c874d1c6fa0022313c045`，验证输入哈希为 `985045431b3b69242ebbb9966393794a18a39fad37e029915e9d75f3b1e06f84`。V18 的三个 dev 帧曾用于模型选择；记录中 test 数为 0。

审计报告列出的 Ag–Ti/Si/C 六个局部位移点均复用了已评分的开发父族，只能作为历史诊断，不是独立验证。V18 在这些点比旧候选混合势的全原子力 RMSE 小，但仍未通过暂定界面力/分离力门槛；基础 MACE 在界面也未通过。因此新方案须同时保骨架和改善界面，不能仅比较总平均误差。

## 2. 纯相数据来源、DFT 口径和资格

`pure_phase_source_eligibility.csv` 是只读元数据登记：从路径中排除 blind/holdout/test/sealed 后，索引了 15 个纯 Ag 与 10 个纯 Ti₃SiC₂ 静态 PBE 归档。没有把原子力、能量或结构标签复制进该清单。25 个归档均报告 SCF 收敛且有 verifier PASS；方法为 GPAW 26.7.0、ASE 3.29.0、PAW 1.2.1、PBE 平面波 500 eV、0.10 eV smearing、SCF 阈值 1e-5。逐文件来源/结果哈希和 k 点见 CSV。Ti₃SiC₂ 的最高横向/垂向网格是 10×10×4；同一几何的不同 k 网格是数值收敛对照，不能计成独立结构样本。

**资格结论：当前 25 个纯相归档全部标注为 `numerical_pure_phase_control_not_training_or_independent_validation`，当前没有一个已获资格的纯相训练帧。** 已收敛和哈希通过仅说明归档可靠，不会自动改变数据角色。不得在本方案或后续脚本中把这些控制标签转成训练标签。若以后要用于训练，必须在另一项明确授权下完成正式 role 复核/变更，或由未来明确授权的新训练标签替代；这不是本轮批准事项。

B 的 Ti4f ID3 ±0.02 Å、C4f ID9 −0.02 Å 三份数据已归档验证；C4f ID9 +0.02 Å 在本方案源快照中还在运行。四点齐全后可作为**非独立骨架响应回归诊断面板**，仍不能因用途改为训练或独立测试。五帧（parent + Ti/C 正负位移）仅构成同一 parent 的局部响应包，不等于 Ti₃SiC₂ 完整构型空间。

纯相汇总记录同时保存 `energy (force_consistent=False)` 与 `free_energy`：前者为 native extrapolated energy，后者为与有限 smearing 力一致的 force-consistent 能量。V18 原配方使用 `REF_energy` native 标签。为隔离微调/数据覆盖影响，首轮配方对照需在所有臂中采用完全相同的能量口径和 key；禁止只对新增骨架帧改用 free energy。该首轮比较只能说明受控筛查结果，不能作为热力学凝固势的最终能量规范。进入液态/相变数据阶段前，应从各训练来源统一重建完整数据包的 force-consistent energy（若来源归档齐全），并单独比较口径变化；若无法逐帧取回并验证，不得混合训练。

## 3. 三种主要受控修复策略

所有模型以基础模型 `mace-mp-0b3-medium.model` 的精确哈希 `2f2be696351ac9e94fbe01cdfb6f017679acdbd2db7645209ef55fec9826b012` 初始化。冻结 V18 哈希 `757586671174db85acbf7971ccfe92de19cc58378ee2431a797efa6d6163cb62` 只作固定对照，不继续从 V18 权重盲目微调。每臂使用互不覆盖的输出目录和独立 manifest；不修改 V18 文件。

| 实验臂 | 初始化与数据 | 单因素问题 |
| --- | --- | --- |
| R30 全量重启基线 | 基础模型；原 V18 30 帧和原配方 | 重现“从基础模型用原 V18 数据微调”是否会再次造成骨架退化 |
| F30 冻结低层 | 基础模型；同一 30 帧、同样训练预算；冻结低层表征，微调高层交互/读出 | 参数约束能否减少骨架遗忘，同时学习原有界面标签 |
| R30+S 骨架回放 | 基础模型；原 30 帧加同一 Ti₃SiC₂ parent 的五帧响应包 | 增加骨架覆盖能否恢复骨架力而不损害界面 |

R30 与 R30+S 是骨架数据增补的核心对照；R30 与 F30 是冻结策略对照。**R30+S 目前因所有纯相标签仍是数值控制而阻塞，不能据此组装或启动。** Freeze 臂也未定为可执行：需先只读核查 MACE 0.3.16 的模块/梯度接口，记录精确冻结参数名和哈希；不得把未经支持的 CLI 参数直接塞进训练命令。建议候选为冻结 atomic/radial embedding 与第一层 interaction、只训练高层 interaction/readout；若 API 不支持或会连带冻结输出头，则停止该臂并另行审查实现。

### 训练控制

- 精确保留 seed 45 的 R30 作为历史配方重现；若首次筛查无明显劣势，再以匹配 seeds 46、47 扩为三 seed。每个 seed 在各臂之间配对。
- 前三臂保持 80 epochs、batch 1、lr 1e-4、weight decay 5e-7、能量/力权重 100/1000、4 CPU threads、epoch 79 比较。保持原 V18 dev 文件只作历史 development；不把它叫独立测试。
- R30+S 每 epoch 从 30 增至 35 帧，按 80 epochs 会多 16.7% optimizer updates。主报告须显式记载这个预算差异。若后续要归因到“新增数据本身”，应另加等 optimizer-step 的 R30 compute-control（或先确认 MACE 可按 step 精确复现学习率日程）；在此核验前不声称已完成单因素因果分离。
- 只写入新的实验目录，保留完整日志、配置、参数梯度 mask、checkpoint、输入和输出 SHA。不得覆盖任何已发布模型或训练集。

## 4. 父族分组与数据切分

禁止按帧随机切分。建立 `parent_family_id` 时，用来源 CIF/原始结构和 DFT 输入 SHA、原子 ID/元素、cell/PBC 及构型生成 lineage 交叉确认；把同一 parent 的 ± 位移/剪切/体积扰动、对称复制、同界面终止/registry 派生、不同 k 网格、真空/偶极数值控制合为同一组。液体轨迹按独立初始 seed/parent 整体分组，临近帧不得拆分。

1. **训练组**：保留原 30 帧的历史训练角色；未来只有经授权且通过 provenance/能量口径/重复度审查的训练资格标签才可加入。五帧骨架响应包不得拆开跨 split。
2. **开发组**：V18 既有 3 帧仅作历史 dev/回归记录，禁止借其证明独立性。新的参数选择需用训练父族之外的新 parent families；目前纯骨架、独立纯 Ag 缺陷/应变及 Ag–Ti/Si/C 新界面 parent 的完整 dev 组仍不足，需后续授权数据安排。
3. **最终测试组**：由独立 evaluator 预先按 parent 锁定，至少覆盖 Ti₃SiC₂ 独立骨架、Ag 纯相响应和 Ag–Ti/Si/C 各自独立界面 parent；推荐每机制至少两个独立 parent 以避免单构型结论。与训练、dev、审计已用的 parent 全部隔离。封存标签保持关闭，仅在模型/配方/门槛冻结后由 evaluator 一次评分。本轮不枚举、不读取、不复制封存结构或标签。

目前 V18 selection record 的 test 计数是 0；已核验公开结构用于本次诊断，因此没有可据此宣称 untouched 的现成独立测试集。严格分组和独立最终验证尚未具备数据条件，属于训练启动阻塞项，不用旧 dev 或同一 parent 的 mesh/位移控制冒充。

## 5. A/B 数据齐全后的受力回归流程

只有归档真正发布后执行以下验证；现在不启动推理、DFT 或任何任务：

1. 对每个归档检查 `scf_converged=true`、verifier/checks 全 PASS、SHA256、方法/能量 key、源结构哈希；逐项匹配 atom IDs、元素、原子顺序、positions、cell、PBC 和实际位移。C+ 在 running 状态时不作为参考。
2. 使用同一 float64/CPU MACE 计算器，在完全相同结构上评分原始 foundation、冻结 V18 和将来获授权的各新臂。力向量定义为 `sqrt(mean_i(||F_model,i-F_DFT,i||²))`，并同时报告分元素 xyz RMSE、最大逐原子误差和逐原子 CSV。不同组成之间不比较绝对能量零点。
3. **B 骨架四点**：确认 Ti4f ID3/C4f ID9 各自 ±0.02 Å 的位置跨度均为 0.04 Å、原子 ID 与其余几何一致。分别算 Ti/C 全向量误差及目标原子 z 力误差；恢复斜率 `Kz = -(Fz(+0.02)-Fz(-0.02))/0.04`，逐模型比较 DFT、foundation、V18 和新臂。审计中 Ti DFT 斜率 17.471248、foundation 13.868116、V18 6.292036 eV/Å²；这一对只能作已知 parent 的响应回归，不是独立测试。C 对称斜率须待 C+ 归档通过后计算。
4. **A Ag–Si ±0.20 Å**：先从 source/结构确认位移对象确为同一 Ag 层、相对同一 parent，层原子 mask 在两侧保持一致。逐点比较全原子与 Ag/框架分元素向量误差、标记接触的分离投影；广义层力 `Gz = Σ(i∈Ag层) F_i,z` 对照 DFT 与模型，中央响应斜率按实际两点位移跨度（若恰为 ±0.20 Å 则跨度 0.40 Å）计算。另报告分离力/层力，不把单原子 Fz 代替整层力。
5. A/B 这些同 parent 数值/响应面板只作已知回归 diagnostics；若它们影响超参数选择，即属于 development，不能对外称独立测试。任何既定 sealed labels 仍关闭。

沿用仓库暂定界面门槛时，向量 RMSE 0.05 eV/Å、标记分离力绝对误差 0.10 eV/Å 应分层列出，且需在独立 parent 的 dev/test 上最终确认适用性。骨架先要求新臂不显著劣于同参考基础模型，报告 Ti/C 单独指标与有限位移刚度；不能用总平均抵消 Ti/C 错误。正式门槛须在未来训练授权前冻结。

## 6. 资源、时间、停止条件

**资源估计（未做基准新跑）**：审计记录的 V18 30 帧、80 epoch、4 CPU threads 历史训练约 43 分钟。35 帧臂线性估计约 50 分钟/seed（只作数量级参考）。三臂各一个 seed 约 2.3 小时纯训练；三臂各三 matched seeds 约 6.8 小时，加入 R30 compute-control 后约 9.3 小时，另留约 1–2 小时用于校验/评估。冻结臂可能更快，但预算按与全量臂等时保守估计。推荐 4–8 CPU cores、8–16 GB RAM、至少 10 GB 可用盘；若并行保留多臂全部 checkpoint，预留约 30 GB。旧 runner 单次启动前有 2.95 GB free-disk guard。本轮不申请或占用这些资源。

**停止条件**：

- 纯相数据仍是 numerical control、缺用户明确 role 授权，或有 SCF/hash/身份错误：停止 R30+S 数据组装。
- 任一训练帧与 DFT force 来源不一、能量 key 混用、PBC/ID/父族无法核实：停止建集。
- 无法建立 parent-disjoint 的 dev/test，或只能读 sealed 值才能选超参数：停止训练授权提议。
- MACE 0.3.16 freeze API 未验证、冻结/解冻层未通过参数哈希测试：停止 F30 臂。
- 训练预算或输出路径会覆盖冻结 V18、旧训练集或 A/B 结果：停止。
- 新臂骨架误差较 foundation 明显退化，或界面指标改善以牺牲 Ti/C 骨架为代价：该臂否决，重新审查目标权重/数据覆盖，不以长训补救。
- 任一上述条件未解除前，不启动 V19 训练。

## 7. 熔池、凝固与熔坑数据缺口

审计的 73 项安全公开 PBE 摘要中没有液态 Ag、过冷液态 Ag、固液界面或高温淬火参考。完成固相修复也不能证明相变能力。未来经授权的数据计划至少需包括：不同 seed/密度的熔点附近液态与过冷 Ag 快照；独立双相共存盒和多个界面取向/相分数；高温 Ti₃SiC₂ 框架及真实 Ag–骨架界面快照；近接触短程排斥范围。所有来源须统一 XC、smearing、cutoff、能量口径并按轨迹/parent 分组。

后续物性验证应分步覆盖固液共存界面迁移、熔点区间、RDF、扩散、液固密度、潜热/焓、晶序、偏析、冷却速率和系统尺寸敏感性。单一高速淬火温度、轨迹不爆炸或 OVITO 外观不能替代凝固验证。LAMMPS/TTM 接口、计算性能与能量守恒另设工程审查，不包含在本次准备或本次授权中。

## 8. 本轮完成与授权边界
