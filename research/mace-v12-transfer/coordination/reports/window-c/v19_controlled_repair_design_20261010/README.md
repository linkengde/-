# V19 受控修复实验设计

本目录归档云端 C 对 V19 修复实验的准备方案，基于冻结审计提交 `e455b71f6ef91a0955495001765e659aaee12174`。方案包含受控对照、纯相来源与训练资格审查、父族分组切分、A/B 响应标签回归检查、资源估计、停止条件，以及熔化—凝固数据缺口。

## 文件

- `PLAN.md`：完整实验方案和当前限制。
- `pure_phase_source_eligibility.csv`：25 个已核验纯相 PBE 归档的元数据和 SHA-256；不包含结构、能量数值或受力标签。所有条目的角色均为数值控制，当前训练资格为 `False`。
- `PROVENANCE.md`：输入来源、审计基线、哈希和检查范围。
- `SHA256SUMS.txt`：本目录文件清单（不含清单自身）。

## 结论摘要

同一 Ti₃SiC₂ 公开骨架参考上的基础 MACE 力向量 RMSE 为 0.038173 eV/Å，V18 为 2.888854 eV/Å。V18 训练集包含 30 帧、没有纯 Ti₃SiC₂ 帧。该现象支持显著微调负迁移，但目前只有一个完整骨架父构型，不能断定唯一成因或模型整体表现。

原始 MACE 基础模型重新初始化是建议的首选起点。冻结层对照须先验证 MACE 0.3.16 的真实参数接口。加入完整骨架训练数据的回放臂目前被数据角色阻塞：现有 25 个纯相归档虽收敛且归档验证通过，却均明确标记为数值控制、不得训练或作独立验证。方案不将其标签升级或复制进训练集。

没有可用的 untouched 独立测试集。V18 已有开发结构和目前公开响应构型都只能作历史开发/回归诊断。熔池和凝固适用性也未获证明，液态、过冷液态 Ag、固液共存以及对应的高温界面参考仍缺失。

## 范围与顺序

本目录只记录 V19 受控实验设计，不启动 MACE 训练、DFT、MD、LAMMPS 或 TTM。C 专属后续队列单独记在 `coordination/tasks/window-c.json`：本目录通过 SHA 核验并归档之后，执行三模型静态推理对比，另建结果目录，并以修订版追加更新本设计。旧审计和本目录均保持不覆盖。
