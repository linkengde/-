# DFT data split plan

The canonical split proposal is in [`TRAIN_DEV_TEST_SPLIT.md`](TRAIN_DEV_TEST_SPLIT.md). Both names are provided because the E6 task request uses `DFT_DATA_SPLIT_PLAN.md` while the final deliverable list uses `TRAIN_DEV_TEST_SPLIT.md`.

No role is frozen in this package. Ten baseline-derived candidate geometries are grouped together as one proposed TRAIN family, pending explicit role approval. Four independent DEV/TEST slots remain blocked until distinct source parents are identified; no sealed TEST data were accessed.
