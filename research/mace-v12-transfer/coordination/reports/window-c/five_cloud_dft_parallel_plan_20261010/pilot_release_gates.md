# 六个液态 Ag pilot 的放行门

本文件只定义未来放行条件。当前无坐标、无 DFT 输入、无已放行作业。全部门通过仍须用户单独批准结构生成和 DFT 单点。

## A. 来源与液体构型

- [ ] 由独立来源核验 1250 K 的液态 Ag 数密度 `rho_ref`（表格/方程、单位、温度插值、出处、页面或文献定位、SHA/访问日期）。`9.3 g/cm³` 目前只是熔点附近的文献量级，不可用于最终 cell。
- [ ] 选定 0.97/1.00/1.03 相对密度的定义和换算，校验原子数/体积/质量密度一致；density factor 不替代绝对密度来源。
- [ ] 核实采样器权重/参数文件来源、版本、许可和 SHA。若用 MACE-MP-0b3-medium，记录其只负责生成坐标；若用 Ag-only EAM，逐文件核实文件与许可。当前旧 EAM+Tersoff+Morse 混合包不因便宜而自动合格。
- [ ] 结构生成任务另获授权后，六条独立采样 seed 真实运行并归档轨迹元数据。当前不得启动 MD/AIMD 或复制理论计划冒充坐标。
- [ ] 每条轨迹进入稳定取样窗；核实 T、V/ρ、能量、应力/压力无显著漂移，报告采样区间和自相关时间。
- [ ] RDF、S(k)、第一极小值处 CN 分布、Q6/CNA、MSD 与同 cell fcc 对照共同支持液态：无持久 fcc Bragg 峰/持续长程晶序，MSD 不呈晶格振动平台。具体数值阈值在读任何 DFT 力前预注册。
- [ ] 六个结构保留独立 seed parent；冻结初始源哈希、轨迹哈希、帧序号、元素/atom ID 顺序、cell/PBC 与派生结构哈希。与其他轨迹和既有来源做精确及近重复检查。

## B. 五主机状态和资源

- [ ] D/E/F owner 只读登记已有运行、排队、未启动任务。任何已启动任务、目录和 checkpoint 保持原样；相同 parent/构型已有运行时不重复排队。
- [ ] D/E/F 每台提交 CPU 物理核/可用核、内存/峰值限制、工作盘剩余、OS、历史相近 GPAW 作业耗时。C 当前无法直接访问 D–H；资源状态不能用其他主机数据代填。
- [ ] 验证 GPAW 26.7.0、ASE 3.29.0、PAW data 1.2.1、PBE、PW 500 eV、σ 0.10 eV、SCF 1e-5。记录 PAW 数据源/许可/哈希，不公开私人绝对路径。
- [ ] MPI launcher、GPAW MPI build 与 runtime ABI 一致；记录 BLAS/LAPACK、ScaLAPACK、LibXC 构建能力。每台独立输入/输出/checkpoint；不共享活跃 checkpoint。
- [ ] 液态 pilot 至少 4 个可用物理核、16 GiB 可用内存、建议 30 GB 可用盘；更大的正式结构建议 32 GiB 以上。超出队列内存/时限则暂停并重新排期。

## C. DFT 方法与数值控制

- [ ] 对同一个已通过液态筛选的 64 Ag 快照比较 Γ 与 2×2×2 k 网格；必要时增至 3×3×3。原子顺序、cell、PBC 和电子设置完全相同。
- [ ] 预注册网格差异门：ΔE ≤ 2 meV/atom、force RMS ≤ 0.01 eV/Å、最大逐原子力差 ≤ 0.03 eV/Å。未通过则继续收敛并重新估时；不把未收敛标签纳入 pilot。
- [ ] 若 k 点仍无法满足成本/精度预算，停止扩展六点，报告误差和选择；不得未经批准降精度。
- [ ] 输入生成器、GPAW/ASE 版本、PAW/PBE、PW cutoff、smearing、k 网格、SCF 收敛判据、MPI rank 数冻结；训练候选统一保存 `free_energy` + 同步 `REF_forces`，另保留 native `energy`。能量 eV、力 eV/Å。
- [ ] 每个任务有完整结构、输入、结果、日志、summary 和 SHA256；SCF 必须收敛，能量/力有限，原子顺序和结构哈希匹配，archive verifier 通过。

## D. 成本与停机

- [ ] 首例先出计时/内存/SCF 曲线；估时超过 8 h 时暂停后续提交，C 与 owner 复估。
- [ ] 每例 12 h wall 或 160 SCF iteration 为暂定上限；先触及即保存原 checkpoint 与日志，停止本批后续新单点并报告。不得自动重启或覆盖 checkpoint。
- [ ] 预算暂估：六个单点 18–48 h，mesh 对照增加 3–16 h；合计 21–64 个四-rank 串行 wall 小时。它不是性能保证；真实预算以 D/E/F 资源报告和 pilot 首例为准。
- [ ] 仅有用户另行书面批准后开始；本规划文档本身不是运行许可。
