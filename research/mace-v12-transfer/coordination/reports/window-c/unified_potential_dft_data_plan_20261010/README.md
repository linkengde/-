# Ag–Ti₃SiC₂ 统一势函数新增 DFT 数据规划

本目录仅为经批准后的数据获取做离线规划，不包含新 DFT/MD/MACE 训练结果。具体建议、成本与停止条件见 `REPORT.md`；现有角色统计见 `existing_data_inventory.csv`；按阶段建议的数据规模见 `proposed_batches.csv`；父族切分约束见 `split_plan.csv`；DFT 数据口径与验收门见 `METHOD_AND_ROLE_RULES.md`。`PROVENANCE.json` 和 `SHA256SUMS.txt` 记录来源与完整性。

本方案不改变纯相数值控制标签资格，不读取封存结构/能量/力标签，不新增或改写 A/B 计算任务。所有构型数和耗时均为待审估算，不代表已证明足够。
