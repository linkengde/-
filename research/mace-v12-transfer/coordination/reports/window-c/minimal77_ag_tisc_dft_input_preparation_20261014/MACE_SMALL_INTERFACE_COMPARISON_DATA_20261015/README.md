# MACE 小界面对照结构包

本包提供 3 个 77 原子 Ag–Ti₃SiC₂ 固定几何候选结构，界面间距分别为 2.16、2.40、2.64 Å，供对同一结构做冻结模型推理并与后续 DFT 结果逐结构比较。

## 数据范围

- 组成：Ag28Ti21Si14C14；每个结构 77 原子。
- 文件：三个 extxyz 坐标、结构清单和 SHA-256 校验。
- 来源：C 窗口 `minimal77_ag_tisc_dft_input_preparation_20261014` 归档；坐标原样复制，未重建或修改。
- 三者是同一候选父族的间距变体，不能当作三个独立验证父族。
- 当前目录只含结构，不含 DFT 能量/力标签，也不含 MACE 推理结果。不能据此声称 MACE 已通过或将其当作有标签训练数据。
- 该模型是受应变的 0° 小界面候选：Ti₃SiC₂ 面内应变约 −3.0045%，Ag 约 +3.0975%；它不等同于 12.51983° 低失配大模型。2.40 Å 是参考间距，不是已优化平衡距离。

建议对基础 MACE、冻结 V18（及经批准的候选模型）在三个相同结构上计算能量与逐原子力；模型间只比较一致的力误差/响应，绝对能量零点不可直接比较。要形成误差结论，仍需同几何、同原子顺序的收敛 DFT 标签。
