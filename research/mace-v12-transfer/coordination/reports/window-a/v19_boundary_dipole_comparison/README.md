# 原始真空界面边界/偶极对照

三个归档SHA256均核对，完全相同元素顺序/ID/标记对/离子位置/晶胞，PBE/PW500/sigma0.10/k6设置一致。分开比较周期→slab-off（PBC变化）与slab-off→slab-on（偶极求解器变化），不将不同控制混为网格重复。原生与自由能分列。

off/on能差0.001740meV/atom、力向量RMS0.001211eV/Å、标记对投影差0.001435eV/Å，均在当前2meV/atom、0.01eV/Å、0.02eV/Å预算内。结论只适用此原始真空固定几何。周期与slab-off结果数值相同，必须审查PW泊松后端实际边界语义，不得仅凭ASE PBC标签声称验证了独立开放静电边界。未检查扩大真空下偶极修正稳定性。

这是参考设置控制，不是模型界面力或分离力误差通过，也不是独立验证数据。compare.py可在副本中复现，使用GPAW环境Python，避免覆盖发布快照。

## 扩大真空与匹配父构型对照（2026-10-10）

又核验了26 Å偶极关闭、36 Å偶极开启结果，并与同一固定父构型的26 Å偶极开启归档逐ID比较。26 Å开/关偶极：native能差−0.000737 meV/atom、free能差−0.000941 meV/atom，力向量RMS/最大差0.000845/0.002078 eV/Å。26→36 Å且都开偶极：native/free能差−0.006762/−0.006551 meV/atom，力向量RMS/最大差0.001056/0.002063 eV/Å。两组都在2 meV/atom和0.01 eV/Å RMS预算内。

这支持当前AgSi固定父构型采用26 Å真空、xy偶极修正后继续做刚性分离扫描；它不证明其他界面排布、应变或热扰动结构也达到相同数值稳定性。机器可读指标和每个配对的几何映射见相邻 `boundary_comparison.json` 所在的 slab controls 包。
