# Ag–Ti₃SiC₂ 法向间距候选输入

从已发布的 COD9009647 AgC/AgSi/AgTi 同胞界面父结构复制整个 4 原子 Ag 层，沿正交笛卡尔 z 法向刚性移动 −0.20、0、+0.20 Å。框架、面内错位、晶胞、原子顺序、LAMMPS ID、标记接触对和 PBC 保持不变。候选列表在 manifest.json，六个几何均为无标签结构，launch_enabled=false 且 owner=null。

三个母结构各为52原子 C16Ag4Si8Ti24，来源哈希在清单中。初始 Ag 平均高度相对最高框架原子为：AgC 2.4 Å，AgSi/AgTi 2.6 Å。±0.20 Å后，标记接触距离约变化±0.19 Å（有面内错位），最低 Ag–框架距离均高于记录的0.55倍共价半径和阈值。这只是避免几何重叠的筛查线，不是物理稳定性或合适势能范围证明。每种界面的 parent、压近、拉开几何都已精确保留 ID/order/cell/PBC；候选 SHA256 已记录。

这些结构来自同一个上传 CIF 家族，不能作独立验证。它们只覆盖一种横向注册和单一热零扰动几何；不能代表真实 Stage69 枝状界面。486个经典势间距数据不是 DFT 标签。A 尚需审查平面波泊松边界语义、真空和能量约定，并固定共同目标；所以这里没有正式 DFT 标签或生产登记。

后续配对分析应保留 GPAW 原生外推能量与自由能，不能把有限展宽力说成原生能量的严格梯度。比较同一父结构下的刚性位移能差、Ag 层合力沿法向分量、逐原子力向量和标记接触力投影。绝对界面能需要匹配同元素、晶胞/面内应变、方法和参考零点的分离两相能量，以及明确界面面积和界面数；直接扣纯相每原子能不成立。
