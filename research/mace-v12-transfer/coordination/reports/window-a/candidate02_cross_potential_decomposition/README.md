# 候选02相内/交叉项分解

16个原结构保持不变，只在LAMMPS内存中将Morse深度设0以得到EAM/Tersoff相内贡献，未改源文件、未采用新势。独立解析计算完整8Å邻居及周期像的未平移Morse能量/力；与完整势减相内势的差逐点核对，能差误差<1e-8eV、力分量误差<1e-9eV/Å。

两个Ag–C诊断结构存在约0.906–0.909eV/Å不可由现有中心交叉项消除的全原子力向量误差下界。做法：对每个原子，将DFT力减相内力投影到所有8Å内Ag–X连线方向张成空间，计算正交残差。此计算允许每对邻居任意独立径向幅值，比统一Morse参数自由得多；残差超过0.05门槛，故固定相内势、交叉配对和8Å截断时，单调D/alpha/r0无法使这些结构全部达标。这个限定不能推广成所有混合势形式或其它截断都不可能。

Ag–Si和Ag–Ti几何下界接近0，仅表示该必要条件未否决，不表示能用共同参数拟合，也不是验证通过。相内项单独与完整界面DFT不匹配，不等于已独立证明纯相势失败，因为参考仍包括界面作用。负交叉势能不是实际升温能量释放的动态证据。

因此下一步继续纯相/骨架控制与界面数据覆盖，评估统一多元素势或相内项修正；不要用Morse补偿全部相内误差。当前不重新加热、不采用试拟合、不读封存标签。候选02尚未确认Stage69配置；所有诊断仍非独立验证集。
