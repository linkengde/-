# 交叉势参考数据首轮核对

本次范围是已发布的 cross_potential_dft_reference_bundle_20261009，不代表仓库全部历史 DFT 数据审计。参考包132文件/16案例核验通过；逐项检查输入输出元素顺序、原子ID、坐标、晶胞/PBC及有限力，重算接触距离和标记原子对的投影力。单位为 Å、eV、eV/Å；原生外推能量与自由能分别保留。reference_ledger.csv 是 DFT 响应清单，绝不是模型误差表。

六个局部诊断点中，Ag–C正负点的标记距离完全相同（2.659731 Å），属于其它自由度扰动，不能称作间距扫描；Ag–Si仅覆盖2.857743/2.917743 Å，Ag–Ti仅覆盖3.192975/3.252975 Å。另十点是同一Ag–Si结构的网格/展宽变化。以上不足以约束完整吸引/排斥曲线，也不是独立验证集。后续应结合历史间距数据逐组核对方法与来源，再决定新增距离点，避免重复计算。

当前未找到实际Stage69混合势文件和类型映射，不能计算其能量/力预测、异常吸引误差或联合拟合。需要原始LAMMPS pair_style/pair_coeff、EAM/Tersoff文件、Morse全部参数及截断/平移、元素类型映射；无加热稳定性还需要实际枝状结构、两相掩码与边界约束。不能用虚构参数或MACE代替旧混合势预测。

绝对界面能需要同构型/晶胞/方法下的分离两相参考及界面面积/界面数定义；不能把纯相每原子能直接从混合结构总能中扣减。联合能量—力校准需先选定并声明一致目标，有限展宽力与自由能对应，原生外推能量并非严格力一致。当前没有拟合参数、旧势误差或通过结论。
