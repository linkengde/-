# 迭代与验收规则

目标为保持 Ti3SiC2 骨架外形和约 59.8775 wt% Ag 的候选体系提供可检验势函数，随后研究 Ag 迁移、熔池和表面凹坑。v13 → v14 → v15/v16 是依据新 DFT 证据的迭代流程；版本号不是通过依据。

用户于 2026-10-04 同意以下暂定筛选门槛，统一使用力向量 RMSE，而非单分量 RMSE：每种界面分别计算能量 MAE ≤ 10 meV/atom、原子受力向量 RMSE ≤ 0.05 eV/Å、标记接触对的分离力绝对误差 ≤ 0.10 eV/Å。逐结构报告最大力误差与力方向，不用全元素平均值掩盖某类界面退化。

通过这些数值门槛仍不足以直接批准生产 MD。每种交互必须有未训练的多种几何；当前单个派生几何的通过只能标记局部检查 PASS，整体仍可能 UNDETERMINED。数据不足不能宣称 PASS。

## 数据使用顺序

1. 完成 A 的两个 v13 几何检查，并在追加训练之前保存 v13 逐结构评估。
2. 若 v13 未过或覆盖不足，使用已收敛且核验过的 A 两点与 B 三个 acquisition 点构建 v14；保留 v12/v13 和冻结 valid/test。
3. A 的 AgC/AgSi `holdout_v14_01` 与 B 的 AgTi `holdout_v14_01` 不进入 v14 训练、验证选 checkpoint 或超参数选择，仅在模型固定后评分。
4. 若 v14 不合格，记录误差集中在哪种元素/局部环境，决定 v15 补点及权重；此前的 v14 盲测若用于训练，需要换新的盲测。v16 同理。
5. 每版核对混合 PW/LCAO 标签、能量缺失掩码、元素能量参考、数据重复/几何族相关和训练实际结束状态；只对真实能量标签报告能量指标。

已有结构是少量原子簇放在约 28 Å 周期超胞中的数据。PBC=true 不等于周期延展的体相界面。小噪声不等于真实高温分布；对加热、液态 Ag、压力和生产候选形貌的适用性需要专门采样与 DFT 检查。后续优先补与目标结构相关的新局部环境，而不是只反复微调同一母结构。

独立界面检查支持后，在候选副本中审计组成、骨架、边界和近邻，再做静态力及短程无热无压稳定性；通过后验证 TTM 场恢复和能量交换，最后建立熔池及相同完整 checkpoint 的零压力/压力对照。分别报告轨迹、Ag 位移/分布、液态区域、熔池尺寸和凹坑几何；这些是计算预测。
