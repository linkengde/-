# Round7 后续分析图：图7–图10

本目录收录 Ag 结构、迁移与温度分析图，图件来自已有 Round7 轨迹后处理。

- **图7：熔化相关指标时间序列**：[PNG](Figure7_Round7_Ag_melting_evidence_timeseries.png) · [PDF](Figure7_Round7_Ag_melting_evidence_timeseries.pdf) · [TIFF](Figure7_Round7_Ag_melting_evidence_timeseries.tif)。联合筛查数随时间增加，但筛查阈值尚未针对 Round7 势函数校准，不能将筛查数直接视为已确认的液态 Ag 原子数。
- **图8：热源区空间演化**：[PNG](Figure8_Round7_source_core_spatial_evolution.png) · [PDF](Figure8_Round7_source_core_spatial_evolution.pdf) · [TIFF](Figure8_Round7_source_core_spatial_evolution.tif)。红色标出各时刻同时通过结构和迁移临时筛查的 Ag 原子。
- **图9：Ag 与 Ti₃SiC₂ 局部晶格温度场**：[PNG](Figure9_Round7_lattice_temperature_fields.png) · [PDF](Figure9_Round7_lattice_temperature_fields.pdf) · [TIFF](Figure9_Round7_lattice_temperature_fields.tif)。温度由局部质心漂移修正后的速度方差估算，使用 20 Å 空间分箱。
- **图10：电子温度统计**：[PNG](Figure10_Round7_electron_temperature_summary.png) · [PDF](Figure10_Round7_electron_temperature_summary.pdf)。归档中只有电子网格温度的全域均值和最大值，没有逐网格温度数组，因此该图不是电子温度空间分布图。
