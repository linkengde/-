# Round7 Ag/Ti₃SiC₂ 界面与 MAX 骨架分析方法

## 图11：界面接触与骨架迁移

固定跟踪更正源区筛选得到的 1,787 个 Ag ID，按 0.60、0.85、1.10、1.35、1.60 ps 五帧统计 Ag 到最近 Ti/Si/C 原子的距离，以及每个 Ag 在 3.5 Å 内的 Ti、Si、C 邻居数。右图按 0.60 ps 时最近 Ag 距离 ≤3.5 Å 将 Ti、Si、C 骨架原子标为界面邻域，比较该组与骨架内部的漂移修正 RMS 位移。漂移取每一帧间隔、z=40–150 Å 骨架原子的平均位移；x/y 采用周期最小镜像，z 不周期。

本体系为双连续 QSGS 形貌，界面弯曲且互相贯通，没有一个可代表全域的平直界面法向。因此不把某个任意 x/y/z 方向包装成“界面法向浓度”；图11改用局部距离和元素接触统计。

## 图12：热源核心 Ag 的条件部分 RDF

以同一组源区核心 Ag 为中心，统计 Ag–Ag、Ag–Ti、Ag–Si、Ag–C 距离分布；目标原子限制在材料层 z=0–150 Å。壳层按该元素在材料层的平均数密度和开放 z 边界下可达的球壳体积归一化，x/y 周期。由于 QSGS 两相在空间上强烈非均匀，长程基线不强制为 1；主要比较第一近邻峰的位置、宽度和时间变化。它是局部条件 RDF，不可当成均匀体相 RDF。

## 图13：MAX 骨架局部结构和几何连通

不使用 Ag 的 FCC/PTM 分类判据。Ti–C 与 Ti–Si 首壳截断值分别为 3.00 Å 与 3.85 Å，依据 0.60 ps 距离直方图第一峰后的首个谷值选定，并固定用于所有帧。配位统计比较 Ti 周围 C 与 Si 的平均近邻数。键长代理跟踪 0.60 ps 首壳内同一对原子，并给出中位数及四分位数；保留率表示这些原子对在当前帧仍处于首壳截断内的比例，不是化学键能或反应判据。界面/内部按首帧骨架原子是否距最近 Ag ≤3.5 Å 分类。

骨架几何连续性以 Ti/Si/C 任意两原子间距 ≤3.25 Å 建图，报告最大连通分量比例和分量数。它是几何连通筛查，不等于力学承载或化学稳定性。

## 数据边界

输入是已有 Round7 全体系五帧 dump，时间间隔 0.25 ps。轨迹文件未保存逐原子力/应力向量，故无法识别分叉点应力集中。轨迹所属 Round7 开发 MTP 尚未独立验证 Ag 熔化与 Ag/Ti₃SiC₂ 界面可迁移性，且运行摘要报告了 133.006 eV/Å 的最大检查点力。因此这些图仅量化该探索性轨迹中的几何接触与局部结构变化，不证明界面扩散、化学反应、熔化或熔焊。
