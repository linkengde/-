# Stage67 300×300 Å 扩展：MODEL_READY 审查

**结论：`MODEL_READY=NO`。本轮没有生成结构或 TTM 空间映射，也没有启动 MD。**

审查基于 GitHub handoff 分支 `cloud-d-stage67-300x300-extension-handoff-20261013` 的提交 `f4faca36e3987ddc577c49c6ce8c27a1731073da`。先 fresh-fetch 该提交，重组 41 个 ZIP 分卷；ZIP SHA-256 为 `6cbef8dbf96ee2f94bf5c2929b0b622902db12898f879cde00e6c97c56a59547`，解包后 49 个文件的内部 SHA256 清单全部通过。

## 已核验来源

- `high_frequency_step_1650.dump`：SHA-256 `91d04a6fa3cb1b2fd9eb668b392cad04ecb593620723beac3e12ea4e7b8e85fc`；step 1650（0.165 ps），303,372 atoms，PBC=`p p p`，盒子 `150.1×200×200 Å`。
- 按交接 driver 的质量映射统计，类型计数为 Ti 105,948、Si 33,176、C 69,624、Ag 94,624；总数 303,372。数密度 `0.05052831 atoms/Å³`，质量密度约 `4.71459 g/cm³`。
- Stage67 driver 记录 timestep `0.1 fs`。势文件为 Ag EAM、TSCBOP 和 `calibration-v0` 交叉项；交接明确交叉项尚未获生产级验证。本审查未修改或替换任何势文件。

## 扩展为何未放行

原横向边长为 200 Å，目标为 300 Å，比例是 1.5，不能由整数周期复制直接得到。另做了来源帧四个 `100×100 Å` 象限的周期等价检查：四象限分别有 75,840、75,842、75,846、75,844 个原子；按类型及 modulo-100 坐标四舍五入到 `1e-6 Å`，与象限 00 的共同坐标键分别只有 14,696、14,817、14,574 个。因此不能把某个 100 Å 象限当作原模型的可重复基元再 3×3 平铺。把 200 Å 周期盒复制后裁到 300 Å 会形成未验证的周期接缝。

还存在尺寸约束冲突：来源 X 长度为 150.1 Å，而请求写 X=150 Å；如严格“只扩大 Y/Z”，应保留 150.1 Å，不能静默压缩 X。

## 可计算但不是生成模型的估算

若保留来源 X=`150.1 Å` 并维持相同密度，目标盒体积是来源的 `2.25×`，密度缩放的原子数估算为 682,587；按来源各类型乘 2.25 得 Ti 238,383、Si 74,646、C 156,654、Ag 212,904。这只是计数估算，不是已构造结构。若严格使用 `150×300×300 Å³`，在来源数密度下的理想原子数为 682,132.245，且 X 与“只扩大 Y/Z”不一致。

目标 `150×300×300 Å` 若保持约 10 Å 的 TTM 单元，网格尺寸候选是 `15×30×30`（13,500 cells）；若保留来源 `X=150.1 Å`，单元尺寸候选为 `10.0067×10×10 Å`。旧映射是 `15×20×20`（6,000 cells），文件名和交接均明确标记为不可用于 300 Å，因此未复制或重编号成新映射。

## 热源位置检查

旧 200 Å 热源表的径向坐标中心是 `(y,z)=(100,100) Å`，深度从 `x=50 Å` 表面起算；旧 4×源总功率为 `64,000 eV/ps`、320 个正源单元。扩大后若保持绝对位置，中心为 `(50,100,100) Å`；若要求在新 300×300 截面居中，则为 `(50,150,150) Å`。现有指令只冻结热源形式，没有确定该中心应保持绝对坐标还是随盒子重心平移，因此未生成热源映射。

## MODEL_READY 阻塞项

1. 需要冻结一种可验证的 Y/Z 扩展与边界缝合规则；现有来源既不具 100 Å 平移对称性，也不能按 200 Å 整数复制到 300 Å。
2. 需要明确 X=150 Å 是精确要求还是对来源 150.1 Å 的取整表达。
3. 需要明确热源中心扩展后保持 `(100,100) Å` 还是移至 `(150,150) Å`。
4. 完成几何规则后，才能从新模型重建 15×30×30 的材料分数、`G_mix`、Te 和热源映射；旧映射不可复用。
5. Stage67 manifest 指向的 `in.regions_x_surface.inc` 在 handoff 中缺失；本轮没有从其他模型替换。

输入 handoff 本身也将状态标为 `PACKAGE_READY_FOR_300A_MD=NO`。因此未生成 `300×300` 结构文件、实际原子计数/密度或 TTM 映射，以免把未经确认的边界接缝和热源位置写入正式模型。JSON 机器可读审查见 [MODEL_READY_REVIEW.json](MODEL_READY_REVIEW.json)。
